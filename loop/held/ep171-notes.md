# 제171화 「서로 다른 집」 미공개 체인 인계

- 170의 세아 문의에 일요일 가람/도준이 각자 새 시간과 열람·메모/대화 이용을 답한다. 도준은 자기 표제까지만/소리·영상 비재생이고 기존 승계 불참은 유지된다. 가람은 원본/허락 사본을 나누고 세아는 자기 연구 정리를 뒤로 옮긴다. 서인 메모는 네 사람이 읽을 기술 목록 질문만이다.
- 같은 식탁에 관한 가람의 돌봄/다른 질문, 도준의 비슷한 주제로 돌아감, 세아의 출처 미확인 소리는 현재 회상 진술이다. 같은 밤/기기·실제 프로그램 증거로 확정하지 않는다. 도준이 선택을 증명받는 질문을 거절해 세아와 서인이 제시 조건으로 질문/제목을 실제 고친다. 부친에게 먼저 묻는 방법과 자기 질문을 먼저 정할 선택을 나눈다.
- 새 허락의 등록 별칭과 관리 표제/참조 목록을 대조해 선택 연습 별칭과135 표제의 대응, 뒤에 추가된 참조 항목을 확인한다. 제목/목록 존재가 실제 열람·재생/작성자 증거는 아니며 옛 등록 방식과 본문/개인 실행 부분은 새 범위를 받아야 한다.135에서 이미 제3필드/PREVENT를 본 것으로 소급하지 않는다.
- 도준은 오늘 메모 이용을 직접 확인하고 수영장 일정으로 나간다. 가람은 남은 시간에 본문/반출 확인을 끝내기 어려워 친구 약속을 지키고 내일 자기 한정 부분을 읽을 시간/질문을 다시 알리기로 고른다. 세아는 밀린 연구 정리를 현재 비용으로 남긴다.172 새 본문 범위는 미래다. 새 회상/등록 이력·일정/허락·장소/메모/문안은 (제안). 나이/어머니 미정·비밀/HOLD/R/176정체·199200 유지.
