# 제174화 「동의하지 않은 아이들」 미공개 체인 인계

- 목요일 오전 세아가 가람이 타인 내용을 걸러 낸 자기 항목을 연다. 어릴 적 자주 꾼 ‘손을 놓은 광장·회색 털장갑’ 꿈이 저녁 이야기 항목에 있고 `외부 제공 단서 · 1건 · 출처 표시: 없음`. 단서의 주인은 열지 않음. 165에서 도윤이 짚은 ‘출처 확인 ≠ 먼저 보여 줌’이 여기서는 둘 다 비어 있음.
- 버스: 세아의 여분 장갑이 회색 털장갑. 버리지 않음(“따뜻하잖아요. 그건 제가 알아요.”).
- 오후 기술원 감사 접수실(연동 검토실 아래층). 박현오가 가람의 월요일 문의에 대한 답으로 접수 담당 배정. 각자 오늘 정해 넘긴 것만 수신, 서명·판본·실행 순서 대조, 타 제공자 원본 불가. 서명 대조 당일, 실행 순서는 길면 다음 주.
- 제출: 가람 — 기록 존재·보관 목록·등록 이력(내용 제외, 제출자 칸에 가람 하나) / 세아 — 승인 칸·출처 표시 칸·판본(광장 단서 원본 제외) / 도준 — 실행 표시 줄의 날짜·실행만(제목·4분 줄 제외, 감사에만, 사례 비공개). 가람 승인 칸은 범위 밖 → 토요일 직접 묻기로.
- 대조 결과(오늘 범위): 가람 등록 이력과 세아 승인 칸이 같은 날짜. 같은 계획인지·출처 누락 판본이 실제 쓰였는지는 실행 순서 대조 뒤(미확인). 승인 설명 “정서 안정 및 가치 판단 회복 지원. 반복 주제 우선.”, 경과 기록에 수면 안정 지표 실제 개선 → “치료 기능도 있었습니다” / “그래서 치료인 줄 알고 자랐어요.” 이니셜 해석 없이 등록 서명 대조: `승인 서명 · 등록 서명과 일치 / 사후 수정 흔적 · 없음 / 서명자 · 도윤.` 출처 표시를 뺀 결정 기록은 범위에 없음(의도 미확인).
- 세아가 자기 자료 제공 조건 칸에 `SOURCE TAG MANDATORY / NO FAMILY EXCEPTION` 직접 기입(자기 자료에만, 도시 규칙 아님). 서인은 결과 사본 수신 거절(대신 말하는 사람이 되지 않으려고). 세아는 오전 회의를 빠졌고 검산표는 밤 작업.
- 끝: 가람→도준 “승인 서명은 아빠 거 맞대. 토요일 오후에 셋이 같이 가서 물어볼래?” 도준 “ㅇ. 대신 내 질문은 내가 함.” 세아 “내 질문은 세 개 다 들고 갈 거야.” 노트 첫째 질문 옆 “아빠.”, 둘째(승인 설명)·셋째(출처 표시 뺀 기록)는 그대로.
- 175 인계: 토요일 오후 세 자녀가 각자 고른 질문으로 도윤과 대면(서인 동석 여부는 자녀들이 정함, 미정). 도윤의 승인·개입 책임 인정과 의도 진술은 175 몫. 실행 순서 대조 결과는 아직 없음. 가람 승인 칸·도준 4분·광장 단서 원본은 각자 소유.
