# 제147화 「먼저 쓸 시간」 미공개 체인 인계

-토요일 실제 작은 방 읽기다.서인·우석과 교대근무자 이강호(146 문의자/이번 새 이름),전날 짧은 참석 답을 준 미란까지4인이다.현장 첫 읽기 시간을 먼저 썼다.현재 정책/요금이 아닌 가상 이동 안내의 누락 조건·추가 확인을 누가 부담할지 읽었다.개인/사업자/공동 부담의 질문과 기본 확인 범위가 갈려 표결/시민 합의로 정리하지 않았다.
-강호는 다음 근무자가 오지 않으면 남은 사람이 기다리는 자기 경험을 들어 더 큰 비교로 남는 일이 실제 줄어드는지 먼저 보고 싶어 한다.미란은 처음부터 빠진 조건을 다시 묻는 데 추가금을 받는지/공동 예산의 ‘같이’가 누구까지인지 묻는다.한 의견이 다른 의견으로 바뀌지 않는다.강호의 직장 이야기를 외부 사례로 배포할 허락은 없다.
-금요일 새 연락으로123의 지역 계약 검토 지원 자문 박유진과 토요일 짧은 공개 문구 통화를 약속했다.기관 대표/다음 준비 인력이 아니다.모두 함께 듣는 데 동의한 통화에서 공개 보고서의 대상 내 비용·신청 지원/검토 완료와 회신·결과 차이를 설명하고 공개 의견 창구를 알려 준다.새 고객·기관 내부 자료는 없다.
-다음 준비는 강호가 새 가상 문항의 말을 한 번 읽는 데 동의/시간은 각자 일정 확인 전이다.기관 내부자료를 줄 허락이 아니고 범위 바뀌면 새 검토 필요다.우석은 공개 비용 지원 조건 읽기1회만 새로 맡고 다음 안내는 어렵다고 했다.서인이 새 다음 안내와 기존 참가 문의를 계속 맡는다.미란 연락처는 새 설명 수신용이지 준비/지불 의향 동의가 아니다.다음 방은 답을 받고 정한다.
-서인은 기관에 확대 비교에 필요한 범위/작업을 문의하고,유진이 알린 공개 창구에는 안내 누락 재확인/새 추가 요청 구분과 공개 지원 비용/담당 범위를 물었다.두 접수만 실제 확인됐고 답/새 자료·계산 허가·재원은 미래다.강호는 자기 의견을 다음 공개 초안에서 자기 문장으로 정리해 보내면 뜻을 봐줄 동의만 추가했다.확대 비교 우선이 유지/비용 무시 입장이 아님을 분명히 했다.
