-163 새 문의 뒤 금요일 정지윤이 센터의 기존 중립 문안 설명 시간/담당을 답하고 세아도 오전만 새로 정한다.새 심리사 양수경과 공고를 보고 신청한 성인 신다영의 배정 검토/보상이며,읽기 종료에도 보상은 유지된다.다영이 새로 만든 비개인 예시와 절차 발언은 두 방문자 메모만,외부 이름/발언 공개는 별도 허락이다.
-본인 단어 빨래/담당 단서/교재 타인 예시를 출처별로 읽는다.다영은 미리 설명받고 고른 구간에서 출처를 잠깐 접었다가 다시 연다.나중에 제시된 처마가 먼저 나왔어도 남의 기억을 얻거나 출처를 잊은 것은 아니다.단어·순서/과제 반복이 함께 달라 표시 접기 하나의 인과/효과 크기를 측정한 결과가 아님을 현재 문안에 붙였다.
-다영은 틀린 답 점수 대신 처음과 뒤의 단어를 함께 남기고,뒤 문안은 출처를 펼친 상태로 고른다.화면 길이/되돌아읽기의 다른 비용과 선택이 실제 수정 항목을 바꾼다.실제 자기경험 재활자료의 출처 유지 절차는 오늘 알고 택한 중립 문안 접기와 별개다.
