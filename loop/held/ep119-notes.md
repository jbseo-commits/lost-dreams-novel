# 제119화 「나간 뒤의 일」 미공개 체인 인계

- 월요일 오후 수리점에서 정라온이 본인 종료 사본과 글을 직접 보여 준다.
- 토요일 밤 도윤이 자기보다 먼저 후계를 떠난 사람을 언급했다. 서인이 직접 묻고 싶다고 해 일요일에 연락했고 월요일 한가한 시간에 만나기로 했다. 도윤은 자신이 이탈한 뒤 라온의 글을 읽고 서신을 나눴다. 같은 시기 동료·비밀조직 선배·정치적 후계라는 관계가 아니다.
- 라온은 자기 역할을 계속하고 싶지 않아 나갔으며, 기준 체계를 고쳐 유지하자는 의견은 밖에서 몇 번 더 냈다. 동일한 문제를 겪은 것과 후속 운동에 동의한 것은 다르다. 성별·나이·27년 간격은 채택하지 않았다.
- 현재 수리점에서 독서 단말을 맡긴 손님에게 기기를 빌려 주고 읽기 위치를 되찾게 한다. AI와 현재 체계의 유용함을 쓰는 생활이 남아 있다.
- 도윤은 내일의 작은 자료 열람 모임용 소개 묶음을 가져왔다. 아직 라온의 인용 허락 전이다. 인용문 자체는 맞지만 ‘혁명 계보’ 표제와 앞 소개가 라온의 이탈을 도윤의 혁명 지지처럼 읽히게 한다.
- 최종 허락은 당사자 설명을 붙인 인용문과 의견서 두 쪽을 **그 모임에서 읽는 범위**다. 다른 공개는 새로 확인한다. 라온이 자기 두 쪽만 복사해 주며 다른 원본 파일은 서랍에 남는다.
- 도윤은 기존 인쇄를 중지해 달라고 연락했다. 앞장·목록·소개 재작성, 바뀐 파일의 인쇄와 배포는 아직 끝나지 않았다.120에서 실제로 수행한다. 전체 D.Y.INDEX의 소급 개고가 아니다.
- 118의 가족 일정·별도 지원 문의는 서인에게 추가로 전달되지 않는다. 라온과 수리점·현재 연락·문서·모임은 새 세부(제안).
- 독립 사실·편집 최종 본문PASS,6항목 각9·평균9.00. 도윤이 서인에게 말하는 첫 소개의 존대/자칭 한 곳을 교정해3560자·누적1/3. 같은 두 검수자 변경분 PASS.
