# 제197화 「돌아오는 사람」 미공개 체인 인계
- 목요일, 쿨링 닷새째. `PUBLIC LOG · 어제 · LEAVE 3 · REJOIN 1 · DECLINE 0`, `LEAVE · 동남 · 아이 운동회`, `REJOIN · 북부 · 보상표 확인 · 하루 네 시간 제한 · 검진 통과`(이틀 지연 때 빠졌던 분, 수요일 재참여). 광고꿈 유지 61%(제안).
- 달걀 심부름 길 초등학교 운동회: 회색 작업복 점퍼 여자, 관자놀이 자국, 동일인 확인하지 않음. 열 개짜리, 깨진 것 없음.
- 저녁 7시 도준 수영장 2층 강습실: 사다리 비유, 네 칸, "회원증 안 뺏어요", 할머니 질문(북부 재참여·빠진 동안 안 나옴), 보드 구석 `사람은 편한 꿈을 고른다. — 아버지(도윤), 12년 전 강연 녹취` 지우지 않음. 문규(대화방) "61은 실패". 지우 "저도 그 61이에요… 알고 안 누른 거예요." "우리가 자유롭게 고르라고 했잖아요. 왜 우리가 원한 걸 골라야만 성공이에요?" 029 회수. `DECLINE · 안 나가는 것도 칸이 있음.`(늘 0이었음).
- 가람 수첩 두 쪽: 왼쪽 '편한 쪽 다시 고른 사람' 번호(지우=스물셋, 날짜), 오른쪽 말 그대로, 이름 제외. 문규 "다음 주에는요?" "다음 주에도 저 친구가 정한 건 저 친구 거예요." 도준 레인 끝 안전요원 의자.
- 밤: 어머니 "잘 자면 됐지." "내일도 사 와." 세아 `SOURCE · CONSENT VERIFIER · CODE PUBLIC · AUDIT OPEN`, 남부 확대 보류(재정, 석 달) "알리는 거예요." 지우 "광고꿈 보고 잘 거야", 서인 "잘 자." 계산 기다리지 않고 불 끔.
- 검수: 3511 → 3517·누적 1/3·FACT_PASS·편집 각 9/평균 9.00. 연출 미구현·미공개.
