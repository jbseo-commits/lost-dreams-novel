# 제189화 「해방됐다는 사람들」 미공개 체인 인계
- 목요일 저녁 6시 시청 앞 광장(입김). `잃어버린 꿈의 귀환을 환영합니다.` 섞인 참가자: 같은 글씨체 팻말 앞줄, 퇴근길·휴대폰·아이 손 부부·포장마차, 아버지가 광고꿈 끄고 웃음(서부인지 팻말에 없음), 일당 청년 둘, 교복 아이 셋.
- 서인 서쪽 가로등 아래 탁자(세아, 가람 연단 뒤), 감사실 공개 자료(이름 없음): `연결 32명` / `동의 창 지연 4분 12초. 동의 없이 시작됨.` / `면담 완료 15명 · 증상 있음 6 · 변화 느낌 4 · 무증상 5.` / `효과 지속 여부 · 모름.` 금지 안 함.
- 도윤 연설: “제가 열었습니다.” 기타(본인 허락, 십육 년 만에), “밤새 힘들어한 사람도 있습니다… 원망스러울 겁니다. 당연합니다.” “먼저 물어야 한다고 합니다. 맞는 말입니다. 그런데 묻는 동안에도 사람들은 잊습니다.” “대가가 있다는 걸 압니다… 저는 지금도 그쪽이 더 무겁다고 생각합니다.” 군중 “우리 딸도 열어 주세요!” → “제 권한은 정지됐습니다. 정지시킨 사람이 저기 있습니다.”
- 탁자: 찢는 남자, “모르는데 왜 막아요?” “모르니까요.” 경민 “무증상 다섯… 엄마한테 보여 줄래요.” 상철 “내가 행복해졌다는 것도 부정할 거예요?” “아니요.” “그럼 저 사람이 옳았네요?” “상철 씨가 행복해진 건 사실일 수 있어요. 그게 다음 사람한테 묻지 않아도 된다는 뜻은 아니에요.” “다음 사람이 나 같으면요?” 서인 “영란… 그 다른 분”(이름 반쯤 노출 — 191~195 결함 씨앗, 손이 탁자 모서리). 상철 코드 넷 “찍지 마세요. 이건 내가 친 거예요. 깨어난 사람이 친 거 아니고.” 세아 “예전엔 그런 말 안 했어요. 우리 얘기 할 때는.”
- 원상복구 무리 `즉시 원상복구.`: 187 남편 서명판(아내 이름 대필) → “아내분 일은 아내분이 직접 말씀하실 거예요. 감사실이 날짜를 따로 잡았어요.” 젊은 여자(어머니 불면, 면담 다음 주 수요일) → 치료는 순서와 따로 먼저. “원상복구에 서명 안 해요… 금요일 새벽이랑 같은 일이에요. 방향만 반대고요.” “이분들 편이요. 서른두 명. 한 분씩.” 남편이 아내 이름 옆에 물음표.
- 끝: 종이 일곱 장, 세아 “맞는 말이 섞여 있어서요.” “싫어하겠네요.” “오늘은요.” “내일도 면담 네 분이에요.” 도윤 마이크 선·끄덕임·가람과 나란히. 어머니 “춥지. 국 데워 놓을게.” 종이 접지 않고 반듯하게.
- 190 인계: 청문회 두 명제, 실행권한 정지·기록 보존·자발 지원·독립 조사·재발 방지, 꼬리표 금지. 대면(‘도윤 씨’), 회수 “효과가 있으면 더 위험하다면서요.”(100 L67 도윤). 선택 목록 `KEEP CURRENT CHOICE / REQUEST SUPPORT / DECLINE FOLLOW-UP / UNDECIDED`(지우려다 멈춤은 동작 변경, 30일 기한 미언급). 원안 해설형 마지막 문장은 행동으로.
- 검수: 3526 → 3531·누적 1/3·FACT_PASS·편집 각 9/평균 9.00. 연출 미구현·미공개.
