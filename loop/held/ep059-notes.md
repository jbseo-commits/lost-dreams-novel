# 제59화 노트 — 누구의 0.006

## 설계
- 목적: 확률이 누구의 것인가. 0.006이 한 아이의 왼손이 된 뒤, 책임은 어디에도 고정되지 않는다. 서인은 명진에게 알리기로 한다(돌아오라는 말 없이).
- 사건: 목요일 신탁이 보호자 면담에 '설명한 사람' 동석 요청 → 병원(아이 생활 장면: 오른손 크레파스, 왼손으로 종이 누르기, 서인이 귀퉁이를 눌러 줌) → 보호자 "길이 막혀서 늦은 거라면서요." 서인 "판단이 늦었습니다." "누가요?" "한 사람이 아니에요." "그럼 아무도 아니네요." → 신탁 "기준계열 얘기를 하면 물을 사람이 하나 생깁니다. 이름이 있는 사람" → 목요일 밤 장부실(앵커 해방 쪽 셋: 다시 묶자는 거냐 / 다친 사람이 아닐 때나 쉽다 / 0.006 허용 범위 → "누구의 0.006인데요." / 한 명 이탈·한 명 보류·한 명 풀 신청) → 풀 남자 "저도 대답했어요?" 하경이 알려 줌 → "오늘은 일찍 잘게요."(아무도 시키지 않은 자발적 의무 — 61–65 '강제 없는 강제' 씨앗) → 금요일 통지 체크, '재연결 상담 안내 동봉' 체크 해제, "설명한 사람이 직접 찾아가 말함."
- 핵심 선택: 서인이 보호자에게 명진의 이름을 넘기지 않음 / 명진에게는 숫자 그대로 통지, 재연결 안내는 뺌.
- 반복 점검: '왜 늦었어요?'(58 간호사) 대신 '길이 막혀서 늦은 거라면서요.'. 메시지 쓰고 지우기 회피(기본 문구 삭제 대신 체크 해제). 파벌 발언 나열 대신 세 사람의 행동(나감·나감·서명). 도윤 미등장(60화).

## 새 제안 (작가 확인 전)
1. 07 신탁 연락 담당(여성, 서른 남짓, 회색 정장). 기준 공백 관련 보호자 면담에 설명한 사람 동석 가능(의무 아님). 신탁 명의 사과 불가(책임 소재 미정). (제안)
2. 아이: 일곱 살쯤, 오른손잡이, 크레파스, 왼손 손가락 두 개 반쯤 굽음. 보호자 서른 중반. (제안)
3. 앵커 해방 쪽 세 사람(안경 쓴 남자 보류, 키 큰 여자 이탈, 작업복 남자 07 풀 6번 신청). 셋은 55화 유예 서명지 서명자. (제안)
4. 풀 남자가 '응답 셋 중 하나'임을 하경이 알려 줌. 07 풀 종이에 '5번 · 밤 10시 반 소등' 자필. (제안)
5. 본인 통지 양식: □ 통지 □ 비통지, '☑ 재연결 상담 안내 동봉' 기본 체크, 통지문 다음 날 오전 발송. (제안)

## 60화 인계
- 토요일 오전 통지문 발송 → 서인이 명진을 찾아감(정해진 일과 밖의 장소: 종점 차고지/바닷가 등). 설계 대사: "아이는 죽었습니까." "아니요." "후유증은요." "아직 모릅니다." 61.3퍼센트. "미안합니다." "그래도 돌아가지는 않겠습니다." "그 아이가 평생 불편하면요?" "그러면 평생 미안하겠죠." "그래도 제 평생을 다시 내놓지는 않겠습니다."
- 도윤: "그럼 누구를 골라요?" "왜 네가 골라야 하는데."
- 마지막: 아이와 명진의 병치(판결 없이). 아이 손에 작은 물건(설계: 스티커나 작은 공).
- 풀 남자의 10시 반 소등 → 61–65로.
- 하경이 58화에서는 '알려 주면 밤이 무거워진다'고 했지만 59화에서 풀 남자가 직접 요구하자 알려 줌(의도된 변화: 본인이 묻는 정보는 막지 않음 — 서인의 명진 통지 결정과 같은 축). (기록)
