# 제188화 「되돌리는 폭력」 미공개 체인 인계
- 월요일 아침 게시판: 지지 모임 목요일 저녁 시청 앞 광장 집회 `잃어버린 꿈의 귀환을 환영합니다.` / 반대 `서부 서른 명 즉시 원상복구.`(이틀 새 천 명 넘음). 같은 사진, 이름 없이 숫자.
- 합동대응팀 1차(시청 별관, 위원장 시 행정실 남자): `역방향 안정화 · 대상 32 · 소요 1일 · 동의 절차: 사후 통지.` 재난 담당(열파 때 먼저 대피) ↔ 서인 “대피는 몸을 옮기는 거잖아요. 이건 이미 떠오른 걸 다시 옮기는 거고요.” 기술부: 역방향도 같은 문. 감사실: 기록 흐려짐. 서부 센터 의사(마흔쯤 여성, 영란 담당): 각자 다른 치료, 새 자극, 만난 분 절반, 영란 처음 두 시간 잠.
- 세아 일요일 전화로 ‘무엇까지 말해도 되는지’: 상철·경민 허락, 영란은 치료 원함까지만. 서인 두 장 공개 + 한 장 뒤집음. 대안: 일괄 역방향 없음, 원하는 분만 진료, 출처 공개, 증상별 치료, 사후 선택, 응급 최소 처치 예외 유지. 세아 “아빠가 마음을 먼저 바꿨다면요… 원래대로 돌아가나요?” 서인 “아니요… 덮어도 덮였다는 게 남고요… 그러니까 이번엔 우리가 먼저 묻는 거예요.”
- 결정: 일괄 안 표결 없음, 2주 안 32명 개별 면담(하루 넷), 응급 예외 유지, 늦으면 재회의. 행정실 “저는 반대했습니다… 제안자 몫입니다.” 재난 담당 “틀리면 그 두 주는 여기 있던 사람들이 같이 진 거고요. 선생님 혼자 진 게 아니라.”
- 도윤 문자(이해관계인 통지) “일괄 되돌리기 막았다며.” “그건 잘했다.” → 집회 공지 알림, 서인 무답.
- 오후 3시 동남 회의(실무 회의는 세아 대리 → 회의록 ‘제안자 불참.’ “틀린 말은 아니에요.”): 대표(쉰쯤, 작업복 위 카디건, 알람 두 번, 정수장 침전지), 손으로 쓴 줄 순서(약국 둘·노인정·학원), 비필수 하한 그날 저녁 재개, 약국 할머니 두 번 헛걸음 “지난주엔 미웠어요… 근데 오늘 왔으니까요.” 메모: 동남 줄 / 세아 문자 / 금요일 접수 번호.
- 저녁 어머니: “누구 편으로?” “편으로는 안 가요.” “뭐가 있었는지 말하러요… 그분들이 허락한 만큼만요.” “춥게 입고 가지 마.”
- 밤: 영란 개별 치료 시작(본인 선택, 잠 아직), 상철 “오늘은 광고꿈 켜고 자려고요. 내일 야간조라서요… 기타는 주말에.” 영란 종이 글자 안쪽으로 접어 가방 안쪽 주머니.
- 189 인계: 목요일 광장 집회(섞인 참가자), 서인 금지 안 하고 공개(허락 범위), 상철 “내가 행복해졌다는 것도 부정할 거예요?”(원안 A — 허락·현장 등장 여부 확인), 도윤 A 인용·B 고통 인정(영란 정보 공개 범위 주의), 서인 진영 원상복구 요구(서명 천 명)에 반대.
- 검수: 3525 → 3540·누적 1/3·FACT_PASS·편집 각 9/평균 9.00. 연출 미구현·미공개.
