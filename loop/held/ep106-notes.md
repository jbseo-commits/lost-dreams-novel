# 제106화 「우리 집」 인계 노트

> Gemini 자기검수 — 독립 검수 아님

## 요약 (5줄)
1. 일요일 늦은 오후, 105화 말미의 `FAMILY REVIEW` 알림 직후 도윤은 서인을 언덕 중턱의 오래된 4층 공동주택인 자기 집으로 데려간다.
2. 현관의 반품 택배 상자, 닳은 신발들, 가족사진과 `REFERENCE TRUST ACCESS` 단말이 공존하는 집에서 도윤의 장녀 도가람이 서인을 맞이한다.
3. 가람이 검토 중인 문서는 신체 앵커 시술 계약이 아니라 3년 주기의 `ARCHIVE / REFERENCE TRUST SUCCESSION REVIEW`(실패 아카이브 보존·기록 접근권·일부 기준계열 신탁 관리권 승계)다.
4. 도윤은 가람에게 "싫으면 안 해도 돼"라고 말하고 가람은 "알아"라고 답하며, 서인은 38화 윤하진의 집에서 들었던 같은 말을 떠올린다.
5. 상태는 `SUCCESSION ACCEPTANCE: PENDING`으로 남고, 서인은 가람이 보관한 과거 유사 기간 단절 실패 기록을 보기 위해 다음 날(월요일) 오후 다시 도윤의 집에 오기로 약속한다.

## (제안) 설정
1. 도윤의 거주지는 상류 구역이 아닌 언덕 중턱의 오래된 공동주택 4층이며, 현관 옆 작은 방에 철제 서가와 연도별 기록 상자를 두고 있다. (제안, 제106화)
2. `ARCHIVE / REFERENCE TRUST SUCCESSION REVIEW`는 신체 앵커 연결과 분리된 기록 접근권·실패 아카이브 보존·신탁 관리권의 3년 주기 가족 검토 절차다. (제안, 제106화)
3. 신탁 검토 문서의 공동 보유자 칸 하나는 비어 있으며, 자녀 확인 서명란은 가람과 동생 둘을 합쳐 세 줄로 구성되어 있다. (제안, 제106화)

## 다음 화(107화)로 넘길 상태
- 시간선: 106화(일요일 늦은 오후~저녁) → 107화(월요일 오후, 도윤의 집 작은 기록실).
- 서인은 월요일 오전/낮에 이소현에게 별도 질문지 문구 검토를 전달한 뒤, 오후에 도윤의 집 기록실로 가람을 찾아간다.
- `SUCCESSION ACCEPTANCE: PENDING` 상태 유지, 금요일 저녁에 삼 남매(가람·도준·세아)가 모두 모이기로 예정됨.
- 신발장 위에 봉지째 놓인 도윤의 여분 새 운동화 끈 한 짝 보존.
