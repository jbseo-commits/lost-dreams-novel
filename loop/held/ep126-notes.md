# 제126화 「사본에 남은 것」 미공개 체인 인계

- 주말 다음 월요일 도윤 기록실. 가람이 허용된 두 자료를 열어 준다. 내부 일반 교육발췌는 현장 열람만, 나중 지역 시민교육 강의자료는 공개본이다. 개인 신경기록이나 교육생 답은 없다.
- 두 검색 사본의 같은 ‘거러’는 원문에는 없는 후대 일괄 추출 오류다. 원자료 생성/현재 사본 생성/도윤의 분류 시점은 별개다. 공통 문구·사례·질문 순서가 보여도 직접 전달의 증거는 아직 아니다.
- 공개 강의자료의 ‘사례 제공: 윤태식’ 표시를 찾아 현재 교육 창구에 문의한다. 공개 강의 PDF와 자기 질문만 보냈다. 내부 발췌·도윤 개인 비교 메모를 밖으로 보내지 않는다.
- 처음 담당자는 전달 가능 여부 확인을 약속했고, 끝에서 공개 안내의 표시를 대조해 윤태식에게 질문을 실제 전했다고 회신한다. 윤태식 본인의 응답·설명 허락·만남·자료 전달은 아직 없다.127에서 새로 얻어야 한다.
- 다른 지역 생활 교육자료의 부분 유사는 별도 줄에 둔다. 제공자 표시가 없는 자료를 윤태식 계보로 묶지 않는다. 서인은 공개본과 자기 메모만 가져간다.
- 공개 강좌·제공자·연락 경로·자료 사례는(제안). 한 달 초안HOLD·가족후속검토·비밀/199·200 전용 장치 경계 유지.
