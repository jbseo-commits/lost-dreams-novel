# 제180화 「가장 가까운 적」 미공개 체인 인계 (176~180 구간 종료)
- 일요일 어머니(콩나물): 청산 줄·상자 설명, “도윤 씨가 넣으려는 것 같아요.” → “그럼 나는 첫날 할래. 상자 비어 있을 때.”
- 월요일 기술원: 서인 서면(신청자 확인 사실·확인한 사람·자리). 현오 접수자 소견(출처 우선 원칙과 반대, 신청 관계인=의견 자리 참석자·본인 확인 전). 증거 보존 요청(보관 표지 번호·신청서 접수 번호, 사안 종료 시까지) + 연동 승인 보류 요청(청산망 운영 기관 감사실, ‘접수. 검토 착수.’, 영향받는 사람 청산망 이용자 전원). 보류 서식 참고 양식의 `SUCCESSOR DELEGATION: —`(책임자 공석 시 위임 칸, 운영 기관 내부 규정, 비어 있음 — 198·199 회수 씨앗, 제안). 보류 요청 조건 `CONSENT BEFORE RECALL / NO EXCEPTIONS WITHOUT REVIEW`. 이해관계인 칸 도윤(본인 발언 기준, 등록 확인 전).
- 자녀: 가람 — 새 주석 복사본·상자 표기 사진을 보존에 넣고 이름을 올림, 도윤 목록 셋째 줄 “나는 아직 내가 맞다고 생각한다.”, 청산 줄은 아빠와 같은 날 옆에서, 아빠에게 직접 말함 / 세아 — 자기 이름 기술 이의(처리 순서만), 셋째 날 / 도준 — 이의 안 냄, 맨 마지막 날 상자 확인. 서인 파일 ‘참고’ 칸 “청산 줄 · 어머니 · 첫날, 상자가 비어 있을 때.”
- 밤 장부실 비공개 대면(김밥): “잘했어.” “난 네가 나를 막을 수 있을 만큼 강해지길 바랐어.” 조건 문구 / “그건 답이 아니야. 선택을 미루는 절차지.” / “누가 선택해야 하는지 잊지 않으려고 만든 절차예요.” “애들한테 직접 들으세요.” 11분(다들 기다림·응급 대기, 기록에 있는 만큼). “그 선택까지 지킬 거예요.” “광고꿈만 고르면?” “그것도요.” “넌 너무 오래 기다리는 사람이 될 거다.” “그러려고요.” “놓아주지 못하는 거고요.” 도윤: 철회 안 함, 신청자 의견 제출, 모듈마다 허가·붙이는 방법 여럿(제한된 우회). “넌 내가 네 편이었다는 것도 의심해?” “아니요.” “도윤 씨가 제 편인 거랑, 다른 사람들 꿈 앞에 상자를 끼워 넣는 거는 다른 일이니까요.” “보류가 받아들여지면, 같이 다시 읽어요.” “그때 보자.” “밥은 먹고 다녀.” 끝: 신청인 서인 / 이해관계인 도윤, 한 줄 간격.
- 181~185 인계: 청산 재편 공고·보류 심사·위임 칸, 도윤의 제한된 우회 경로(계약·권한·모듈 호환성), 서인은 권한 중지와 필수 서비스 유지를 함께. 도윤 생존(199에서 서인을 구하고 죽음, 사상 미철회), 세 자녀 각자의 행동. 186에서 서인의 반박(179 보류분). 크레파스 방 ‘지금은’ 회수는 서인 replay 미주입 경계와 맞출 것(작가 판단).
- 검수: 3536 → 3549·누적 2/3·FACT_PASS·편집 각 9/평균 9.00. 연출 미구현·미공개.
