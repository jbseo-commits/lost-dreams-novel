# 제58화 노트 — 여든세 초

## 설계
- 목적: 83초가 한 사람의 몸에 남는다. 원인은 하나가 아니고, 07이 있었다면 달랐을 가능성(61.3%)만 남는다.
- 사건: 02:19 경로 A 전방 사고 정체 → 진출 우회(권고 경로) → 02:51 도착(예정 02:36, +15분). 병동: 2시 33분 발작 악화, 병동 약으로 버팀, 4.1도 냉장 유지된 약 투여, 2시 58분 멎음, 왼손 손가락이 다시 조금 굽음. 보호자 "왜 늦었어요?" 간호사 "길이 막혔대요."(59화 '판단이 늦었습니다'와 대비). 수요일 9시 사후 분석 로그(원인 사슬)와 반사실(07 있었으면 5.1초·B 권고·02:43·61.3%), 신탁의 '본인 통지 여부: 설명한 사람 의견 요청, 금요일 18:00'. 오후 기사 방문("기다린 시간은 그냥 시간", "나는 고른 게 없어"). 저녁 경과(왼손 미세운동 저하, 2주 뒤 재평가) → 서인이 '이상 없음' 카드를 떼지 않고 같은 압정으로 사고 카드를 겹쳐 꽂음.
- 핵심 선택: 서인이 성공 기록을 지우지 않고 비용을 같은 압정에 겹친다. 명진 통지 결정은 금요일로 넘긴다(59).
- 반복 점검: 57(일상+씨앗)과 달리 사건의 몸·원인 사슬·책임 주체 부재. 하경의 공백 남기기 대신 '왼손'. 회색 칸·버튼 미누름·컵 감싸기·메시지 지우기 없음. 도윤 미등장.
- 설계 대비: 설계 사후분석(5.1초/88.4초)은 관측 83초(평소 4~6초)로 통일, 61.3% 유지. 100% 막았다는 서술 없음(39% 언급).

## 새 제안 (작가 확인 전)
1. 사고 타임라인: 02:08 서부 고속화도로 하행 3km 화물차 전도, 02:19 지도 반영, 02:24 진출로 우회(냉장 우회망 합류 권고, 이탈 아님), 02:51 도착(예정 02:36). (제안)
2. 모델 1(A, 빠른 길)·모델 2(B, 냉장 지키는 길) 불일치 → 기준 질의. 풀 응답 3명 모두 A. 풀 참여자는 자기가 무엇을 골랐는지 모름. (제안)
3. 반사실 표: 07 활성 시 5.1초 · B 권고 · 도착 02:43 · 결과 차이 가능성 61.3%. (제안, 설계 수치)
4. 신탁 사후 분석의 '본인 통지 여부: 설명한 사람 의견 요청 · 금요일 18:00 기한'. 통지 안 해도 일일 요약에 '판단 지연 1건'은 남음. (제안)
5. 병원: 서부 2의료원 소아병동에 해당 약 재고 없음, 병동 약으로 버팀, 도착 시 4.1도, 02:58 발작 멎음. 결과: 좌측 손 미세운동 저하, 2주 뒤 재평가. (제안)
6. 기사 단말 기록 '지정 경로 준수', 기다린 시간은 기록되지 않음. (제안)

## 59화 인계
- 금요일 18:00 통지 의견 기한. 서인의 결정은 '알린다, 돌아오라고는 안 한다'(설계).
- 병원 방문: 보호자 "왜 늦었어요?"(이미 간호사에게 '길이 막혔대요'를 들음) → 서인 "판단이 늦었습니다." "누가요?"
- 혁명군 회의(파벌 발언 나열 금지 — 행동·한 장면으로). "0.006퍼센트입니다." "누구의 0.006인데요."
- 코르크판의 겹친 카드, 풀 3명에게 알릴지(하경: 알리면 덜 눕는다).
