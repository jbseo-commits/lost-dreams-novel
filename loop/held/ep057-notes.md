# 제57화 노트 — 0.006

## 설계
- 목적: 떠나도 세상은 돌아간다 → 그 '이상 없음' 위에서 83초가 처음 생긴다. 비용은 처음엔 보이지 않는다.
- 사건: 월요일 장부실 코르크판(재연결/해제 유지)에 서인이 1호·4호 결과를 꽂는다. 풀 5번 남자가 두 칸 사이에 "돌아가는 사람도 있고, 안 돌아가는 사람도 있다. / 둘 다 본인이 정했다." 화요일 명진의 첫 자유(종점, 제일 늦게 나오는 콩국수, "아무것도 안 했습니다." "그게 해 보고 싶었습니다."), 명진은 요약을 열지 않고 "이상 있으면 선생님이 알려 주시겠지요". 수요일 02:11 소아 냉장 의약품 이송 경로 판단 보류 83초 → 경로 A(앞쪽 비상등) → 병동의 아이 왼손. 아침 요약: 처치 영향 확인 중, 질의 칸은 요청자(한명진) 전용.
- 즉시 비용/이득: 명진의 하루 / 풀 남자의 닷새째 밤 / 기사의 83초 / 아이의 기다림. 서인은 '알려 주겠다'는 약속을 진다.
- 핵심 선택: (작은 선택들) 서인이 '이상 없음'을 성공 칸에 꽂는다. 기사는 기록 때문에 확정 전 출발하지 않는다(시스템 규칙이 사람을 묶음). 서인이 명진에게 알리겠다고 약속.
- 마지막 여운: "83초." 52화 18초 '처치 영향 없음'과 대비되는 '확인 중', 그리고 질의 권한이 명진에게만 있음 → 59화 '알릴 것인가'의 토대.
- 반복 점검: 56(결정·자정)과 달리 결정 없는 일상과 사고의 씨앗. 52의 알림/질의 칸을 의도적으로 회수(이번엔 쓸 수 없음 — 버튼을 안 누르는 것이 아니라 권한이 없음). 서명·냉장고·컵 감싸기·메시지 지우기 없음. 도윤 미등장(60화 대비). 100·200화 컵라면 보호를 위해 기사 소품은 누룽지 종이컵.
- 설계 대비: 설계의 "4~6초 → 83초", A 고속도로/B 냉장 우회망 유지. 아이의 손(58화 후유증)은 손가락이 움찔하는 것까지만. 사고 결과는 58화.

## 새 제안 (작가 확인 전)
1. 장부실 코르크판(설명회 판 재사용) '재연결 / 해제 유지' 두 칸. (제안)
2. 07 일일 요약: 밤 단위로 다음 날 아침 수신(본인·설명한 사람). 질의 입력은 요청자(본인) 전용. (제안)
3. 풀 5번 남자: 석 달 유예 서명지를 버리고 11명에게 사과, 셋이 다음 주 풀 신청 예정. 꿈 없음, "남의 집에서 자고 나온 것 같아요". (제안)
4. 명진: 장부실 앱 없음(종이 확인서), 회사 식당 19년, 요약 알림을 열지 않음. (제안)
5. 냉장 물류: 도시 서쪽 끝 냉장 물류창고, 기사 쉰쯤·12년, 냉장 건은 경로 확정 전 출발 시 기록(온도 책임, 다음 달 배차 제외). 소아용 주황 띠. 경로 A 서부 고속화도로 24분 / B 냉장 우회망 31분. (제안)
6. 서부 2의료원 소아병동, 아이 일곱 살쯤(왼손, 해열 패치), 보호자 여자. (제안)
7. 기준 질의 → 분산 참조풀 응답 대기로 경로 판단 83초(평소 4~6초, 설계 수치). 풀 응답 3/5 · 미입면 2(야간 근무 1, 미취침 1) — 지연은 개인이 아니라 구조. (제안)
8. 07은 표준안 신청 4호, 요청자 = 한명진(본인). 서인은 '설명한 사람'으로 07 일일 요약을 수신하나 질의 입력은 없음. 서식 사본(세 번째 장 포함)은 하경이 서인에게 보냄. (제안)
9. 명진은 해제 주간에 휴가(19년 미사용 연차). (제안)

## 58화 인계
- 앞쪽 비상등(야간 사고) → 경로 A가 막힘 → 우회 전환 → 도착 지연 수분. 아이는 죽지 않음, 왼손 미세운동 후유증 가능성.
- 사후분석 반사실(설계: 5.1초 vs 88.4초 관측, 61.3%) — 57화 원고는 83초(판단 소요)로 썼다. 88.4초를 쓸 경우 '단말 표시 83초'와 '전체 판단 88.4초'의 구분 필요. 단순화 권고: 관측 83초로 통일.
- 서인은 요청자 권한이 없음 → 하경/작성팀 경로로 로그 추적, 명진에게 알릴지 문제.
- 풀 응답 3/5 · 미입면 2 — 특정인에게 책임을 씌우지 않는다(설계 원칙 1·2). 58 사후분석은 '관측 83초 / 평소 4~6초' 기준.
