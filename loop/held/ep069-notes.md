# 제69화 「누구의 성공」 설계 노트

## 목적
- 시범 28~29일째. 다섯 쪽이 같은 데이터를 각자 '성공'으로 읽고(전부 사실), 운영국 빨간 줄이 같은 사실을 비용으로 읽는다. 위원회가 요구하는 '종합 판정 한 줄' → 66 첫 주 다툼이 '첫 줄' 다툼으로 귀환.
- 압박: 판정 한 줄이 넓힐지 접을지를 정한다. 선택: 서인은 판정을 '30일째 주민 선택 결과로 갈음' — 광고꿈 재가입도 판정에 들어간다(비용: 위원회 절반은 실패로 읽음, 윤세라 경고).
- 주제 질문 하나: "뭐가 좋아져야 성공인데?"(도윤). 답 없음, 도윤도 모름.

## 장면
1. 28일째 오후 약국 앞 — 68의 아이 업은 남자, 엿새 만에 "괜찮대요". 67 약국 종이('시범 끝날 때까지 계속')를 보고 "끝나면 없어져요?"
2. 28일째 밤 장부실 — 검은 줄/빨간 줄. 키 큰 여자 "부분 성공이라고 써요. 내 줄 때문에." 빨간 줄에 처음 생긴 검은 동그라미. 윤세라: 위원회는 30일째 아침 한 줄. 첫 줄 다툼, 하경 가나다순(자기 회복이 맨 뒤) → 상인회 여자 "그렇게 뒤로 가 버리면 앞에 선 사람이 뭐가 돼."
3. 도윤 국밥(지하 계단 위, 화단 턱) — "자유로워진 사람이 다시 광고꿈 켜면?" 어머니 "달걀 사야 된대요" → "그 말은 좋다."
4. 그날 밤 30일째 선택 안내문 — 항목별 선택, '고르지 않으면 지금 그대로'(기본값 문제를 지우지 않고 '언제든 다시 바꾸실 수 있습니다' 추가).
5. 29일째 노인정 — 안내문은 우편함으로(문에 붙이지 않음: 68 편집 경고 반영). 김 영감 "안 고르는 것도 고르는 거네." 윤 여사는 접어 방석 밑에. 판정 칸 → 윤세라 문답. 9시 윤 여사·어머니 귀가(방석·종이 그대로). 9시 반 순덕 "적어 줘. 좋아서 켰다고." 서인 "하나 적으면 다음엔 물어야 돼요. 안 적은 사람한테도요."(66 '묻는 순간 거절하는 사람이 설명을 해야' 원칙). 순덕이 안내문 뒷면에 직접 '좋아서.' → 담요 가운데. 김 영감이 판을 한 뼘 옮김. "세 글자는 판 밖에 남았다."

## 연속성 메모
- 대기: 첫날 사흘(김 영감) → 평균 6일(68) → 빨간 줄 '사흘에서 엿새로'. 남자 결과 '엿새 만에', 약국에서 본 지 '보름 전쯤'(68=보름째, 69=28일째 → 13일 전).
- 분산 풀 이탈: 68 한 사람 예고 → 69 '두 사람'(제안: 한 명 추가 이탈).
- 판정 시한: 30일째 아침. 서인 "내일 밤까지 쓸게요" = 29일째 밤 제출.
- 도윤: 서인→도윤 존댓말, '도윤'. 형 호칭 없음.
- 숫자: 7퍼센트(키 큰 여자) 하나만 정밀 수치. 나머지는 말 단위.

## 연출 (pilot.html `inks`)
- 장부실 화이트보드: 검은 줄·빨간 줄이 번갈아 쌓이고, 맨 아래 빨간 줄 '분산 풀 이탈 · 두 사람'에만 검은 동그라미. 판정 칸 '30일째 주민 선택 결과로 갈음.' 마지막에 보드 밖에 손글씨 '좋아서.'
- 새 문법: 두 색 잉크 장부(66 twopaper·67 rail·68 cushion과 겹치지 않음). 본문에 없는 사실 없음.
- 400px 검사: 넘침 없음(sw 400), 콘솔 오류 없음, 닫힌 뒤 터치 정상.

## 새 제안 (작가 확인 전)
1. 위원회 '종합 판정' 한 줄 형식(성공/부분 성공/실패), 30일째 아침 제출, 조정자 작성. (제안)
2. 분산 풀 이탈 누적 두 사람, 기준자 부담 7퍼센트 감소. (제안)
3. 30일째 선택 안내문: 항목별 선택, 미선택 시 현행 유지, 언제든 변경. 우편함 배포. (제안)
4. 서인의 판정: 30일째 주민 선택 결과로 갈음(재가입 포함). (제안)
5. 도윤 국밥(지하 클리닉 건물 앞). (제안)
