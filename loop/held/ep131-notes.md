# 제131화 「앞장을 고르는 사람」 미공개 체인 인계

- 화요일 건물운영에 별도대여를 다시 문의한다. 목요일19~21시 정원6명 작은방을12TOKEN에 예약,서인/우석각6씩자기부담결제했다. 기존큰설명회/선우의조건부설치도움은확보하지않았다. 우석사전책상이동,서인종이/필기구·종료후복구담당,앞뒤15분씩빼읽기시간은19:15~20:45의90분이다.
- 우석이소현에게전화해소리를키우고서인과함께듣는다. 소현질문정리마감은화요일오후,목요일은다른일정으로불참이다. 맡긴범위를모집/설치노동으로넓히지않는다.
- 저녁서인/우석이도윤집에서세아를만난다. 세아는자기연구소검토회의목록정리전30분만허락한다. 도윤은자기교육사본의일반진행지시만현장비교로열고집에남긴다. 개인답/다른수강생로그를열거나밖에전하지않는다.
- 반복판단교육형식과현재질문지가닮았지만목적/답을못냈을때결과/고칠기회도다르다는세아반론이남는다. 직접전승/교육악/자녀사상주입·유년나이/replay범위를새확정하지않는다.
- 서인/우석은세편을한편(생활선공개의견서)으로줄이고유지하고싶은것→불편한조건/비용으로질문순서와시간을정한다. 진행자가고른순서임을안내하며재독/생활/이전영향이섞이므로통계적실험결과로보지않는다. 외부용은공개원문+자기질문지만,태식한정설명/복사본·내부발췌·비공개답/라온인용제외.
- 성인두사람에게목요일읽기준비자리안내를보냈다.한사람은초기혼자읽기/전부말하지않아도됨을답받고참석확인,다른한사람은아직미답.132에서두번째참석응답을새로얻어야한다. 운동가입/지지약속은아니다.
