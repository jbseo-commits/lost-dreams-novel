# 제176화 「누가 이 역사를 썼나」 미공개 체인 인계
- 월요일 도윤 집 작은 기록실. 도윤이 175 목록 첫 줄에 “넘어지지 않게.”만 씀. 가람이 FAILURE ARCHIVE의 서로 다른 세 기록(남부 정수장 배급 순번·야간 교대 거부 행진·공동 수면실)을 나란히 놓음. 색인(도윤 후대 분류층, 124에서 이미 앞뒤를 바꾼 걸 함께 봄)이 모두 세 칸: 대신 정했다 무너진 사례 / 버틴 사람이 잃은 것 / ‘참고’. 원문의 소규모 자기결정(약병 제비·늦게 합류한 사람의 골목·석유난로 당번)은 ‘참고’로 밀림. “쓴 사람이 다 다른데 남길 순서를 정한 사람은 하나.” 가람 교육 목록도 같은 칸.
- 가람: 107 청색 폴더의 옛 G.R. NOTE(예측 과다) 뒤, 정수장 색인에 새 주석 ‘사례 배열 원문과 다름. 맨 아래 칸 재검토.’ 도윤이 점심 국수 때 읽고 “맞다.”
- 서인 파일(`외부 관찰 · 비개인화 · 본인 열람 가능`, 자녀 파일 다음 칸): 도윤이 건넨 자료 목록, 같은 세 칸, ‘참고’만 비어 있음. 서인이 70화 윤 여사 장면을 직접 기입(그날 서인이 먼저 권한 건 큰 버튼). “맞는 걸, 이 순서로 줬어요.” “다르게 묶어 본 건 한참 뒤… 처음 판단은 이걸 받은 대로 했어요.”
- 도윤: 파일 요구 없음(“그럼 네 거지”), 빈 칸 얘기는 “날은 네가 잡아.”로 서인에게 넘김(178). 형제 단체방: 세아 날짜 요청, 도준 “난 안 봄. 맨 아래 칸 뭐였는지만 나중에.” 끝: 세 상자 옆면·가람 목록·서인 파일 표지 안쪽에 `D.Y. / GENERATIONAL CONTINUITY.`(연도 몇 해에 몰림, 의미 미확정).
