# 제52화 「모래가 붙는다」 — 보류 노트 (2026-10-08)

- 상태: 글 검수 진행 중 · 연출 보류 · 공개 대기. 51화(`ep051-standard-one-20261008.md`) 다음.
- 연출 설계안(보류) — **sandsticks**: 발바닥 실루엣 위로 모래 점이 떨어져 '붙는다'(남는다). 같은 화면 왼쪽 위에 흐린 광고꿈 바다 카드 "모래가 발에 안 붙어"가 떠 있다가 사라짐. on: "붙네.", KEY: "몰랐어."
- 새 제안(작가 확인 전, settings/05 미등록):
  1. 요청자 알림: 풀 지연을 전일 집계로 요청자에게 알림. 요청자 전용 '환자 정보 열람' 버튼과 질의 입력 칸(사람이 답함). 환자 정보 열람은 51 notes 4번의 '참여자 번호 화면 열람'과 별개 권한.
  2. 표준안 신청 2·3호(대기): 둘 다 선임, 계열 09·11. 풀 참여자 5명 추가 대기.
  3. 표준안 요청자 칸 수정: '본인 또는 가족', 서인은 작성자 공동 수신. 서식 수정 이틀, 2·3호 이틀 지연.
  4. 장부실 벽 '앵커 해방' 종이 신설(49화에는 없었음).
  5. 구청 접이식 휠체어 일주일 대여, 김 영감의 덮는 담요 대여. 할머니가 모래 위를 몇 걸음 걸음(51 notes 8).
  6. 하진의 어머니는 실제 바다에 가 본 적이 없다. 서인 어머니는 광고꿈 바다를 "너무 깨끗해" 싫어한다.
  7. 도윤과 9층 가족의 첫 대면(하진 "도윤 씨죠. 얘기 들었어요.").
- 반복 경고(편집 검수): 서명란 앞에서 펜이 멈추는 장면(48·51·52), 서인이 이름 알기를 거절하는 장면(50·51·52)은 53~55화에서 쓰지 않는다.
