# 제186화 「열리지 말아야 할 문」 미공개 체인 인계
- 금요일 새벽 서부 권역 회복 센터(1시 반부터). 로그 `LEGACY CONTINUITY PATH / FAIL MODE: OPEN` / `PRE-CONSENT STABILIZATION (CONTINUITY EXCEPTION)` / `ASSOCIATION PRIMER ACTIVE` / `SOURCE TAG DELAYED` / `CONSENT ROUTER: PENDING — 4m 12s`. 세아 “예전에 우리가 잰 건 사본이 확인받는 데 늦는 시간이었어요. 이건 늦는 게 아니에요. 기다리게 만들어 놓은 거예요.” “모릅니다.” 야간 운영자 1시 넘어 ‘응급 재활 복구’ 승인(양식). 실행 권한 서명 = 외부 연구 협력 계정. 185 ‘범위 다툼 계속’ = 틈. 세아 “사람은… 서인 씨가 물어봐 줘요.”
- 서인 7시 실행 권한 정지 청구(이미 돈 건 못 멈춤), 접수 번호를 184 동남 메모 줄 아래. 도윤 “사고 아니야.” “내가 정했어.” “서부 센터. 가람이한테는 문자 보냈어.” 11시 정지 발효, 이후 새 실행 없음.
- 범위표: 서부 대기자 쉰 명쯤 중 연결 서른 남짓, 가족 경로 미확인. 기술부 “운영자가 속은 게 아니라, 양식이 그걸 허락한 거예요.” 정지윤: 자기 센터 무영향, 185 신청 어머님 아침에 딸 이름 한 번에(프로그램 다음 주 시작, 무관). 가람 “서인 씨한테 먼저 들으라고.” “청산 줄은 같이 설 거예요… 오늘은 아빠 얼굴 못 보겠어요.”
- 밤 서부 센터 대기실: 무증상 아내·불면 남편, 이어폰 청년(무증상, “엄마가 가 보래서요” — 187 C 후보), ‘원래대로 돌려놓으라’ 남자(189 씨앗)와 의자 바로 놓는 노인, 작업복 남자(마흔쯤, 기름때, 번호표 뒤 줄과 점 — 187 A) “난 처음으로 내가 뭘 원했는지 생각났어요.”
- 3층 B(쉰쯤, 어머니 돌보며 인지 공급한 보호자, 새벽에 어릴 적 집 얘기하며 웃다가 숨 가빠짐·불면, 진정제 거부): 도윤 아침부터(가족 아님), 물수건, 셔츠 자락으로 이마(공개 45). “누구세요.” “아는 사람이에요.”(B는 도윤을 모름 — 187에서 정리)
- 복도 대치: “도윤 씨가 그랬잖아요. 꺼내는 사람이 대답하기 전에 이미 반은 정한 거라고.” “기억해. 그래서 아무도 안 꺼냈어. 떠오르게만 했지. 문도 안 잠갔고.” 쉰 명 vs 다른 센터 열한 명. “넌 기간을 정해서 잠그려고 했잖아.” “네. 저는 잠그려고 했어요.” 제한→유예→최소 회복기간. 창밖 붉은 접속 패치 충전 표시등. “넌 저 사람들한테 뭘 줬는데. 기다리라고?” 서인 무응답(메모의 접수 번호). “그날 도윤 씨가 제 이마 닦아 준 거, 진심이었죠.” “지금도 진심이야.” 자판기 생수 → B 머리맡, 뚜껑 닫힌 채.
- 187 인계: A(작업복 남자, 음악)·B(보호자, 치료·기록 삭제)·C(무증상 청년, 양쪽 홍보에 분노) 증언 보존, 피해자 한 종류로 묶지 않음. B에게 출처(돌봐 준 사람이 결정자) 알릴지.
