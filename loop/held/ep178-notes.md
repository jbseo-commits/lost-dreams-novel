# 제178화 「나를 고른 사람」 미공개 체인 인계
- 목요일. 아침 어머니: 큰 판단 뒤 왼쪽 관자놀이를 누르는 버릇, “병원 갈지는 네가 알아서 해. 근데 아픈 건 나한테 말해.”
- 지하 2층 장부실(출근 전), 하경 책상 옆 캐비닛의 봉투. 본인 열람 시술 기록: `성격 반응 조정 1단계 / 대상: 판단 전 재확인 행동`(11화) + `요청 · 도윤` / `범위 지정 · 판단 지연만. 인지 내용 비접촉.` / `본인 동의 · 서명 확인` / `측정 · 재확인 지연 평균 0.8초 → 목표 · 지연 제거`. 하경 손글씨 반대 의견(냉각 부담·장기 추적·열일곱 중 중단 다수), `추적: 본인 요청 시. 요청 없음.` 하경 “적기만 했어. 손은 내가 댔고.” “그때 네가 물었을 땐 안 알려 줬지… 그 뒤로 네가 다시 안 물었고, 나는 그걸 핑계로 삼았어.” “네가 수술 중에 뭘 봤는지는 기록 밖이야.” 추적 요청 여부는 서인이 나중에 정함.
- 가람 사진: 도윤 이름 줄 둘째 줄 “같은 데서 넘어지는 걸 너무 많이 봤다.”
- 클리닉 옥상 환기구(30·49). “제 머리, 도윤 씨가 만든 거예요?” “네 재능을 만든 적은 없어. 하지만 네가 다시 확인할 시간을 지우는 데 내가 관여했어. 범위도 내가 정했고.” 하경 반대를 “보고도 했어.” 의료실 값(30) “그거랑 이건 따로야.” 열두 명 “다 찾아가 봤어. 문 열어 준 집보다 안 열어 준 집이 많았다.” 크레파스 방(11화): 서인이 하경 말을 전하자 “그렇겠지. 나한테도 그건 기록 밖이야. 지금은.”(열린 질문 — 서인 replay 주입 없음 경계 유지). 이유: 대신 생각해 주지 않는 머리가 같은 데 도착하면 “내가 틀리지 않았다는 뜻”, “난 네가 스스로 답을 찾길 바랐어.” “도윤 씨가 먼저 골라 놓은 질문에서요.” “도윤 씨 답을, 제 입으로 듣고 싶으셨던 거네요.” 125 재배열 날 “다행이라서. 그리고 무서워서.” “지금도 둘 다.”
- 보여 주지 않은 회색 파일(기숙사 소등 투표, 공동 냉장고 열쇠 끈) “쉬운 게 아니거든… 그래도 갔던 데가 있어.” 마지막 장 지난주 날짜 `RECOVERY ACCELERATION / MEMORY CONTINUITY` / `연동 검토 요청 · 접수 완료`. “그건 다음에 물어. 하나씩.” 서인이 도윤 얼굴을 일부러 두 번 봄.
- 179 인계: 이 공문의 실체(도윤 현재 계획, 청산망·회복 지원망 연동 승인 절차)를 서인이 파악. 160에선 연구 소개 제목일 뿐이었음. 전국 적용 미실행.
- 검수: 최초 3548 → 최종 3553·누적 2/3·사실 FACT_PASS·편집 각 9/평균 9.00. 연출 미구현·미공개. 작가 판단: 크레파스 방 ‘지금은’.
