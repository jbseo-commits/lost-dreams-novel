# 노선 교체로 보류한 원고 (2026-10-07)

제36~50화를 새 노선(TOKEN 전쟁·앵커 인간화·1부 마무리)으로 다시 쓰면서, 옛 47~50화의 사건(회색 문, 이름표, 704호 이름 등)을 잇던 아래 원고를 공개 목록에서 내리고 이곳에 보존한다. 작가 승인(충돌 처리안).

- `ep051.md` 「금요일의 끝집」, `ep052.md` 「토요일의 셈」: 옛 50화 「목요일의 이름표」 뒤를 잇는 본편.
- `ep047-1.md` 「거꾸로 읽은 장부」, `ep048-1.md` 「문 잠가 달래요」: 옛 47·48화 위에서 쓴 인물 범퍼.

새 노선에서 다시 쓸 때 인물·장면·대사를 재료로 쓸 수 있다. 그대로 되살리면 새 46~50화와 사건이 충돌한다.
