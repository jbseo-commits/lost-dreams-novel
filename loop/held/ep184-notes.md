# 제184화 「누구의 몫인가」 미공개 체인 인계
- 화 새벽 지우: 동생 답 “같은 데 하나, 다른 데 하나”, 다른 데가 더 마음에 들지만 원서 그대로, 내년에 또 물음. 서인 엄지.
- 화 오후 청산위원회 공고(수 16시 시청 대회의실). A 시장 우선 / B 전면 긴급 배급(부속서 기준자 연결 의무 연장) / C 회복 우선(연합 + 외부 연구 협력 계정) / D 필수 보장·공개 재검증 하한·비필수 누진 비용·개인별 철회권(183 조서 두 마디 + 그날 밤 세아와 정리한 네 항목, 제안자 서인). 어머니 방청.
- 화 밤 `북부 냉각 용량 18% · 예약 확정 대기 · 확정 시각 수요일 18:00.` 예약자 = 182 단가 인상 사업자, C 지지 성명. 열파 해지 순서(동부 공공 병원 단가 고정 계약 먼저, 고급 비필수 끝까지) “이 회사는 급하면 공공부터 놓아요.” 세아 경고(교대 근무 대표) → 서인 “사무국이 통지할 거예요.” 일정 변경 → 수 8시 통지, 10시.
- 수 10시: 동남 권역 대표 불참(밤새 정수장 근무, 8시 통지 수면 중). A 경제학자 “대체로 돈이 덜 있는 쪽입니다.” + 작은 검증소 남자. B 구청 재난 담당 “비상이 끝날 때까지는 어렵습니다.” C 도윤(원고 없음, 가람 셋째 줄) + 연합 담당자(딸 이야기), 노인 “잃어버린 게 없으면?” “그럼 끄시면 됩니다. 다음 날 바로요.” “부자는 틀릴 기회를 삽니다. 가난한 사람은 처음 나온 답을 운명이라고 배웁니다.” 서인 “도윤 씨 말에 동의합니다.” “그래서 누구도 남의 첫 질문을 대신 정하면 안 됩니다.” D 불완전, “제일 덜 나빠서요.” “두 번째는 얼마예요?” “아직 몰라요.”
- 하진의 어머니(앵커 가족 대표, 9층 식탁 사과, 현역 기준자, 얼마 전 계속 동의): B 부속서 반대, “이 표대로면 우리 집한테는 그 둘 중 하나예요. 둘 중 하나만 고르라는 표는 찢겠습니다.” 견본 찢음 → 수정 동의. “오늘은 제 차례라서요. 할머니 곁에 있는 건 하진이 차례고요.”
- 의결: D 한시 승인(지역별 검증·재정 재심사), B 기준자 의무 부속서 삭제, C 부결, 기존 계약 경로는 대상 아님(서부 예비 경로 잔존). `북부 냉각 용량 18% · 예약 일부 철회 · 9% 공공 계약 전환.`
- 도윤 “잘했다.” “냉각은 네가 맞혔어.” “동남 권역은 봤냐.” 가람 “어젯밤에 혼자 몇 번 했어요. 부엌에서.”
- 비용: `동남 권역 · 비필수 재검증 하한 적용 · 지역 검증 미완료로 1주 연기.` 대표 “다음엔 하루 전에 주세요. 그럼 가요.” 어머니 “그 여자 잘하더라. 찢는 거.” “너는 왜 안 찢었어?” 통화 기록 맨 위 동남 번호. “두부 사러 가자.” 메모 `동남 권역 · 1주 · 내가 당긴 시각.` 맨 위 고정(191~195 씨앗).
- 185 인계: 필수 경로와 회복 replay 경로 제한적 분리, T0/T1 유지, 자발적 회복 존중, 도윤 대화(‘도윤 씨’), 대시보드 `LEGACY CONTINUITY PATH: ACTIVE / SCOPE DISPUTED / FAIL MODE: OPEN`, 세아 “막은 건 가격표예요. 그 아래 계약은 아직 남았어요.” 서인 과부하 전조(단위가 잠깐 의미 없음, 아무도 모름). 186 강제 복원 미실행.
