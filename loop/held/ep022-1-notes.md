# 제22-1화 「청원 버튼」 보류 노트

- 상태: 2026-10-06 보류. 독자 공개 대상에서 제외하고 `loop/held/`로 이동.
- 사유: `loop/BUMPER-CONTINUITY.md` 생성 게이트 4항 미충족. 23화 본편이 이미 2~5문장으로 필요한 정보를 모두 담고 있다.
  - 57분 지연 전파: 23화 본편이 "22화 시범에서 제4 검증이 57분 늦어진 사실이 알려졌고"로 스스로 서술.
  - 서인의 질의 명단 등재: "질의 응답 명단에 서인의 이름도 들어갔다" + 백윤하 "직원들이 요청했습니다".
  - 팀 평균 표시가 소규모 팀 압력으로 이어지는 구조: "팀 평균이 실시간으로 보이니까 소규모 팀은 추정할 수 있습니다".
  - 거부자의 설명 강요: "참여하지 않는 이유를 왜 동료들에게 증명해야 하는지 모르겠습니다"와 6항 신도시그라프가 이미 존재.
- 추가 결함: 6항 연속 독서 검수 위반. 범퍼를 읽으면 23화의 신고 장면(아이 검사 일정인이 "혹시 모르니까요"로 버틴 대목)이 예감으로 바뀌어 충격이 희석된다.
- 작성 과정의 문제: 개연성 판단을 작가 설정에 맞춘 우주적 근거에서 출발했다. 사용자 지적("아무것도 모르는 독자가 이걸 읽을 때 서인이 말이라서 믿는다는 건 개연성이 없다")은 맞았으나, 23화 본편이 이미 그 근거를 독자에게 주고 있었다. 원고를 먼저 읽어야 했다.
- 검수 기록: 4-1 전부 통과, 4-2 전 항목 9·평균 9.0. 점수는 통과했지만 게이트 미충족 판정이 우선이다. 검수는 글만 평가하고 존재 이유를 평가하지 않는다.
- 보류 원고는 분량 3667자, 제목·첫 줄 형식 정상. 되돌릴 때는 `scripts/build-manifest.mjs`의 HIDDEN 처리와 `pilot.html`의 `BUMP`/`D` 항목을 함께 정리해야 한다.
- 생성 규칙: `settings/05-open-questions.md`에 사유 등록. 새 범퍼 생성 전에 4항을 먼저 확인한다.
