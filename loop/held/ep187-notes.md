# 제187화 「내가 원했던 것」 미공개 체인 인계
- 토요일 아침 8시 3층 침대 옆 의자 빔, 도윤 새벽 6시 떠남(물 한 번 더, 수건 개어 둠). 감사실 담당자가 같은 층 상담실에서 독립 조사 진술(원하는 사람만, 녹음은 허락 시). 서인 청구인 입회. 원칙: 무엇이 켜졌는지 먼저 말하지 않음.
- A 장상철(마흔쯤, 공구 공장 야간조 십육 년, 입사 때부터 광고꿈): 새벽 4시 기타 줄 누르던 손가락, 스무 살 밴드, 기타 팔았음 → 어제 아침 퇴근 후 중고 기타, 어젯밤 처음 광고꿈 끄고 줄 갈기(손끝 까짐, TOKEN 덜 들어옴 = 줄 값), 야간조 미정. “동의 안 한 건 맞아요. 근데 지금 이 마음도 내 거예요.” 원상복구 반대. “청구 낸 사람이면, 이거 뺏을 거예요?” 서인 “저는 안 뺏자고 할 거예요.” 번호표 오선 사진 기록.
- B 오영란(쉰쯤, 어머니 십 년 돌봄·인지 공급, 휠체어, 녹음 거절): 마당 있는 옛집 → 어머니 쓰러진 날 반복, 숨 막힘. 어머니는 동생이, 공급 이틀째 멈춤(약값). 치료 + 기록 삭제(조사 후 본인 요청). 서인(담당자 동의) “그분이 이 일을 정한 사람이에요.” “그게 이거를 지워 주진 않잖아요.” 담당자 “떠오른 기억 자체는 영란 님 거예요.” “내 마음이라고 해도, 누가 허락 없이 건드렸잖아요.” “그 사람, 벌 받아요?” “그거 말고요.” 생수는 아침에 목말라 땄음.
- C 경민(스물셋, 무증상, 엄마 권유): 게시판 `서부 센터 서른 명이 깨어났다. 잃어버린 꿈이 돌아왔다.`(도윤 지지 모임) / `서부 센터 서른 명이 머릿속을 침해당했다. 원상복구하라.` 엄마 전화 무시. “난 아무것도 안 느꼈는데 왜 자꾸 내 이름으로 말해요?” 숫자에서 빼 달라 → 본인 진술(무증상) 첨부.
- 대리 진술 남자: 아내 대신 원상복구 → 본인 진술 원칙. 아내 “남편이 그러라면…” “남편분 말고, 선생님 생각이요.” “다음 주에 제가 직접 갈게요. 혼자요.”
- 피해 유형 칸 대신 파일 이름 = 각자 한 말: `지금 이 마음도 내 거예요.` / `누가 허락 없이 건드렸잖아요.` / `왜 자꾸 내 이름으로 말해요.` 세아 “아빠한테 보여 줘도 돼요?” “그분들한테 먼저 물어봐야죠.” 컵 세 개(빈 것·반·손 안 댄 것) 서로 닿지 않게.
- 188 인계: 합동대응팀 일괄 역프라이밍 제안, 서인 거부, 상철 음악·영란 치료·경민 무조치 모두 허용, 응급 최소 예외 유지, 대응 지연 비판. 이름 확정 전 한 글자 차이 검색(scratchpad namecheck).
