# 제63화 노트 — 알아

## 설계
- 목적: 강제는 나쁜 부모나 잔인한 제도에서만 생기지 않는다. 완벽에 가까운 좋은 부모 아래서도 아이는 같은 방향으로 기운다.
- 사건: 금요일 저녁 계열 10 현역 이현주(현수 동생, 마흔쯤) 집. 거부 쪽만 준비된 서류철(나래 명의 별도 TOKEN 계정·독립 비용·외부 변호사 거부 절차 상담 예약 — "이거, 제가 열아홉 살 때 받고 싶던 거예요"). 서인이 서식을 읽다 현주가 "세 번째 장은 빼 주세요"(연장 예상 줄). 서인은 따른다. 나래 "세 번째 장 왜 안 읽어요?" → "네가 안 해도 우리 괜찮아." "알아." "진짜로." "알아." → "몇 년." → 현주가 직접 "5년 11개월." "그건 내가 정한 거야." 밤 10시 나래가 "엄마, 시간."(아무도 시키지 않은 집행). 자정 무렵 나래가 신탁 앱 사전 신청서를 연다. 이름은 이미 채워져 있고, 참여 형태는 하나뿐, 시작일은 비어 있다.
- 앞머리: 하진 보류 2회차 만기 → 3회차 보류. "이제 거부해도 엄마한테 가는 거 없잖아요… 그런데도 못 누르겠어요." "누가 안 된다고 한 것도 아닌데." (48화 '이제 거부를 눌러도 어머니에게 가는 것은 없었다' 회수; CURRENT-LINE 미처리 항목 처리)
- 즉시 비용/이득: 나래는 숫자를 엄마 입으로 들음(현수 "그거 하나요"). 현주는 서류철 20년을 처음 남에게 보임. 서인의 배려(세 번째 장 생략)는 막지 못함.
- 핵심 선택: 서인이 세 번째 장을 읽지 않기로(부모의 요청 존중) / 현주가 숨기지 않기로 / 나래가 신청서를 열기로(아무도 시키지 않음).
- 마지막 여운: "엄마는 11시에 이미 연결돼 있었다." 설계의 '악역 음악 금지 — 그냥 가족의 저녁' 유지.
- 반복 점검: 서명 망설임·버튼 안 누르기 없음(신청서는 열기만, 누르지 않는 장면을 결말로 쓰지 않고 '이미 채워진 칸'과 '하나뿐인 형태'로 끝냄 — 검수 확인 요청). 메시지 쓰고 지우기 없음(나래는 배를 그리고 지우지 않음). 냉장고 모터 없음(냉장고 문 달력은 소품). "네가 정해"(200화 최종 문장) 회피 — 하진의 어머니는 말없이 사과만. 도윤 미등장. 숫자: 5년 11개월(핵심 하나), 10년째·2년쯤·열아홉/열여덟/스물(나이·대략), 23:00 달력 1회, 10시·11시.
- 64 인계 씨앗: 참여 형태 칸 '완전 참여' 하나뿐 → 64 선택지 확대 실험.

## 새 제안 (작가 확인 전)
1. 이현주: 계열 10 현역, 마흔쯤, 동쪽 신도시 고층 아파트(현역 가구 지원 — 주거·관리비). 남편(말수 적음), 딸 이나래(스물, 설계 전공). 콩자반만 먹음(10년째), 젓가락 끝 미세 떨림, 다음 달 달력에 23:00과 정기 점검뿐. 밤 10시 취침 준비, 11시 연결. (제안)
2. 현주가 나래 출생 주부터 '거부 쪽' 서류철 준비: 나래 명의 별도 TOKEN 계정(열여덟 생일), 거부 시 독립 2년 비용, 신탁 외부 변호사 거부 절차 상담 예약(상담 전날). (제안)
3. 신탁 서식 구성: 첫 장 참여(중첩 동기화·현역 가구 지원·교육/의료 우선), 둘째 장 보류·거부(거부 시 본인 불이익 없음), 셋째 장 맨 위 '현 기준자 연결 연장 예상'. (제안)
4. 현주 연장 예상(나래 거부 시): 5년 11개월. (제안, 설계 수치)
5. 신탁 앱 '상담 전 사전 신청': 신청서 맨 위 '후보 1순위 · 이름' 자동 기입(수정 불가), 참여 형태 '완전 참여' 단일, 시작일은 빈칸(넛지 장치 없음 — 편집 검수 반영). (제안)
6. 하진: 보류 2회차 만기 상담(만기일 직후 일정으로 잡힘)에서 3회차 보류(보류 최대 180일 이내). 담당자가 '거부해도 현 기준자 영향 없음'을 다시 읽어 줌. 어머니는 말없이 사과를 깎음. (제안)

7. 서식 열람: 보호자 요청으로 설명한 사람이 특정 장 낭독을 생략할 수 있으나, 본인(후보)은 앱에서 셋째 장까지 직접 열람 가능(38화 하진 화면 열람과 정합). (제안)
8. 현역 가구 아파트: 로비 카드 인증 엘리베이터, 방문 카드. 나래 독립 2년 비용은 서인 한 해 소득보다 많음. (제안)

## 64화 인계
- 선택지 확대 실험: 참여 형태가 하나뿐인 신청서 → 장부실·혁명군 여러 파·신탁(오정택)과 중간 선택지 시범(완전/단기/저강도/분산풀/TOKEN 대체/거부). 실제로 선택이 다양해짐(일부 성공). 그러나 부담 총량은 남는다. 생활파 인물 "부담을 고르는 방법이 늘어난 거죠."
- 나래의 상담(다음 주) — 선택지가 늘어난 서식을 받는 첫 사람 후보.
- 풀 소등 시각 당김(하경 예측 '9시 반') 한 줄.
- 아이 왼손 2주 재평가는 65.
