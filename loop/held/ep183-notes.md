# 제183화 「합법적인 우회」 미공개 체인 인계
- 월요일 감사실 열람실 병합 심사(정지 청구·목요일 밤 변경 요청·기술 이의). 원 계약 맨 아래 근거 조항 `CONTINUITY EXCEPTION`: 인지 공급이 끊기거나 줄 때 필수 의료 재검증·회복 지원 같은 우선 경로. 오래전, 옛 기관 직인, 공급 끊긴 해 제정(사건 미특정), 응급 대기 감소 기록 — 정당한 조항. 감사실 담당자 어머니 금요일 또 밀림 “필수가 먼저인 건 맞다”.
- 서명 셋(지난 두 달, 기관 순서): `필수 의료 재검증 우선순위 유지.`(협의체) `회복 지원 대기열 편입.`(연합) `교체 모듈 규격 호환 확인.`(기술부). 명세서 제출 = 179 외부 연구 협력 계정, `기존: 회복 지원망 안정화 모듈. 교체: RECOVERY ACCELERATION / MEMORY CONTINUITY.` 계약 안 변경 양식에 전체 서명 칸 없음 — “칸은 셋이었고, 셋 다 채워져 있었다.”
- 기술부(마흔 중반, 넥타이) 규격만, “다음엔 명세서도 끝까지 읽겠습니다. 제 칸이 아니어도요.” 협의체(전화) “저희가 승인한 건 의료 연속성입니다. 기억 유도까지 승인한 적은 없습니다.” 연합 담당자(182) `동의 확인 후 해제 가능` → 세아 “해제는 켜진 다음이에요.” / “알아요. 그래서 해제 가능이라도 있는 쪽이 낫다고 봤어요.” 세아 “각자 승인한 부분은 안전했어요.” 서인(손바닥이 다 못 덮음) “그런데 이어 붙인 전체를 승인한 사람은 없었네요.”
- 서인: 조항 유지 + 통합 책임·사전 동의 검증(구두 → 조서). 교체 모듈 임시 차단. 정지 청구는 범위 축소(교체 모듈) → 묶음 배정 축소 해제(오늘 밤부터 조금씩, 내일 원래대로). 공고 다음 달 초 → 더 밀릴 수 있음.
- 지우: 원서 냄, 동생이 직접, 답은 내일(화) 새벽.
- 도윤(장부실, 통지문): 지연 비용(단가, 연합에서 들은 딸 이름 잊는 분). “서명은 내가 받으러 다녔어. 한 장씩.” “그러니까 내가 이어 붙인 거고.” 서인 “그럼 도윤 씨가 서명하세요. 전체에요. 도윤 씨 이름으로.” (펜 쪽 손 멈춤) “그러면 막을 거잖아.” “그 서명이 있어야 막을지 말지를 정할 수 있죠.” “네가 지금 미루는 동안에도 사람들은 기다려.” “금요일에 2%였어요.” “오늘은 몇이었는지도 봐라.” → 3%.
- 끝: `RECOVERY SUPPORT · WEST · ROUTE: FALLBACK · ACTIVE.` 교체 모듈 칸 막히자 옛 안정화 모듈로 자동 우회(139 OPERATOR CONFIRM·140 권고와 별개), 서부 대기자 쉰 명쯤 상담 지속. “어느 길로 돌지는 저희가 안 정해요. 차단을 걸면 걸수록, 이 조항이 먼저 옆길을 찾아요.” 안전한 차단법 필요. 상자 옆구리 가는 선.
- 184 인계: 공개 심의 A~D, 전날 밤 냉각 용량 선점, 서인 가지치기·표결 앞당김 → 지역 대표 불참, 하진의 어머니(제안) “둘 중 하나만 고르라는 표는 찢겠습니다.” D안 한시 승인, 도윤 측 일부 권한 잔존. 지우 동생 화요일 새벽 답.
