# 제56화 노트 — 아직 안 정했습니다

## 설계
- 목적: 51–55의 "돌아온 사람" 뒤, 이번에는 정말 떠나는 사람. 56–60 "돌아오지 않은 사람과 그 비용"의 시작.
- 사건: 계열 07 현역 한명진이 연장 통지(20번째)에 동의하지 않기로 하고, 줄이 덜 비게 하려고 장부실 표준안을 찾아온다. 금요일 자정 연장 없이 만료, 풀(5)+연산 보강으로 전환.
- 즉시 비용/이득: 명진은 처음으로 정해지지 않은 밤을 얻는다. 07 신탁은 연산 +0.47M/년, 풀 참여자 5명(앵커 해방 쪽 남자 포함)은 밤과 아침의 무거운 머리. 서인의 이름이 07 해제 기록의 '본인 설명 확인'에 붙는다.
- 핵심 선택: 서인이 본인에게 보이지 않는 세 번째 장의 `+0.006%`를 소리 내어 읽어 준다(숨기지도, 말리지도 않음) → 명진은 이미 보고 왔다 → "그래도 나가시겠어요?" "네."
- 마지막 여운: 심야버스 "아직 안 정했습니다." "그래서 좋네요." → 기록 `07 해제 · 본인 설명: 서인.` → 노선도 종점 이름의 흐려진 자리.
- 반복 점검: 51화(원격 승인·식탁·냉장고)와 달리 승인 절차 없음(연장 미제출), 장소는 장부실→빈 거실→정류장. 서명란 망설임 없음(서인은 멈추지 않고 씀). 냉장고 모터·컵 감싸기·메시지 지우기·도윤 연설 없음. 도윤 미등장.
- Flash 재료 S-1(정류장 노선도) 변형 사용. 원문 문장은 쓰지 않음.

## 새 제안 (작가 확인 전, 확정 아님)
1. 한명진: REFERENCE LINE 07 현역 기준자, 남성, 쉰 남짓, 19년, 연장 19회. 낮에는 출퇴근(회사 차). 매일 22:30 씻고 23:00 취침. 장부실에서 버스로 네 정거장. (제안)
2. 계열 07 기능: 구급·의약품 수송 경로 등 의료물류·재난 경로 판단(설계 원문). 본인은 내용을 모른다("밤에 자고 있으면 정해진답니다"). (제안)
3. 계열 07: 선임 6년 전 사망, 후계 후보 2명 모두 최종 연결 거부 → 현역 연장. (제안 — settings/12 '후계자 거부 시 선대 연장'과 일치)
4. 현역 기준자의 기간제·연장 통지(`연장 동의: 미제출`)로 떠나는 방식: 연장에 동의하지 않으면 만료 시 해제. 신탁은 해제 모델 숫자만 미리 보내고 연장을 권하지 않는다. (제안)
5. 표준안 서식 새 칸 `대상: 현역 · 후계 없음 → 분산 참조풀 + 연산 보강`(지난주 작성팀 추가), 연산 비용은 해당 신탁 부담. 07 풀 적정 12명, 해제 시점 5명. (제안)
6. 해제 모델 수치: 의료물류 판단 신뢰도 −1.6%, 재난 경로 −2.4%, 추가 연산 +0.47M TOKEN/년, 치명적 실패 증가 +0.006%(허용 범위). 모델은 서식 세 번째 장, 작성팀·신탁만 열람. (제안 — 설계의 −1.8%는 1.8초 고정 규칙과 섞이지 않게 −1.6%로 바꿈)
7. `본인 설명 확인 · 작성팀 확인자` 칸(현역 대상에서 생김), 서인이 서명 → 07 해제 기록에 `작성팀 · 서인`. (제안)
8. 앵커 해방 쪽 서명지 남자(55화)가 07 풀 5번째 참여자로 신청. (제안)
9. 만료 전 현역이 평소 입면 시각에 눕지 않으면 `기준 신호 미수신 · 연산 보강 선투입`(비용이 앞당겨 듦). 풀 참여자가 모두 입면하면 연산이 덜 든다. (제안)
10. 7번 수정: 서인의 칸은 '작성팀 확인자'가 아니라 `본인 설명 · 설명한 사람:`(출력 종이), 기록 `07 해제 · 본인 설명: 서인.` 서인의 작성팀 소속은 확정하지 않음.
11. 재조정 기간(settings/12 '재조정 기간')의 07 수치는 원고에 쓰지 않음. 작가 확인 후 57화 이후 필요 시. (제안 보류)
