# 제138화 「집에 가려면」 미공개 체인 인계

- 같은 과거 사고7분대의 병원 제한 시점/8분 운영실/다시 병원이다. 민재라는 어린 아들과 아버지·의료진은 새 인물/현장 세부 (제안)이며 정확 나이·성씨/기관·진단/치료 결과를 정하지 않았다. 병원은 망 중단 이전부터 진료했다. 중단 때문에 복통이 생긴 인과가 아니다. 현재 서인이 이 장면 전체/사적 대화를 읽은 것도 아니다.
- 민재는 집에 돌아갈 조건과 기다릴 시간을 알고 싶어 한다. 아버지는 식사 뒤 토한 것과 식사 전부터 아팠던 때를 다시 구분해 설명한다. 움직일 때 더 아파하는 관찰도 의료진에게 전한다. 의료진은 이를 현장 기록/검사 순서 재의논/별도 재검토 갱신의 근거로 쓴다.
- 현장 진료·처치·추가 검사 요청은 이어진다. 검사 장비/인력·다른 응급 검사와 시간을 맞추는 일과 여러 판단의 대조 의견을 기다리는 일은 다르다. 접수 완료 표시가 검사/재검토 완료를 뜻하지 않는다. 의사가 참조 답이 없으면 아무것도 못 하거나 돈 보호가 돼야 치료하는 제도를 만들지 않는다.
-8분 자동 생존정산 보호 개시: 기존 자격 검증 수급자는72시간 유지, 신규 요청은 별도 심사다. 해당 소아의 정산 자격은 이 운영 화면에서 모른다. 정산 보호와 새 의료 판단 대기는 다른 절차다.11분 수동복구는 아직이다.
- 보호자의 ‘한 번 더 봐 달라’는 말은 침대 곁 사적 대화다. 동의 없는 원음/이름·진료 내용이 운영실에 전달되지 않는다. 운영실에는 병원에서 필요한 범위로 갱신한 비식별 요청/현장 확인 지속·대기 앞당김 요청만 간다. 민재에게는 아버지가 다시 답을 기다리는 시간으로 남는다.
- 생존/사망·영구 손상·확정 진단/복구의 치료 효과·중단이 없었다면의 반사실은 미정이다.20의11분 복구/두 공급사 차단/37분 안정화,98 환자결과 미열람/광고꿈 뇌계산 비밀·30분실험배제/세아 잠긴본문·가족 후속검토/한달HOLD/R/199·200 경계 유지.
