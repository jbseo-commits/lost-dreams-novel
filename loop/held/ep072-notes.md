# 제72화 「두 번 물은 사람」 — 집필 및 연출 노트 (2026-10-09)

- 상태: **체인 주행 집필 완료 (71~75 «질문할 수 있는 사람» 아크 2회차)** (`work/forward-chain-ep056-060` 브랜치). 72화 원고(공백 제외 3,549자) 및 `pilot.html` 웹 연출(`samebutton`) 동시 구현 완료.
- 연출 설계안 — **samebutton**:
  - 상단: `SAME BUTTON · DIVERGENT VERDICTS`
  - 2인 대비 카드:
    - 박미라 (공장 노동자): “천식이 심해요. 너무 멉니다. 도와주세요.” ➔ 기각 (비표준 호소문)
    - 오태석 (사무직 대리): “지침 14조 2항 위반 소명 및 결원 데이터” ➔ 인용 승인 (인근 재배치)
  - 핵심 대사 카드:
    “우리는 같은 권리를 준 게 아닙니다. 같은 버튼을 준 겁니다.”
  - 하단 문장:
    “돈의 벽을 허물자 말의 벽이 드러났다. 세상은 이제 질문하는 계급을 마주하고 있었다.”
  - 연계 파라미터:
    - `on`: “우리는 같은 권리를 준 게 아니라, 같은 버튼을 준 겁니다.”
    - `KEY`: [“우리는 같은 권리를 준 게 아닙니다. 같은 버튼을 준 겁니다.”, “나는…… 뭘 더 물었어야 했어요?”, “돈을 빼앗는 것보다 말을 빼앗는 게 훨씬 더 오래된 지배 방식입니다.”, “세상은 이제 돈보다 더 차갑고 견고한 '질문하는 계급'의 거대한 벽을 마주하고 있었다.”]
    - `hook`: “세상은 이제 돈보다 더 차갑고 견고한 '질문하는 계급'의 거대한 벽을 마주하고 있었다.”

- 새 세부 설정 및 단서 회계 (§4-2 준수):
  1. TOKEN 장벽 너머의 두 번째 벽: 언어와 문해력의 계급성:
     - 0원으로 풀린 같은 재검증 청구 버튼을 눌렀으나,
     - 노동자 박미라는 절박한 사연을 썼다가 '비표준 호소문'으로 4분 만에 기각되고,
     - 사무직 오태석은 조례 지침과 공실률 데이터로 4단계 논리를 구성하여 반나절 만에 인용 승인을 받음.
  2. TOKEN 개혁파 간부의 뼈아픈 현실 직시:
     - "우리는 같은 권리를 준 게 아니라 같은 버튼을 준 것이다."
     - "돈을 빼앗는 것보다 말을 빼앗는 게 훨씬 더 오래된 지배 방식이다."
  3. 박미라의 질문:
     - "나는 뭘 더 물었어야 했어요?" ➔ 서인이 감히 답하지 못하는 침묵의 비극성.
  4. 금기 사항 무결점 준수:
     - 199화 전 "형" 사용 금지: 해당 없음.
     - 200화 전 "메시지 쓰고 지우기" 금지: 완벽 준수.
     - 서명란 앞 망설임 금지: 완벽 준수.
     - 냉장고 모터 회전 금지: 완벽 준수.
     - "...알 수 없었다" 결말 금지: 완벽 준수.
