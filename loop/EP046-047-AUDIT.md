# EP46–47 연속독서 감사

대상: `manuscript/ep045.md` → `ep046.md` → `ep047.md`

## 최초 판정

- EP45: PASS. 물레·흙·430 봉투·컵이 제도와 관계를 동시에 운반한다. 기준 장면으로 보존한다.
- EP46: CHANGES. 컵 앵커와 단답 왕복이 과도해 의도적 혼란과 독해 혼란의 경계가 무너졌다.
- EP47: CHANGES. `컵이 미지근했다`와 들기/마시기/씻기가 반복 틱처럼 작동했고, 지우의 640 대화가 책임·이름·제도 선택을 지나치게 분절했다.

## 적용한 수정

1. 새 범퍼를 만들지 않았다.
2. EP45는 수정하지 않았다.
3. EP46은 사건 순서를 유지하면서 어머니 첫 대화, 정미경 방문, 저녁 이름 대화를 압축했다.
4. EP46의 컵은 `지우가 준 물건 → 이름 없는 소유 → 어머니의 기억`으로 의미가 변할 때만 회수했다.
5. 정미경의 배달·문·잠금은 지시 대상을 직접 밝혀 되읽기를 줄였다.
6. EP47 오전 대화는 `앞집 4천 → 같은 동 7층 → 이름을 말하지 말라는 어머니`의 인과만 남겼다.
7. 재심사 문서의 사건·기한·윤세라 서명·반론 가능성은 보존했다.
8. 지우의 640 대화는 `내 돈 / 제도의 선택 / 약병의 이름 / 책임 주체를 모름`이 한 번에 추적되도록 압축했다.
9. 704호 이름표와 마지막 컵 장면은 보존하되, 반복되는 미지근함 표현은 제거했다.

## 재검수

### EP45 → EP46

PASS. EP45의 컵이 EP46에서 단순 소품 반복이 아니라 `이름이 없어도 내 것인가`라는 질문으로 넘어간다. EP45의 감정과 사건을 다시 설명하지 않는다.

### EP46 내부

PASS. 장소와 화자는 유지되며, 어머니의 회피는 의도적 불확실성으로 읽힌다. 정미경 장면은 배달과 문 잠금의 대상이 즉시 잡힌다. 컵을 빼도 보이는 구간에서는 컵을 반복하지 않는다.

### EP46 → EP47

PASS. EP46의 `이름 없는 컵`이 EP47의 `이름이 붙는 비용과 책임`으로 확장된다. 같은 질문을 그대로 반복하지 않고 7층이라는 실제 주소 방향으로 전진한다.

### EP47 내부

PASS. 재심사 문서와 지우의 640 사례가 `책임 경계`라는 같은 문제를 서로 다른 생활 결과로 보여 준다. 지우의 말은 여전히 망설이지만 독자가 의미를 복원하기 위해 여러 줄을 되읽을 필요는 없다. 704호 이름표가 추상적인 이름 논의를 실제 문 앞에서 끝낸다.

## 자율루프에 승격할 규칙

### 앵커 과반복 금지

구체물은 장면을 붙잡기 위한 장치이지 매 문단마다 존재를 확인하는 체크포인트가 아니다.

- 같은 소품 + 같은 상태 + 같은 동작이 의미 변화 없이 세 번 이상 반복되면 경고한다.
- 반복할 때마다 관계, 선택, 정보 중 하나가 달라져야 한다.
- `컵을 들었다/마셨다/미지근했다`, `화면을 봤다/닫았다/다시 열었다`처럼 자동 생성 가능한 동작열은 우선 압축한다.
- 소품을 빼도 장면이 보이면 뺀다.

### 대화 파편화 금지

짧은 대사는 이 작품의 리듬이지만 짧다는 것 자체가 품질 기준은 아니다.

- 독자가 세 줄 전의 명사를 되찾아야 현재 대사를 이해하면 실패다.
- 1~2어절 응답의 연속이 의미를 날카롭게 하지 않고 왕복 횟수만 늘리면 합친다.
- 중요한 제도·책임·관계의 차이는 한 번쯤 완전한 문장으로 말해도 된다.
- 의도적 말막힘과 정보 부족 때문에 생긴 불명료함을 구분한다.
