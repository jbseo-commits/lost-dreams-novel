# 자율 집필 루프 설정

작가가 이 파일의 값만 바꾸면 루프의 동작이 바뀝니다. 루프는 이 파일을 고치지 않습니다.

| 항목 | 값 | 설명 |
| --- | --- | --- |
| 상태 | 실행 | `실행` 또는 `정지`. 정지면 루프가 아무것도 하지 않습니다. |
| 목표 화수 | 20 | 화수 제한 없이 계속 씁니다. 숫자를 적으면 그 화까지 쓰고 멈춥니다. |
| 종료 시각 |  | 이 시각이 지나면 새 화를 시작하지 않습니다. 비워 두면 시간 제한이 없습니다. |
| 한 번에 쓰는 화수 | 1 | 한 번 돌 때 쓰는 화 수 |
| 분량 (공백 제외) | 3500~5500자 | 1~10화 평균에 맞춘 범위 |
| 미정 설정 | 제안으로 쓰고 계속 | 새로 만든 설정은 `(제안)`으로 표시하고 `settings/05-open-questions.md`에 올립니다. |
| 품질 기준 | 마스터피스 | 글과 연출 모두. 7개 항목 각 8점 이상, 평균 9점 이상이어야 공개 (`LOOP.md` 4단계) |
| 재검수 | 고친 부분만 | `고친 부분만` 또는 `처음부터`. 고친 부분만이면 같은 검수자가 지난 결함과 바뀐 부분만 다시 보고 점수를 다시 매깁니다. 토큰을 크게 아낍니다. |
| 배포 | 바로 공개 | 검수를 통과하면 main에 올리고 웹 배포까지 확인합니다. |
