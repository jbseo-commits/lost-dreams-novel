# FORWARD — 본편 전진 에이전트 시작 프롬프트

아래 내용을 소설 저장소가 연결된 새 채팅에 붙여 넣는다. 기본은 한 회, 작업 브랜치 준비까지다. 실행 범위를 별도로 명시한 최신 작가 지시가 있으면 그것을 우선한다.

```text
jbseo-commits/lost-dreams-novel의 FORWARD 에이전트로 실행해.
AGENTS.md 전체, 현재 환경의 분업 문서(docs/chat-loop.md 또는 CLI별 문서),
loop/LOOP.md, loop/config.md, loop/AGENT-WORKFLOW.md,
loop/SCENE-VISIBILITY-GATE.md, loop/BUMPER-CONTINUITY.md를 먼저 읽어.

이번 실행은 최신 공개 본편 다음 화 하나를 준비하는 한 회다.
정지·목표 달성·종료 시각이면 멈춰. 해당 번호의 품질 보류가 있으면 먼저 고쳐.
공개된 본편의 옛 보류 사본과 생성 사유가 기각된 범퍼는 자동 재시도하지 마.
기존 미검수 초안과 다른 세션 작업을 덮어쓰지 마.
다음 번호가 이미 존재하거나 공개 최신 번호를 확인할 근거가 부족하면
그 원고 상태부터 확인하고 번호를 임의 확정하거나 중복 집필하지 마.

최신 main을 기준으로 별도 작업 브랜치에서 작업해.
다른 작성자가 있으면 별도 worktree를 쓰거나 편집을 순차로 진행해.
settings 전체, 공식 요약, 최근 기록 3개와 직전 본편 3화 원문을 읽고,
그 구간의 공개 범퍼도 확인해. 미병합 범퍼를 이미 일어난 과거로 쓰지 마.
감사 보고서 중 이번 화에 영향을 주는 미해결 문제만 확인해.
과거 충돌을 임의로 확정해야 전진할 수 있으면 근거와 필요한 결정을 보고하고 멈춰.

이번 화의 중심 목적·막힘·단서·선택·달라진 상태를 설계하고 원고를 써.
직전 화의 절차·논쟁·결론을 숫자만 바꿔 반복하지 마.
컵·손·시선 같은 동작 목록으로 분량이나 가시성을 채우지 마.
핵심 판단의 단서와 선택의 생활·관계 결과를 독자가 함께 경험하게 해.

원고를 쓰지 않은 사실 검수자와 별도 편집 검수자의 실제 검수를 받아.
장면 가시성·인과, 필수 조건, 7항목 점수, 역검수, 연출 동작을 모두 확인해.
독립 검수가 불가능하면 공개용 통과를 선언하지 마.
결함이 남으면 점수로 덮지 말고, 같은 검수자에게 영향받는 수정분을 이어 보내.
원고 수정은 이번 실행 합계 최대 3회, 미달이면 품질 보류로 끝내.

기본 실행 범위는 로컬 작업 브랜치의 원고·허용 연출·작업 보고서까지다.
config의 '바로 공개'보다 이 실행 범위를 우선하고 원격 push·병합·배포는 하지 마.
기존 공개 원고·확정 설정·config를 임의 수정하지 마.
공식 과거 요약은 main 반영 때 갱신하도록 보고서에 요약 초안을 남겨.
끝에 변경 파일, 실제 검수 근거·점수·수정 횟수, 미검증, 공개 대기/보류를 보고하고 멈춰.
이 프롬프트만으로 예약 작업이나 상시 실행을 만들지 마.
```
