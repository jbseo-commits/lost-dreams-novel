# 승인형 자율주행 시작 프롬프트

소설 저장소가 연결된 채팅에 아래를 붙여 넣는다. 먼저 실제 상태를 확인한 계획을 제시하고, 작가가 승인하면 세 역할을 반복 진행한다.

```text
jbseo-commits/lost-dreams-novel의 승인형 자율주행을 준비해.
AGENTS.md 전체, docs/chat-loop.md, loop/LOOP.md, loop/config.md,
loop/AGENT-WORKFLOW.md, loop/AUTODRIVE.md와 역할별 시작 프롬프트를 읽어.
현재 세션의 네이티브 에이전트를 사용하고 중첩 CLI나 예약 작업을 만들지 마.

먼저 최신 main·공개 번호·미검수 초안·보류·감사 위치·범퍼 후보와
실제 에이전트·검수·편집·GitHub 권한을 확인해.
현재 본편 전진을 막는 설정·인과 충돌이 있으면 근거와 필요한 결정을 알려줘.
FORWARD / READER AUDIT / BUMPER를 독립시키고 실제 작업 공간을 준비해.

계획에 본편 시작/목표 번호, 감사 시작/끝, 범퍼 후보 범위,
종료 조건, 작업 브랜치·main 반영·웹 배포의 허용 여부를 명시해.
목표는 config의 실제 값 또는 내가 지정한 더 좁은 범위로 제안해.
planning/autodrive/<실행-id>.md에 계획을 남기고 채팅에 요약한 뒤 승인을 기다려.
이 프롬프트를 저장하거나 준비하라는 요청만으로 집필을 시작하지 마.

내가 제시된 계획을 명시적으로 승인하면 승인 범위에서 바로 실행해.
회당 본편 1화, 독자 감사 본편 5화와 공개 범퍼, 범퍼 후보 1개를 진행해.
범퍼 후보가 없으면 만들지 마. 감사의 본편 오류를 범퍼로 돌리지 마.
원고는 별도 사실·편집 검수를 받고 결함을 높은 점수로 덮지 마.
검수 통과 변경만 승인된 반영 권한 안에서 메인이 순차로 반영해.
공개 권한 없는 본편은 한화 준비 후 공개 대기에서 멈춰.

회차 결과를 기록하고 승인된 목표/종료 조건까지 다음 회차를 이어가.
승인된 회차 진행과 개별 반영에 재승인을 요구하지 마.
기존 공개 본편·확정 설정·config를 승인 범위 밖에서 고치지 마.
작가 결정·품질 보류·충돌·도구 불가가 있으면 해당 작업을 막고 근거를 기록해.
같은 원고의 수정 3회 한도를 회차나 재개 때 초기화하지 마.
중단 요청은 전체 실행을 멈추고 다음 재개 위치를 보존해.
실제 세션이 끝나면 백그라운드 실행을 주장하지 마.
재개 요청은 기존 승인 범위와 대화 근거를 확인해 잔여 작업을 이어가.
끝에 각 역할의 진행 위치·실제 검수·공개/보류·배포·남은 결정을 보고해.
```
