# SCENE / STUDIO — 게임 아트 제작실

기준 원화를 보존하며 인물 원화·키포즈·컷신을 제작하고, 후보 비교 → 검토 → 승인 → 장면 적용 → 실제 게임 미리보기를 한 작업 공간에서 진행합니다. 원고를 편집하는 도구가 아닙니다.

## 실행

이 폴더의 `start.ps1`을 PowerShell에서 실행하거나 `node tools/art-studio/server.mjs`를 실행하고, 출력된 로컬 주소를 엽니다. 기본 주소는 `http://127.0.0.1:4321`입니다. Node.js와 기존 프로젝트 파일만으로 동작합니다. 서버는 로컬 PC에만 바인딩합니다.

## 작업 순서

1. 왼쪽에서 프로젝트와 장면을 고릅니다. 비주얼 노벨은 현재 공개 데모 1–11화 및 포함 범퍼의 실제 실행 좌표를 사용합니다.
2. 오른쪽의 인물 기준 원화를 확인합니다. 서인은 티저 계열 원화, 지우는 작가가 확정한 여성 원화가 기준입니다. 기준 파일의 SHA-256을 기록하며 원본을 덮어쓰지 않습니다.
3. 표정·자세·시선·장면 의도를 정해 새 후보를 제작하거나 PNG/JPEG/WebP를 가져옵니다. 기존 라이브러리의 에셋도 비교 대상으로 등록할 수 있습니다.
4. 나란히/겹침 비교와 확대, 밝은/어두운 배경으로 후보를 봅니다. 네 가지 검토 항목과 메모를 남긴 뒤 후보를 승인합니다. 도구가 그림의 동일 인물 여부를 자동으로 보증하지 않으며, 확인은 제작자가 합니다.
5. 적용 구간과 위치를 지정합니다. **이 후보로 장면 보기**는 미승인 후보도 임시로 보여 주며 적용 파일은 쓰지 않습니다. **승인한 후보를 장면에 적용**은 선택 범위만 저장합니다.
6. 실제 게임 화면에서 다음 문장으로 진행하고 모바일 400px로도 확인합니다. 적용 목록에서 개별 변경을 되돌릴 수 있습니다.

## 생성 엔진

### 프롬프트만 입력해서 제작

오른쪽 **프롬프트 입력**에서 원하는 그림을 적고 **이미지 생성**을 누릅니다. 예: `서인과 지우가 사무실 책상 건너편에서 마주 본다. 지우는 동의서에 손을 올리고 서인은 대답을 망설인다. 두 사람의 얼굴과 손이 보이는 컷신.`

등록된 인물 이름을 읽어 해당 인물의 잠근 기준 원화를 자동 첨부합니다. 인물 이름이 없으면 현재 선택 인물의 원화를 사용합니다. 인물·컷신·배경의 판단과 첨부 인물은 입력 아래에서 확인할 수 있고, 결과 형태는 직접 바꿀 수 있습니다. **전달 내용 보기**에서 실제 프롬프트를 확인합니다. 자동 판단은 등록 이름·키워드 기준이므로 복잡한 요청은 결과 형태를 지정하세요.

완료된 그림은 비교 후보로 자동 선택되며 입력한 초안은 유지됩니다. `Ctrl+Enter`로도 제작할 수 있습니다. 표정·자세·시선은 **세부 연출**에서 지정할 수 있으며 자유 프롬프트에는 숨겨진 기본값을 덧붙이지 않습니다. 후보는 검토 전 상태로 저장되고 장면 적용에는 별도 승인이 필요합니다.

생성은 기존 ChatGPT 로그인에 연결된 `codex` 경로만 사용합니다. API 키·별도 API 결제는 사용하지 않습니다. 로그인·권한·구독 한도에 문제가 있으면 실패를 표시하고 멈춥니다. 서버에서도 다른 provider를 거부합니다.

설치된 sprite-gen CLI의 기존 생성 엔진을 사용합니다. 생성 버튼을 누를 때 선택한 구독의 이미지 생성 권한을 명시합니다. 인증 또는 한도가 없으면 실패를 그대로 표시하며 별도 API 과금 경로로 전환하지 않습니다. 생성 결과는 승인 전 후보로 들어옵니다. 엔진이 연결되지 않아도 이미지 가져오기·비교·검토·장면 적용을 쓸 수 있습니다.

잠근 기준 파일을 참조 이미지로 전달하고 실제 프롬프트를 확인할 수 있습니다. 얼굴·헤어·의상·선·색감 유지 지시와 이번 표정·자세·시선·사건의 의도를 함께 전달합니다. 프롬프트만으로 일관성을 보장하지 않으므로 승인 절차를 거칩니다. 동작 시트의 새 애니메이션 제작은 기존 sprite-gen 파이프라인에서 추출·정렬한 결과를 가져오는 방식이며, 정지 원화를 완성 애니메이션이라고 표시하지 않습니다.

## 실제 게임 연결

비주얼 노벨은 기존 `vn/app.js`와 `EpisodeOneStage` 렌더러를 그대로 실행합니다. `studio=1` 로컬 미리보기의 저장 데이터는 메모리에만 존재하고 실제 플레이어 저장과 분리됩니다. 일반 게임은 `vn/art-direction.json`의 승인 적용본을 읽습니다. 인물·컷신·배경은 기존 연출 뒤에 지정 범위에서만 바뀝니다. 챕터 원문 fingerprint 및 양끝 문장이 달라지면 오래된 적용을 무시합니다.

야구는 별도 로컬 작업본을 **읽기만** 합니다. 실제 장면 적용 슬롯은 타자 4×2 시트(7키포즈)와 Red Rush 10×12 시트(120프레임)입니다. 인물 기준 원화·키포즈 생성과 비교는 지원하며, 정지 원화는 기준 전용으로 표시하고 실제 애니메이션을 바꾸었다고 표시하지 않습니다. 기존 시트/아틀라스 규격을 검증하며, Vite 미리보기에서 이미지 import만 바꿉니다. 실제 CinemaLab의 경기장·투구·타격 렌더러로 재생합니다. 원래 야구 프로젝트 파일이나 밸런스·게임 규칙을 수정하지 않습니다. 야구 적용 기록은 제작툴의 manifest이며, 원래 저장소에 반영하거나 공개 배포한 상태가 아닙니다. Vite가 없는 환경에서는 원화 비교와 manifest 내보내기만 가능하다고 표시합니다. 다른 야구 작업본은 `BASEBALL_PROJECT_ROOT` 환경 변수로 경로를 지정합니다.

## 저장과 복원

후보·참조 해시·생성 작업·검토·적용 이력은 `.art-studio/`에 저장됩니다. 비주얼 노벨 적용 에셋은 `vn/assets/studio/`, 적용 manifest는 `vn/art-direction.json`입니다. 작업 내보내기는 JSON을 다운로드하며 실제 이미지 파일은 원래 경로에 보관됩니다. 후보 파일도 함께 보존하려면 `.art-studio/`를 백업하세요. 서버 중단 당시 진행 중인 생성은 다시 요청하지 않고 중단 상태로 남깁니다.

로컬 데이터와 생성 인증은 Git에 포함하지 않습니다. 공개 GitHub Pages로 이 제작 서버를 배포하는 기능은 없습니다.
