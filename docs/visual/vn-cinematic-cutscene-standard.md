# 비주얼 노벨 시네마틱 컷신 제작 기준

> 작가 확정 기준 · 2026-10-23 · 《꿈을 잃은 세계》
> 핵심: **컷신은 문장을 삽화로 복창하지 않는다. 인물의 시선과 행동을 따라 이동하면서 독자가 감정을 직접 발견하게 한다.**

## 1. 목적과 적용 범위
인물 입상 두 장을 배경 위에 세워 두는 것은 일반 대화 연출이며, **컷신이 아니다**. 컷신은 이야기의 관찰·인식·선택·감정이 실제로 변하는 지점에 삽입한다. 중요한 외형, 손, 사물, 미세한 반응과 후속 행동은 필요하면 여러 컷으로 분해한다. 모든 서술에 컷신을 끼우지 않는다. 원고의 인과상 의미 있는 순간을 우선한다.

## 2. 기본 카메라 문법: 시선 → 디테일 → 반응 → 행동
1. **Establish (공간·관계):** 현재 장소와 인물의 상대 위치를 보여 준다. 이전 컷과 화면 방향·동선이 이어져야 한다.
2. **Gaze (관찰자):** 누구의 시선인지 보여 준다. 눈과 고개 방향을 후속 클로즈업의 위치와 맞춘다.
3. **Detail / POV (발견):** 관찰자가 발견한 구체적인 것을 화면 중심에 놓는다. 손톱 밑 흙, 다 닳은 옷깃, 망가진 그릇 등 텍스트에 있는 **그 디테일 그대로** 제작한다. 독자가 한눈에 알아차려야 한다.
4. **Reaction (의미):** 말 대신 짧은 멈춤, 미소, 손가락의 움직임, 시선 회피 등을 사용한다.
5. **Action (완료):** 발견 때문에 이어지는 동작을 보여 주며 장면을 마친다. 인물 사이의 거리와 소품 위치를 이어간다.

이 다섯 단계는 필요한 만큼 결합·생략할 수 있으나, 인과상의 핵심인 **발견과 뒤따르는 행동**은 빠뜨리지 않는다. 카메라 위치만 바뀐 채 감정·행동이 정지한 그림 나열은 실패다.

## 3. 컷신 하나를 만들기 전 반드시 제출할 시퀀스 카드
- 원문 앵커: 장/시작 문장/끝 문장/beat 좌표, 무엇을 알려 주고 무엇을 감출지
- 관찰자·시선 경로: 누구의 눈에서 어느 구체물로 내려가거나 이동하는가
- 비트별 컷: WIDE → EYES → POV DETAIL → REACTION → RETURN/ACTION
- 감정: 컷 전/중/후 어떻게 달라지는가. 직접 설명하지 않는다
- 연속성: 시간·빛·장소·의상·머리·손의 어느 쪽·소품 잡는 손·사물 위치
- 오디오: 필요한 경우 기존 BGM/환경음/짧은 효과음, 무의미한 효과 남발 금지
- 화면: 모바일 390~400px, 하단 텍스트 박스와 상단 조작 UI를 감안한 인물·디테일 안전영역
- 원문/설정: 이미 확정된 성별·인물 원화·비밀 정보 수준 유지, 원고 임의 수정 금지

## 4. 원화 제작의 통과 조건
1. **동일 인물:** 기존 정본 얼굴·헤어·체형·의상·연령 인상과 화풍 유지. 지우는 여성, 서인은 남성.
2. **행동 정합:** 원문에서 손톱 밑에 '조금' 남은 씻긴 흙이라면 손 전체에 방금 물레를 만진 듯 진흙을 칠하지 않는다.
3. **연속성:** 컷마다 캔, 손 위치, 빛 방향, 의상 및 흙의 양과 위치가 갑자기 바뀌지 않는다.
4. **시선 일치:** 관찰자가 내려다본 곳에 바로 다음 디테일이 존재해야 한다. 시선의 방향과 화면 전환이 모순되면 탈락.
5. **영화적 구도:** 배경 미장센보다 발견 대상의 시각적 가독성이 우선. 비슷한 표정의 전신 그림만 여러 장 만들지 않는다.
6. **PC·모바일:** 원화는 가로 구도를 기본으로 하되 모바일 크롭 시 눈·손톱·핵심 동작이 가려지면 별도 세로판 또는 초점 지정.
7. **글자 없음:** 컷신 원화 안에 임의 대사·자막·로고·워터마크를 굽지 않는다. 게임 텍스트는 기존 엔진이 표시한다.
8. **검수:** 얼굴·손가락 개수·손 구조·소품 그립·표정·흙의 양을 100%와 모바일 실제 크기로 확인한다.

## 5. 3화 '편의점 앞 흙 묻은 손톱' 기준 시퀀스
정본: `manuscript/ep003.md`, 비주얼 노벨 beat 96~107.

| 비트 | 화면 | 설명·주의 |
| --- | --- | --- |
| 96~105 | TWO SHOT | 편의점 앞에서 두 사람이 맛없는 맥주를 마시며 웃는다. 공방을 떠난 뒤이므로 땀·흙은 상당 부분 씻긴 상태. 실제 편의점 거리 배경, 늦은 오후 조명 |
| 105 | GAZE | 웃던 서인이 지우의 손으로 시선을 내린다. 눈동자와 고개 방향이 다음 컷을 가리킨다 |
| **106** | **POV INSERT / FINGER DETAIL** | '지우의 손톱 밑에는 씻어도 빠지지 않은 흙이 조금 남아 있었다.' 얼굴이 아니라 손톱 아래에 남은 **적은 양의 마른 흙**이 주인공. 캔 잡는 손과 복장 유지 |
| **107** | **RETURN / ACTION** | '서인은 그걸 보다가 자기 캔을 지우의 캔에 가볍게 부딪쳤다.' 서인의 시선이 디테일에서 돌아와 작은 건배로 감정이 전달됨. 과장된 충돌·새 대사 없음 |

화면 시퀀스: `투샷 → 서인의 내려가는 시선 → 손톱의 작은 흙 클로즈업 → 두 캔이 가볍게 맞닿음`. **흙의 발견이 건배의 의미를 만든다.** 컷신은 그 사실을 보여주어야 한다.

### 3화 앞선 공방 장면과의 대비
- 공방: 머리 땀, 볼의 흙, 엉망인 앞치마와 환한 웃음을 한눈에 보여 준다.
- 편의점: **이미 씻었지만 손톱 밑에 조금 남은 흔적**이다. 동일한 '온몸에 묻은 흙' 그림을 재사용하면 시간의 경과가 사라진다.
- 두 장면의 지우 얼굴과 서인 인물 정체성이 같아야 하되 흙의 상태는 **다르게** 연출한다.

## 6. 게임 코드와 파일 규칙
- 원본 `manuscript/`, `settings/`, `manifest.json`, 저장 진행 좌표, 선택지는 변경하지 않는다.
- `vn/ep1-assets.js`에 CG를 등록하고 `vn/episode-cutscenes.js` 또는 해당 시퀀스 테이블에 **원문 정확 앵커**로 연결한다.
- 원문 개고로 앵커가 달라지면 잘못된 컷신을 보여주지 말고 검증 실패로 처리한다. 작품 내용에 맞춰 재연결한다.
- `vn/episode-one-stage.js`는 컷 간 자연스러운 페이드/시선 유도/축소·확대를 지원해야 하며, 원화 자체를 단순 두 배 확대해 흐릿해지는 임시 방법은 지양한다.
- 숨은 오버레이는 클릭을 가로채지 않는다. 움직임 감소 환경에서는 전환 효과만 줄이고 컷 정보는 남긴다.
- 원화 파일명은 `vn/assets/cutscenes/` 아래 영문 소문자와 하이픈을 사용한다.
- **독립 PR 브랜치 작업 후 검수**, main 직접 수정/병합 금지.

## 7. 테스트 및 출고 게이트
1. 원문 앵커·beat 범위·원본 텍스트 및 저장 좌표 불변 검증
2. 각 컷의 CG 파일 존재, MIME·해상도·손·얼굴·소품 정합성 확인
3. **순방향 진입 → 뒤로 → 자동 진행 → 읽은 곳 넘김 → 저장 복원** 테스트
4. 390×844/400×844 및 데스크톱에서 손톱의 흙, 건배 동작 식별 확인
5. 세 컷 사이에서 인물·조명·소품 불연속, 화면 번쩍임, 손 부자연스러움 검사
6. 모바일 터치, 전체 이미지, 화면 숨김, reduced motion, 오프라인 번들 리소스 검증
7. 사람이 실제 속도로 읽고 '서인이 왜 캔을 부딪쳤는지' 그림만으로 이해되는지 평가
8. 오류 발견 시 **그림 하나로 때우지 말고 장면 시퀀스 전체 인과를 재검수**
