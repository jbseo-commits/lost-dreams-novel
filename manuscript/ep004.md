# 제4화. 일곱 초

사건은 회의실에서 일어났다.

회사의 예측 AI가 멈춘 것은 처음이었다.

계약 상대가 조건 하나를 바꾸자 경우의 수가 폭발했다. 82억 개의 경로. 추가 토큰 요청. 승인 대기.

사람들은 조용히 화면만 바라봤다.

서인은 상대편 대표를 봤다.

남자는 손목시계를 세 번 만졌다. 회의를 끝내자는 말이 나올 때마다 시선을 문으로 보내지 않고 창밖으로 돌렸다. 메시지가 올 때마다 화면을 뒤집었다.

서인이 말했다.

“회의 끝내지 마세요.”

팀장이 돌아봤다.

“근거?”

“지금 집에 가기 싫어합니다.”

“뭐?”

“계약 조건이 문제가 아니에요. 시간을 끌고 있어요.”

AI는 여전히 계산 중이었다.

팀장은 미쳤냐는 표정이었다.

그래도 7초를 기다렸다.

상대 대표가 입을 열었다.

“방금 조건은 철회하겠습니다.”

회의실이 조용해졌다.

계약은 체결됐다.

그리고 진짜 문제는 그다음에 생겼다.

사내 보안 시스템이 서인의 판단을 분석했다.

**미등록 추론 모델 의심.  
예상 연산비용: 41,200 TOKEN 이상.**

“무슨 모델 써?”

팀장이 물었다.

“안 썼는데요.”

아무도 웃지 않았다.

상층에서는 토큰이 곧 사고력이었다. 더 많은 토큰, 더 좋은 AI, 더 정확한 미래.

그런데 서인은 0토큰으로 7초 만에 답을 냈다.

그날부터 사람들이 그를 보는 눈이 달라졌다.

누군가는 비밀 모델을 물었다. 누군가는 회사 이름을 물었다. 누군가는 돈을 제시했다.

서인은 설명할 수 없었다.

그냥 보였다고 말하면 더 이상하게 들릴 뿐이었다.

퇴근 후 낯선 메시지가 도착했다.

**당신은 생각보다 오래 기다렸군요.**

발신자 없음.

삭제하려는 순간 두 번째 문장이 떴다.

**AI 없이 생각하는 법을 잊지 않은 사람이 아직 있었네요.**

서인의 손이 멈췄다.
