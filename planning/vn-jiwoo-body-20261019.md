# 지우 몸 전체 비례 재수정

작가가 첫 정정의 점토CG를 보고 “전체적으로 몸이나 이런 부분이 남자같아보여 얼굴만 한다고 되는게 아니잖어”라고 재지적했다. 앞선 수정은 얼굴·표정 확인에 치우쳤고, 넓은 어깨와 상체·큰 팔과 손·상자처럼 부푸는 셔츠를 충분히 고치지 못했다. 기준 main은 `4b8ccedbb273c66ac1e0125a2cd1b09b3c225e1a`.

## 재작화

- 지우 세 표정과 점토CG의 몸 전체를 내장 이미지 편집 도구로 다시 그렸다. 좁고 완만한 어깨, 작은 흉곽과 자연스럽게 이어지는 허리·골반, 팔과 손의 크기, 몸에 맞춰 떨어지는 셔츠 실루엣을 함께 수정했다. 얼굴이나 화장만으로 차이를 만들지 않았다.
- 짧은 갈색 머리·회색 셔츠·짙은 티·작업 바지와 장난기/결심/상처의 연기를 유지했다. 점토CG에서 남성 서인의 모습, 서인의 상자를 받치는 두 손과 지우가 점토를 건네는 행동은 보존했다.
- 새 파일 경로 `jiwoo-woman-body-*.webp`, `cg-clay-woman-body.webp`를 자산 맵에 연결했다. 이전 체형 파일을 새 기준으로 오인하지 않도록 2화 제작 인계·원화 제작 기록을 갱신했다.
- 단일HTML도 새 자산으로 재빌드했다. 원고·이야기 데이터·읽기 묶음·저장 키·음향과 티저는 변경하지 않았다. 실제2화 그림을 이번에 교체한 것은 아니다.
- [실제 제출 프롬프트·참조·원본 기록](../vn/assets/ep1/jiwoo-body-provenance.json). PNG에서 WebP로 형식만 변환했으며, 별도 코드로 몸이나 알파를 조작하지 않았다.

## 검증

- `npm test`:10개 검사 파일 통과. 새 그림4종이 실제 서로 다른 WebP 파일로 연결됨을 포함한다.
- PC1440×900·모바일400×844의 세 표정/점토CG8개 화면에서 새 그림 디코딩, 옛 체형 파일 요청0, 가로 넘침0, 기존 저장110/138/155/185 복원, 지난 이야기 닫기와 클릭/터치 다음 이동을 확인했다. 페이지 스크립트 오류0.
- PNG의 RGBA와 외곽 투명 알파를 확인하고 실제 사무실 배경과 합성했다. 얼굴 외에도 어깨·몸통·팔과 손·옷의 실루엣을 이전 그림과 비교했다.
- 단일HTML 로컬 실행에서 티저 스킵·본편·홈·목차의 모바일 조작을 외부 자산 차단 상태로 확인했다. 새 점토CG를 내장WebP에서 실제 디코딩하고 터치로 진행하는 것도 확인했다. 빌드 자산 목록에 새 그림4종의 경로·해시가 기록된다.
- 실제 iOS/Safari와 직접 파일 열기는 새로 검증하지 않았다. 1화 전체161화면을 다시 순회한 검증으로 주장하지 않는다.
