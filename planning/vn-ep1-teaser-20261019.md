# 1화 체험판 시작 티저와 건너뛰기

작가 요청: “1화 체험판 시작할 떄 티저 영상 틀어주고 영상 스킵하는거 넣어줘.” 기준 main은 `826c59068830daa6e9ce90ce6f72509d6c419e8b`.

## 동작

- 체험판에서 소리를 선택하면 기존 [티저 V14](../teaser/README.md)가 먼저 재생된다. 영상은 약54.8초이며, 처음부터 보이는 ‘영상 건너뛰기’ 버튼 또는 Esc로 즉시 1화를 시작한다.
- 영상 끝·미디어 오류·재생 거절·초기10초 로드 시간 초과도 같은 종료 경로로 본편을 한 번만 시작한다. 티저의 영상·이벤트·타이머는 정리한다.
- 기존 소리 켜기/무음 선택과 설정 음량을 따른다. 탭을 숨기면 일시정지하고 ‘계속 재생’으로 재개할 수 있다.
- 티저 중에는 기존 자동 저장을 덮어쓰지 않는다. 본편 시작 시 이전 읽기 위치를 기존 돌아가기 기록으로 보존한다. 이어 읽기·전체 이야기·저장 불러오기에는 티저를 추가하지 않는다.
- 원고, 이야기 데이터, 원문263개·읽기 화면161개, 저장 키와 원문 인덱스는 그대로다.

## 영상과 단일 HTML

- 원본 `teaser/output/lost-dreams-teaser-v14.mp4`의 편집·자막·음악은 유지하고 웹용으로 재인코딩했다. H.264/AAC,1280×720,약9.4MB,faststart이며 영상을 잘라내지 않고 화면 안에 맞춘다.
- 재현 명령: `ffmpeg -i teaser/output/lost-dreams-teaser-v14.mp4 -c:v libx264 -preset medium -crf 24 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart vn/assets/ep1/teaser.mp4`.
- MP4 MIME과 자산 맵을 연결해 단일 HTML에도 같은 영상을 내장한다. 파일 크기는 약47.6MB다.

## 검증

- `npm test`:10개 검사 파일 통과. 티저 검사는 종료·스킵·Esc·오류 중복 시 한 번만 진입, 지난 세션의 뒤늦은 재생 거절, 초기 로드 시간 초과, 숨김·재개, 음량0과 범위 제한을 포함한다.
- 저장소 필수 `node --test tools/agent-dashboard/agent-loop.node.mjs`:10개 통과.
- Chromium PC1440×900·모바일400×844에서 실제 영상 시간 증가, 일시정지/재개, 클릭·터치 스킵, 무음·음량 설정, Esc, 본편 진행, 이어 읽기 우회를 확인했다.
- 티저 중 이전 저장111 유지 및 본편 오디오 미시작을 확인했다. 실제 미디어 종료는8배속 연속 재생으로 검사했다(일반 감상 시간 평가 아님).
- 영상 요청 실패와 play() 거절 시 본편 진입, 단일 HTML의 내장 MP4 실제 재생·터치 스킵·본문 진행을 확인했다. 단일 HTML은 로컬HTTP로 열고 외부 자산 요청을 차단한다. 브라우저 기본 favicon 요청은 차단되며 앱 자산 의존성과 구분한다.
- 직접 파일 열기와 실제 iOS/Safari 기기는 이번에 검증하지 않았다. 이전 파일 열기 검사는 관리자 브라우저 정책에 차단됐다. 사람의 영상 전체 청취를 새로 평가한 결과는 아니다.
