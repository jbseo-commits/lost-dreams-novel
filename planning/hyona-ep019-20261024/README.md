## 인물과 이야기에서 보존한 것

서인은 빠르게 고른 답을 고치면서도 자기 동네 신청의 변경 기록을 놓치고, 현장의 위험을 가볍게 보는 면이 남는다. 강연우는 농담을 받아 주면서도 그의 판단과 안전을 따로 짚는다. 윤세라는 서인의 소문보다 실제 선택을 보고, 주민 신청은 자기 이름으로 처리한다. 이 구별되는 반응과 참여자4의 마지막 열람 기록을 살렸다.

서인의 자각은 중복 해설을 덜고 “제 기분 편하자고 다 깨울 뻔했네요”라는 반응에 담았다. 공동주방에서는 늦은 재료로 기사들의 도시락을 어떻게 만들 것이냐는 질문이 다음 현장 방문으로 이어진다.
