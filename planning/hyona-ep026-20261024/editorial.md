### H26-01 / 필수 / 면제 사용 여섯과 줄에 선 여섯이 반대 의미로 읽힘

- 217–225행: “R-17 계열 면제: 도시 전체 41건” / “면제 사용 신청: 6건” / “마흔한 명 중에 여섯만 줄에 섰네요.”
- 반응: “여섯은 면제를 써서 줄에서 빠진 사람들이야, 면제를 거부하고 줄에 선 사람들이야?”
- 끝에서는 어머니가 ‘면제 사용 안 함’을 누르자 585행 사용 신청이 5건으로 줄어든다. 이 연결로 보면 여섯은 면제를 사용한 쪽이다. 225행 ‘줄에 섰다’는 어머니가 면제를 끄고 줄에 선다는 후반의 말과 반대로 들린다.
- 최소 방향: **등록·지정 대상 41과 실제 사용 6**을 구별하고, 225행도 그 뜻에 맞출 것. 다른 35명의 선택이나 신청 여부를 추측해 확정하지 않는다. 6→5라는 실제 반영은 유지한다.

### H26-02 / 필수 / 차단 건수와 조회 순번 표기가 겹침

- 175–181행: 합계 “차단 기록: 3건” 아래 각 줄이 “1건 / …”, “2건 / …”, “3건 / …”으로 시작한다. 603행 새 줄도 “4건 / 21:52 / …”이다.
- 반응: “한 건, 두 건, 세 건이면 합계 여섯 아닌가? 아니면 첫째·둘째·셋째 번호야?”
- 이야기의 합계는 세 건에서 네 건으로 늘어난다. 각 줄 앞은 개별 조회의 순번인데 건수처럼 표시되어 다시 읽게 된다.
- 최소 방향: 목록 앞을 ‘첫 번째 조회’나 ‘조회 1’처럼 **순번**으로 구별할 것. 합계 3→4와 개별 요청 항목은 그대로 둔다.

### H26-03 / 국소 명료화 / 어머니가 신청하지 않은 대상

- 131행 “어머니는 신청한 적도 없는데.”
- 반응: “광고 추가 계약은 어머니가 직접 신청했잖아?” 바로 뒤 133행 ‘가족은 지정된다’에서 가족 보호 묶음을 말한다고 복구된다.
- 최소 방향: 광고 신청과 구별되도록 ‘이 보호’처럼 대상을 짚을 것. 어머니의 실제 광고 계약 신청이나 직접 면제 미사용을 고르는 행동을 바꾸지 않는다.

## 유지할 인물과 재미

- 읽지 않고 누른 자기 알림이 돌아오고, 백윤하가 “광고꿈 약관처럼요”라고 찌르는 대목이 좋다. 서인이 몰랐던 혜택과 설명회 발언의 파장이 연결된다.
- 정미경이 묻는 것은 항의보다 ‘화를 내도 되는가’에 가깝고, 이후 “그럼 그거 누르면 누가 좋아지는데요?”가 면제 포기의 실제 한계를 드러낸다. 교정 예약을 이미 잃은 대가는 되돌려지지 않는다.
- 어머니는 도움이 안 된다는 말을 듣고도 직접 줄을 선택한다. 달걀 농담과 “달걀은 네가 사”가 관계의 온도를 남긴다. 정미경을 곧바로 용서하거나 감사하는 사람으로 만들지 않는다.
- 마지막 서인의 “없어”와 보내지 않은 추가 설명은 불편하지만, 보호까지 풀라고 할까 봐 숨긴다는 동기가 제시된다. 단순 전달 누락으로 처리해 정직한 인물로 교정할 필요 없다. 숨김의 비용을 남긴다.
- 조회자의 정체와 다음 접촉은 아직 모르는 위협이다. 현재 조회가 차단됐다는 사실과 묶음을 풀면 차단도 풀린다는 선택은 이해된다. 미래 답을 읽어 정당화하거나 배후를 확정하지 않는다.

숫자·대상 정리 후 같은 검수자가 변경 대조와 최종 전체 독서를 한 번 수행한다. 별도 점수표나 전편 줄거리 재진술은 추가하지 않는다. 다음 화는 별도 지시까지 읽지 않고 사용량을 반복 질문하지 않는다.
