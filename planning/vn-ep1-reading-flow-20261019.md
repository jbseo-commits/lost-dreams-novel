# 1화 체험판 — 생활감과 읽기 호흡 수정

- 작가 승인: 1화 체험판 전체 평가의 네 가지 개선에 대해 “음 좋아 수정해줘”.
- 기준 main: `f84308274217790880840b58512a63a9bdb4c560`.
- 작업 브랜치: `codex/vn-ep1-reading-flow`.
- 범위: 비주얼 노벨 1화의 집 그림, 표시 페이지, 결말의 조건 보기, 퇴직 경고 제목. 원문·설정·기존 읽기 웹과 다른 화의 공용 그림은 보존.
- 판정: 같은 독립 reviewer의 변경 부분 재검토 PASS. 음원 감상 품질·사람의 독서 시간·상업적 완성도 인증으로 확대하지 않음.

## 바뀐 독서 경험

1. **집의 생활 형편을 화면과 맞춤.** 아침·밤 배경, 식사·밤 CG를 1화 전용으로 수정했다. 작은 창 밖의 맞은편 건물, 바로 옆의 칸막이와 침대, 냉장고 앞을 막는 접이식 식탁이 같은 집으로 이어진다. 식사 CG는 서인 왼쪽·어머니 오른쪽 구도를 유지하며 따뜻한 관계를 살린다. 모바일에서는 전체 그림을 담아 두 사람의 얼굴과 달걀을 건네는 손이 잘리지 않게 했다.
2. **원문263개를161개 읽기 화면으로 연결.** 짧은 왕복 대사와 연결 서술은 2~4개씩 함께 보여 준다. 여러 화자의 대화에는 줄마다 이름을 표시한다. 장면 경계18곳, 시스템 카드, 표정·CG·음향 변화, “알아” 세 번과 마지막 암전의 문장들은 건너뛰지 않는다.
3. **결말의 강제 복습을 선택적 열람으로 변경.** ‘정산·수면 조건 다시 보기’를 열지 않고도 수동·자동으로 이어 읽는다. 열고 정보를 읽을 때는 자동 진행을 멈추고, 기존 선택 기록도 복원한다. 서인의 결정을 바꾸는 새 분기는 만들지 않았다.
4. **퇴직 경고를 사건 이름으로 표시.** 문서 제목은 ‘퇴직 의사 확인서’, 불이익 카드는 ‘퇴직 시 불이익 / 지우의 퇴직 확인창’으로 구체화했다.

## 원문·저장·연출 보존

`story-data.js`의263개 문장·화자·순서와 저장 키는 변경하지 않았다. 표시 묶음은 별도 `episode-one-reading.js`에서 계산한다. 묶음 내부의 이전 저장은 원래 source index부터 이어지고, 다음·이전 이동도 원문 좌표로 처리한다. 묶음 전체 텍스트를 자동 진행 대기 시간에 반영하며 실제 표시가 끝난 원문만 읽음으로 기록한다.

지난 이야기는 기존처럼 원문 문장별로 열람한다. 모달을 닫으면 현재 위치로 돌아온다. 독립 검토가 발견한 ‘모달 재렌더 때 묶음 전체가 백로그에 중복 추가되는 회귀’는 마지막 묶음 전체를 비교해 수정했다. 기존 백로그에는 클릭 점프 기능이 없으며 이번에 새로 추가하지 않았다.

`manuscript/`, `settings/`, `pilot.html`, `vn/story-data.js`, 공용 방·주방 그림 및 이전 식사·밤 CG가 기준 main과 같음을 `git diff --quiet`로 확인했다. 새 그림은 [생성 기록](../vn/assets/ep1/home-revision-provenance.json)에 도구에 전달한 실제 프롬프트와 참조 파일을 남겼다. 원본 PNG는 실행 환경에 보존하고 런타임 파일은 WebP 형식 변환만 했다.

## 실제 검증

- `npm test` (`vn/`): 9개 검사 파일 통과, 실패·취소·건너뜀0. 새 검사는 원문263개의 순서·전수 포함, 모든 옛 저장 인덱스, 이전 페이지 왕복, 연출 경계, 화자 표시와 조건 보기의 제한 범위를 검증한다.
- 저장소 CI `node --test tools/agent-dashboard/agent-loop.node.mjs`:10개 통과.
- **400×844에서161개 화면 전체 순차 조작**: 원문263개 표시 확인, 페이지 오류0·요청 실패0·가로 넘침0·본문 넘침0. 대표 지점은1440×900에서도 확인했다.
- 조건을 고르지 않은 상태로 결말까지 진행, 종막→2화 버튼과 2화의 기존 한 문장씩 진행을 확인했다. 마지막 암전 이후 새 오디오 소스 시작0.
- 이전 저장111 복원→이전110→다음114, 새로고침 후 이어 읽기, 원문별 지난 이야기 열람을 확인했다. 기존240번 선택 기록도 복원했다.
- 조건 보기의 터치·키보드 펼침이 원고를 진행시키지 않고, 미선택 자동 진행은 계속됨을 확인했다. 긴 묶음의 자동 대기가 첫 문장 분량으로 줄지 않는 것도 확인했다.
- 백로그 수정 후 설정·지난 이야기 모달을 각각4번 왕복해 현재 묶음4줄이 중복 없이 남고 현재 위치로 복귀함을 재확인했다. 모바일 식사 구도도 수정 후 다시 촬영했다.
- 단일 HTML 재빌드: 이미지·음원67종 내장, 스크립트 구문 검사 통과. 로컬 서버로 연 단일 HTML에서 새 읽기 화면 진입과 추가 자산 요청0을 확인했다. **`file://` 직접 실행은 관리자 브라우저 정책 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 미확인**이다. 이 제한은 우회하지 않았다.

문장 바로 표시 설정을 사용한 기능 검사이며 자연스러운 감상 시간이나 독자 이탈률을 실측한 것이 아니다. 음향은 기존 음원·제어를 유지하고 재생 경계를 검사했다. 직접 청취에 의한 음색·믹스 평가는 수행하지 않았다.

[검증 요약과 화면 해시](../vn/notes/ep1-flow-qa.json). 전체 순차 조작 원자료는 실행 환경의 `/tmp/vn-ep1-flow-evidence/verification.json`, 후속 검사는 `followup.json`에 보존한다. 전체 순차 확인 후 백로그·식사 크롭을 좁게 수정하고 해당 부분을 재검증했으며 전체 새 독자 실험으로 보고하지 않는다.
