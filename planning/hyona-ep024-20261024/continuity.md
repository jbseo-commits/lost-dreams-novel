# 제24화 사실·연속성 초기 검수

**판정: PASS.** 시간·동의·선지급 보상과 제공 권리의 처리·이름 사용 범위에서 필수 사실 수정은 찾지 못했다. 대상 `manuscript/ep024.md`는 337행·5,368자, 제목·구분선 제외 공백 제외 본문 3,926자, SHA-256 `c40f98c7729ab074cdd5dd7fd40b773bc78ff1173626de99936c40f1223b3508`이다.

## 읽은 범위

제24화 전체와 제24-1화의 이름 도용 컨설팅 첫 장면, 제25화의 새 광고꿈 모집 도입만 대조했다. 제23화의 익명 거절 직원과 김수현을 동일시하지 않았다. 제24-1화 인물의 발언은 사기성 컨설팅의 주장으로만 다뤘다.

## 사실과 연속성

- 08:03에 서인은 세르젠 보도자료의 `SEO-IN CONSENT STANDARD`와 자기 이름 사용을 처음 확인한다. 백윤하는 이미 법무에서 열세 통을 받았다고 한다. 이름 사용 문제와 계약 조건 확인을 별도로 요청한다. 서인은 제도를 만들지 않았고 이름 사용을 허락하지 않았다고 말한다. 보도자료 표기는 서인의 동의나 인증으로 취급되지 않는다.
- 김수현은 이름이 밝혀진 세르젠 협력사 야간 장비 관리직 참여자다. 그는 2.5 TOKEN 보상과 아이의 추가 교육 상담을 원해 직접 참여를 눌렀지만, 가족 생활 검증 크레딧이 이미 연결된 상담 예약에 쓰인다는 점은 신청 화면에서 알지 못했다. 그가 신청을 철회하고 반환을 확인하자 2.5 TOKEN은 빠르게 반환되지만, 크레딧은 이미 배정된 작업이 끝나야 반환될 수 있어 즉시 복구되지 않는다. 14:00 예약 확인 기한 전에 상담 자격이 사라질 위험이 생긴다.
- 11:06 무렵 문제를 확인한 뒤 세르젠은 우선 같은 상태의 철회자에게 회사가 대체하겠다고 한다. 13:00 공동 운영위원회에서 오늘 시작된 검증은 끝내되 신규 접수 확대는 중단하고, 크레딧 반환을 기다려야만 하는 사람에게는 반환 때까지 회사가 비용을 대는 안을 요청한다. 회사는 당일 한정 임시 대체를 승인한다. 신청이 제대로 동의된 것으로 인정되었다고 서명하지 않고, 기존 진행분만 마치며 새 조건은 다음 날부터 혜택별로 다시 받기로 한다. 22:00에 참여율 61%로 내려간 사실과 추가 안내 미발송도 이 제한에 부합한다.
- 이 결정은 오늘 한 번 시작된 시범과 아직 환자에게 확정 통지되지 않은 신규 접수 확대를 구분한다. 이미 진행 중인 검증을 중단하거나 새 접수 전부를 확정 시행하지 않는다. 이후 신청은 이용권별 손실·반환 조건을 확인하고 새로 선택하게 한다. 2.5 TOKEN 반환과 가족 크레딧 복원은 같은 처리로 합쳐지지 않는다.
- 제24-1화에서 김수현은 서인의 이름을 이용한 유료 인증 컨설팅을 의심해 서인에게 연락한다. 컨설턴트가 아르카디아 모델 v2.2와 ‘비공식 기준’을 안다고 하는 말은 해당 인물의 기만 주장으로 제시되며, 본문이 기술 사실이나 승인자 4의 정체로 확인하지 않는다. 제25화는 기업 의료 이용권과 별개인 이용자 광고꿈 추가 계약 모집으로 시작하고, 광고꿈 망과 기업 네 번째 검증의 연산이 같은 자원이라는 연결을 확정하지 않는다.
