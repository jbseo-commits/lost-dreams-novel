# 제176화 설계 · 누가 이 역사를 썼나

- 월요일. 도윤 집 작은 기록실(107). 도윤은 175 목록 첫 줄에 “넘어지지 않게.”만 씀. 가람이 “우리 집 말고 남의 집 걸로” 순서가 반복되는지 보기로 함(보관자 범위).
- FAILURE ARCHIVE / D.Y. INDEX의 세 상자(남부 정수장 배급 순번, 야간 교대 거부 행진, 공동 수면실 — 모두 제안). 원문은 그대로, 후대 색인(D.Y. INDEX 분류층, 107·116~124 회수)이 세 칸: 대신 정했다 무너진 사례 / 버틴 사람이 잃은 것 / ‘참고’(스스로 정해 별일 없던 소규모 사례, 거의 비어 있음). 원문에는 열두 집 약병 제비, 뒷줄의 다른 골목, 수면실 마지막 달 당번이 있음.
- 가람 “아빠가 역사를 지운 건 아니에요.” “그럼요?” “남길 순서를 정했어요.” 자녀 교육 목록(가람 자기 범위 사본)도 같은 칸 나누기. 몇 년 전 G.R. NOTE(숫자 반박)에 이어 새 주석 `사례 배열 원문과 다름. 맨 아래 칸 재검토.`(원문 미수정).
- 서인 파일(`외부 관찰 · 비개인화 · 본인 열람 가능`, 자녀 파일 다음 칸): 도윤이 건넨 자료 목록, 같은 세 칸, 서인 것만 ‘참고’ 칸이 비어 있음. 서인이 직접 “동부 27 · 노인정 · 30일째 · 윤 여사가 넷 다 한 칸씩 고른 화면.”(70 회수) 기입. “맞는 걸, 이 순서로 줬어요.” / “그 순서 말고 다른 순서로 읽어 본 적이 없어요.” 영향 단정 없음.
- 도윤 귀가: 파일을 요구하지 않음(“그럼 네 거지”), 빈 칸 질문은 “그 얘기는 따로 하자… 네가 정해.”로 178에 미룸. 점심 국수, 새 주석 읽고 “맞다.”
- 형제 단체방: 세아 “내 건 내가 볼게. 언니는 열지 마.” 도준 “나는 안 봐. 근데 맨 아래 칸에 뭐 있었는지는 나중에 말해 줘.”
- 끝: 세 상자·가람 목록·서인 파일 모두에 `D.Y. / GENERATIONAL CONTINUITY.` 날짜가 같은 몇 해에 몰림.
- 잠금: 편집 사실을 첫 공개처럼 쓰지 않음(색인=도윤 분류층은 기존). 11화 시술·광고방송 탈취·회복 가속 계획 미언급. 표기의 승인 의미는 175 서명 인정과 이어지되 범위 확정은 다음 화.
- (제안): 세 기록과 세부, 세 칸 색인, 새 G.R. NOTE, 서인 파일·분류·기입, 서인 업무 연기, 도윤 귀가·국수·“맞다”, 단체방 답, 표기 위치·날짜.
