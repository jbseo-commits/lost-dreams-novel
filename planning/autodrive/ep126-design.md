# 제126화 설계 · 사본에 남은 것

- 선행125 최종3549자·누적1/3·독립 사실/편집 본문PASS,126~130 적용안 사전PASS 뒤 집필한다. 주말이 지난 월요일, 서인·가람이 도윤의 허용된 비교자료 중 한 질문의 출처를 확인한다.
- 서로 다른 시기의 교육자료와 공개 강의자료 검색용 사본에 같은 잘못된 표기가 보인다. 원문 이미지와 비교해 현재 추출/검색용 파일에만 생긴 오류를 나누고, 추출일을 원자료 작성일이나 직접 전달의 증거로 읽지 않는다.
- 오타 가설이 약해져도 두 원문에서 질문 순서·사례를 대조하는 행동은 남는다. 비슷한 가상 배분 문제가 널리 쓰일 수 있다는 가능성을 인정하며 문구만으로 복제·조직 계보를 단정하지 않는다.
- 공개 강의자료의 제공/참고 표기와 당시 공개 강의 안내에서 가칭 윤태식에게 물을 공식 연락 경로를 찾는다. 내부 허용 교육발췌를 외부에 첨부하지 않고 이미 공개된 강의자료의 출처만 문의한다.
- 현재 교육 창구는 예전 강좌가 끝났다고 설명하고, 자료 보관/사용자를 통해 질문을 전할 수 있는지 확인한다. 개인 연락처를 자동 취득하거나 당일 만남을 일방 확정하지 않는다.127에서 실제 답과 시간·공개범위 동의를 새 장면으로 받는다.
- 실제 성과는 닮은 문장 가설과 분리해 ‘누구에게 어떤 공개본을 물을지’가 특정되는 것이다. 뒤에 다른 지역 자료의 유사 대목도 남지만 전달 표기와 경로는 비어 있어 전체 계보가 완성되지 않는다.
- 자료 작성/현재 사본생성·추출/후대 분류 시점 분리, 열람/개인메모/외부전달 범위 유지. 윤태식·강의·사례·검색용사본·문의는(제안). 불필요한19년/Line08/나이와 기술 비밀은 쓰지 않는다. 연출 구상만, 실제 구현·모바일 검증·7번 점수 없음.
