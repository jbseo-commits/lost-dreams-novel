# 제177화 설계 · 광고가 멈춘 이유
- 화요일. 169 후속 문의에 자료실이 외부 보관소(송출 사업자·보험사 분쟁 때 양측이 손대지 못하게 맡긴 사본, 합의서 ‘원인 미상’ — 제안) 작업 문서를 한 시간 현장 열람으로 허락. 세아·서인, 박현오, 조한길.
- 작업 흐름표: `REPLAY CHANNEL OVERRIDE`(114 기존) 아래 새 칸 `목적 · 일시 송출 중단 후 자율 수면 회복 관찰`, `예상 · 자율 선택 증가` ↔ 169 사후 집계(다른 꿈 문의 소수, 불안·불면 복귀 신청 다수). settings/12 확정(광고꿈을 멈추고 자율 꿈을 돌려주면 자유를 고를 것이라는 가설 시험)의 회수.
- 승인 서명: 이니셜 미해석, 등록 서명 대조 → 서명자 도윤(174 방식). 적용 `지정 구역 일부`(전 도시 아님, 범위 미확인).
- 탈취: 그날 밤 자정 무렵 재생 계통 보관 권한 한 줄이 외부 계정으로 복제, 모듈명 가림(미정 유지, settings/07). 계정 등록 번호 = 가람이 174 감사에 낸 교육 목록 접근 경로 번호(연결은 두 장 범위까지).
- 내부 메모(사건 한 달 뒤, 도윤 손글씨): `강제 일괄 적용은 실패한다. 돌려주는 것만으로는 고르지 않는다.`
- 조한길: 새벽 네 시 ‘꿈이 안 온다’던 여자에게 곧 고치겠다고 함, 사흘 뒤 복구, 그 사흘을 자기 몫으로도 여김.
- 현오 허락 범위: 목적 칸·대조 결과·적용 범위·메모 두 문장만 손으로 옮김, 접근표 불가. 세아는 가람에게 번호만, 도준에게는 물으면 한 줄로.
- 저녁 클리닉 지하 장부실(49의 자리, 도윤이 용기를 엎는 동작 회수). 서인 “제 파일 얘기는 다음에요.” “그때도 사람들한테 묻지 않았네요.” / “묻는 순간, 이미 그 질문을 할 수 없게 된 사람들은 어떻게 하지?” / “그 사람들 대신 묻는 권리가 도윤 씨한테 생기진 않아요.”(원안 ‘형’→‘도윤 씨’). 49 “안 했어” 닫음: “여기서 도윤 씨가 안 했다고 했어요.” “응.” 한 얼굴: “첫날 밤에 한 사람이 울면서 다시 켜 달라고 했어. 잠이 안 온다고. 신청한 사람도 아니었어.” “알았지.”(위험 인지). 사흘 유지 이유 “돌아가지 않겠다는 사람이 나올 줄 알았다” “몇은.” 도윤: 메모·서명·중단 결정 인정, “켜 주지 않았어. 사흘 동안.”
- 잠금: 탈취 모듈·피해 규모·수신 범위 미정. 잠든 뇌공급/지급가치 비밀·R·HOLD 미개방. 시술(178)·회복 가속(179) 미언급. ‘형’ 없음. 결론형 문장(“그래서 다음엔 끊지 않았다”) 쓰지 않음.
- (제안): 외부 보관소와 분쟁·합의서, 목적·예상 칸 문구, 접근 권한 변경표와 복제 시각, 계정 번호 일치, 메모 작성일·문구, 한길의 새벽 통화, 현오 허락 범위, 세아 전달 방식, 사흘.
