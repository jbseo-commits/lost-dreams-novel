# 제174화 설계 · 동의하지 않은 아이들

- 재개 범위: 2026-11-19 작가 지시 “다음 체인집필 진행해줘”의 체인 연속(173 본문 PASS 뒤). 문체는 173과 같이 사건·직접 대사 중심.
- 사건: 목요일 오전 세아가 가람이 타인 내용을 걸러 낸 자기 항목을 열람(173 인계). 어릴 적 자주 꾼 ‘손을 놓은 광장·회색 털장갑’ 꿈이 저녁 이야기 항목에 있고 `외부 제공 단서 · 1건 · 출처 표시: 없음`. 외부 단서의 주인은 열지 않음(타인 원본 비개방). 165 연동 검토실에서 도윤이 짚은 ‘출처 확인 ≠ 먼저 보여 줌’이 여기서는 둘 다 비어 있음.
- 버스: 주머니의 여분 장갑이 회색 털장갑. 버리지 않음(“따뜻하잖아요. 그건 내가 알아요.”) — 개입이 현재 취향 전체를 결정했다고 환원하지 않음.
- 오후 기술원 감사 접수실(연동 검토실 아래층). 박현오가 가람의 월요일 문의에 대한 답으로 이번 건 접수 담당 배정. 권한: 각자 오늘 정해 넘긴 것만 수신, 서명·판본·실행 순서 대조, 타 제공자 개인 원본 불가. 비용: 서명 대조 당일, 실행 순서는 다음 주까지.
- 제출 범위(각자 새로 정함): 가람 — 기록 존재·보관 목록·등록 이력(내용 제외), 제출자로서 아빠 이름이 감사 서류에 오르는 망설임 / 세아 — 자기 항목 승인 칸·출처 표시 칸·판본, 광장 단서 원본 제외 / 도준 — 점심시간을 쪼개 와서 실행 표시 줄만, 제목·4분 줄 제외, 사례 비공개·감사에만. 가람 승인 칸은 범위 밖 → 토요일 직접 묻기로.
- 대조: 같은 계획·반복 주제(대리 결정의 비용), 세아 항목의 실행 판본에서 출처 표시 누락. 이니셜로 정하지 않고 등록 서명 대조 → `승인 서명 · 등록 서명과 일치 / 사후 수정 흔적 · 없음 / 서명자 · 도윤.` 출처 표시를 뺀 결정 기록은 받은 범위에 없음(의도 미확인). 승인 설명 “정서 안정 및 가치 판단 회복 지원. 반복 주제 우선.” 현오 “치료 기능도 있었습니다”(수면 안정 지표 실제 개선) → 세아 “그래서 치료인 줄 알고 자랐어요.”
- 세아가 자기 자료 제공 조건 칸에 직접 `SOURCE TAG MANDATORY / NO FAMILY EXCEPTION`. 자기 자료에만 붙는 조건, 도시 규칙 아님.
- 서인은 결과 사본 수신을 거절(“제가 들고 있으면 누가 먼저 저한테 물어볼 거예요. 그럼 제가 대신 말하게 되고요.”) — 가족 진실을 대신 발표하지 않음. 세아 비용: 오전 회의 연기, 검산표 밤 작업.
- 끝: 가람이 도준에게 토요일 셋이 아빠에게 묻자고 문자, 도준 “ㅇ. 대신 내 질문은 내가 함.” 세아 질문 셋 중 첫째 옆 “아빠.”, 둘째·셋째는 토요일까지 남음(175 대면·직접 인정 몫).
- 잠금: 도윤의 인정·의도는 175. 이니셜/D.Y. 의미 미확정 유지(서명 대조는 서명 값의 일치이지 이니셜 해석 아님). CROSS-SUBJECT 전모·타 제공자 정체·176 이후·R·광고꿈 비밀·HOLD 미개방. 나이·기간·강도 수치 없음. ‘형’ 없음, 메시지 쓰고 지우기 없음.
- (제안): 광장 꿈·회색 털장갑·여분 장갑, 외부 제공 단서·출처 표시 칸, 현오 접수 배정·권한·소요 시간, 각자 제출 범위, 승인 설명 문구, 수면 안정 지표, 서명 대조 결과 표기, 제공 조건 칸, 서인 사본 거절, 세아 연구실 일정, 토요일 방문 약속.
