# 제196화 설계 · 내가 없어도
- 일요일(195 토요일 밤 다음, 쿨링 첫날). 아침 의무실(타일 세다 다시 셈 — 다시 세는 건 좋은 신호, 혈압 조금 내려감). 가람 문자 “아빠는 오늘 장부실에 안 나왔어요. 집에 있어요.”(서인 답 못 함).
- 밤 10시 하진 전화: 어머니가 오늘 밤 그만하고 싶다, 정하러가 아니라 옆에. 어머니가 서인 휴대폰을 맡음 “가서 앉아만 있어.” 택시 창밖 붉은 점(세지 않음).
- 9층(54 카디건·156 탁자 내보낸 자리 판독 의자): 10시 반 교대 직후. “그날 집에 와서 생각했어요. 나도 모르겠다고.”(195 회수) “하진이가 연결 안 하겠다고 했을 때… 부러웠어요.” “서인 씨라면 누르겠어요?” “그건 제가 고를 수 있는 게 아니에요.” “그럼 내가 고를게요.” 마지막 판독 하나 끝까지(9분, 이유 세 줄) “이건 끝내고 싶었어요.”
- 23:41 `WITHDRAWAL REQUEST · ANCHOR · RECEIVED 23:41`. 예전 빨간 창 “당신이 빠지면 의존 중인 환자에게 위험할 수 있습니다.”(숫자 없음, 열한 번 다시 앉음, 제안) → `ALTERNATE PATH · STARTING` / `RISK DISCLOSURE · PUBLIC`(드문 판독 세 건 평균 40분 지연, 응급 대기열 별도 보호, 병원 통지) → 서부 의사(자문 당직) “40분이면 기다릴 수 있어요.” → `TRANSFER CONFIRM · 4/5 · 1 EMPTY (REQUESTER)`(세아·우석·동남 대표 정수장·위원회 야간 당직, 빈 칸 그대로) → 서인 숫자가 줄 서려다 손을 펴서 멈춤(하진 봄) → 원안 “철회 요청 승인됐습니다.” “그럼… 내일 다시 와야 합니까?” “아니요. 원하시면 다시 오실 수는 있습니다.” → `CONNECTION END · 23:58`, 패치 자국, 붉은 점 꺼짐, “생각보다 조용하네요.” 창문.
- 원안 ‘귀가 시간’ → 자는 시각 스스로(“한 시에 잘래”, 알람 없이). 보리차. 하진 “오늘은 엄마가 답했네요.”(156 “그건 하진이가 답했어요” 회수) “저 아무것도 안 했어요.” “그래서 고맙대요.”
- 끝: 세아 캡처 `WITHDRAWAL COMPLETED / SERVICE CONTINUES`, 승인란 넷+빈 칸, 서인 이름 없음, 확대 안 함, 휴대폰 다시 맡김. 월요일 아침 세아: 세 건 37·41·44분 종료, 하진 어머님 칸 비워 둠. 어머니 “이건 판단이야?” “그냥 읽는 거예요.” 서인이 가람에게 “밥은 드시라고 전해 주세요.”(180·190 결).
- 잠금: 서인 판단 안 함(쿨링), ‘형’ 없음, 30일 없음, 도윤 직접 등장 없음.
- (제안): 철회 버튼·절차 문구·수치, 예전 경고문·열한 번, 야간 당직, 시각.
