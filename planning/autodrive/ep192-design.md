# 제192화 설계 · 틀릴 시간을 없애다
- 목요일(191 수요일 밤 다음). 신문 앱 `사람이면서 사람을 대체한 최후의 기준.`(사진: 기술원 정문, 휴대폰 보는 옆모습), 어머니 “너 이렇게 찍히는 거 싫어하잖아.” 반 공기. 정지윤: 소아 열 내림(자는 사진). 세아 “근거가 한 줄 아래로 내려가면, 제가 다시 물을게요.”
- 9시 남은 59시간, 충돌 서른 넘음. 설명 생략 “시간이 없습니다.” 참관 위원 둘(대기 칸만 촬영, “보고서로 나중에”, “숫자가 말해 주잖아요”). 서인 처음으로 목소리 높임 “지금 줄에 애들이—” / 세아 “애들 있는 거 알아요. 그래서 묻는 거예요.” 과부하 2단계(과잉 확신): 지금이 제일 잘 보인다, 의심하지 않음.
- 11시 우석(원안): “이번엔 어떻게 알았습니까?” “그냥 보였어요.” “그럼 검증은요?” “나중에요.” 여백 기록·물음표 셋·점 둘. “장부실에서는 모르면 비워 뒀잖아요… 이번엔 비워 둔 칸이 하나도 없어요.”
- 오후 1시 서부 센터 의사: 191 일곱 번째 투석 결정이 실제로 도움(내일까지 밀렸으면 위험) → 근거 한 줄이라 기록 불가 → 서인이 근거를 기억 못 함(재확인 브레이크 약화 후유증).
- 오후 3시 스물두 번째: 동남 투석 여섯 명 새벽 4시 이동(냉각 여유·검증 공석, 깔끔한 답) → 12분 뒤 동남 대표(정수장 야간조, 쉬는 날) 현장 반론: 새벽 4시 버스 없음·첫차 5시 40분·다섯 버스·한 명 휠체어·할증. 공개 화면 접속자 오백, 자식들 전화. 수정(다섯 오후 칸 유지, 일반 재검증 밀림, 대기 +4분), 근거 다섯 줄 “제 첫 결정은 이동 수단을 보지 않았음.” 대표 “다음엔 누가 전화해 줘요?… 오늘은 쉬는 날이라 본 거예요.” 현장 확인 칸 추가 → 세 번째 이동 사례에서 건너뜀 → 세아 지적 → 확인(같은 답).
- 5시 위원장 “내일 위원회에서 연장 얘기가 나올 겁니다.” 7시 남은 49시간, 손끝 저림·왼쪽 귀 소리·점심 거름. 우석 근거 길이표 “제일 긴 게 틀렸던 거네요… 틀린 걸 고칠 때만 길어졌어요.” 서인이 서부 의사에게 정리: `결정은 유지. 결정 당시 근거는 기억나지 않음. 재검토 필요.` → 감사 답.
- 끝: `ARBITER OVERRIDE REQUESTS: INCREASING`(비필수: 지역 재건 순위·교육 크레딧·비필수 재검증), 넷 → 열일곱, 수신인 서인. 지역 재건 순위를 열자마자 답이 옴 → “제가 보기 전에요” 전부 범위 밖 반송, 그사이 두 건 더. 9시 세아 담요, 요청 칸 스물셋.
- 잠금: 개인화 AI 미사용, 예지 아님, 현장 반론이 실제 수정, ‘형’ 없음, 30일 등 없음, 도윤 무등장.
- (제안): 기사 문구, 시간 수치, 참관 위원, 동남 투석·버스 시각, 현장 확인 칸, 근거 길이표, 요청 수.
