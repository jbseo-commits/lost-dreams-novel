# 제198화 「철회할 수 있는 세계」 설계
- 토요일, 쿨링 이레째(마지막 날). 오전 공개 실증 `PUBLIC TRIAL · JOIN / LEAVE / REJOIN / DECLINE` + `MINOR · SELF + GUARDIAN · BOTH REQUIRED` / `SOURCE TAG · SHOWN BEFORE CONTENT` / `CONSENT CHECK · INDEPENDENT REVIEWER` / `EMERGENCY EXCEPTION · POST REVIEW WITHIN 24h`(제안). 단말 네 대, LEAVE 남자 22분 공개(제안).
- 오후: 동부 아동병원 생후 여덟 달 대사 이상(제안) + 북부 재참여 앵커 SELF LIMIT 4h 도달 LEAVE → RECHECK DELAYED, `ANCHOR RECALL REQUEST · SEND?` 보내지 않음. 서인 복귀 시도 → 세아 "서인 씨가 와야만 성공한다면, 이건 실패한 설계예요." 로비 대기. 임시 대체 경로 2+2, 보호자 동의 영상, 가족 설명, 3:50 RESPONSE LOW, 4:25 `ALT PATH CONFIRM · 4/4 · DOSE ADJUSTED`(서인이라면 처음 용량), 혈당 안정·중환자실 하룻밤·비응급 두 건 지연. 북부 앵커 문자 "한 시간은 더" → 세아 "네 시간 지켜 주셔서 고마워요."
- 밤: 사후 심사(24h)에서 발견 `EMERGENCY CONTINUITY · OPENED · RARE CASE + ANCHOR LEAVE · 14:12` → `CONTINUITY EXCEPTION · OPERATOR CONFIRM: SKIPPED` → `LEGACY CONTINUITY PATH · FAIL MODE: OPEN` → `LEGACY AUTH · REACTIVATED · 17:46` → `SUCCESSOR DELEGATION: ARMED`(이름 가림·시점 미정) → `CONSENT CHECK BYPASS — PENDING EXECUTION`. 도윤은 만들지 않고 기다림(160 회수). 레거시 실·출입증 6시·차단 승인 두 시간(제안). "판단하러 가는 거 아니에요. 그 사람한테 가는 거예요." "그건 설계가 아니니까요." 어머니 "이건 판단이지." "그럼 갖고 가." "달걀은 내일 내가 살게." 택시 도윤 무응답·가람 '파 한 단'. 미회복 상태.
