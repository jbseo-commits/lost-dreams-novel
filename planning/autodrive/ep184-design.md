# 제184화 설계 · 누구의 몫인가
- 화요일 새벽 지우 문자: 동생 답 “같은 데 하나, 다른 데 하나”, 다른 데가 더 마음에 들지만 원서 그대로, 내년에 또 물음. 서인 엄지(쓰고 지우기 없음).
- 화요일 오후 청산위원회 공개 심의 공고(수 16시, 시청 대회의실). 안건 A 시장 우선 / B 전면 긴급 배급(부속서: 기준자 연결 의무 연장) / C 회복 우선(제안자 연합 + 외부 연구 협력 계정) / D 필수 보장·공개 재검증 하한·비필수 누진 비용·개인별 철회권(183 조서가 감사실 통해 안건화, 제안자 서인). 어머니 방청 희망.
- 화 밤 선점(보강): `북부 냉각 용량 18% · 예약 확정 대기 · 확정 시각 수요일 18:00.` 예약자 = 182 단가 인상 사업자, 동시에 C 지지 성명. 서인 가지치기: 열파 때 해지 순서(동부 공공 병원 단가 고정 계약 먼저, 고급 비필수 끝까지). 세아: D 통과 시 확정 전 예약에 누진 비용. 세아 경고(교대 근무 대표). 서인 일정 변경 요청 → 수 8시 통지, 10시로.
- 수 10시 심의: 동남 권역 대표 불참(야간 정수장 근무, 8시 통지). A 경제학자(덜 급한 수요 = 돈 덜 있는 쪽)·작은 검증소 남자, B 구청 재난 담당, C 도윤(원고 없이, 가람 셋째 줄) + 연합 담당자, 노인 “잃어버린 게 없으면?” “그럼 끄시면 됩니다. 다음 날 바로요.” 도윤 “부자는 틀릴 기회를 삽니다. 가난한 사람은 처음 나온 답을 운명이라고 배웁니다.” 서인 “도윤 씨 말에 동의합니다.” “그래서 누구도 남의 첫 질문을 대신 정할 권리가 없습니다.” D 불완전 인정, “제일 덜 나빠서요.” 두 번째 값 미정.
- 하진의 어머니(앵커 가족 대표, 제안; 156 현역 기준자·자기 선택으로 계속): B 부속서 반대, “둘 중 하나만 고르라는 표는 찢겠습니다.” 견본 찢음 → 수정 동의. “오늘은 제 차례라서요.”
- 11:40 의결: D 한시 승인(지역별 검증·재정 재심사), B 기준자 의무 부속서 삭제, C 부결, 기존 계약 경로는 대상 아님(서부 예비 경로 잔존 = 도윤 측 일부 권한). 12:30 `북부 냉각 용량 18% · 예약 일부 철회 · 9% 공공 계약 전환.`
- 도윤 “잘했다.” “냉각은 네가 맞혔어.” “동남 권역은 봤냐.” 가람 “어젯밤에 혼자 몇 번 했어요. 부엌에서.”
- 비용: `동남 권역 · 비필수 재검증 하한 적용 · 지역 검증 미완료로 1주 연기.` 대표 통화 “다음엔 하루 전에 주세요. 그럼 가요.” 어머니 “너는 왜 안 찢었어?” → 서인은 시각을 당김. 메모 `동남 권역 · 1주 · 내가 당긴 시각.` 고정 (191~195 씨앗).
- 잠금: ‘형’ 없음, 4.8배·1.8초 없음, 도윤 패배 아님, 수치 18%·9%·1주만.
- (제안): 위원회·일정·장소, 안건 구성 문구, 선점 줄, 해지 공시, 동남 권역·대표, 의결 조건, 철회 9%, 인물들.
