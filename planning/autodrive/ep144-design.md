# 제144화 설계 · 고르기 전에

-143 최종 독립 본문PASS 뒤 집필.수요일 세아의 짧은 기술 검토와 기관 담당자의 새 문안 승인부터 실제로 얻는다.기관 원표/내부 견적은 전하지 않고 새 가상 서비스 선택지와 견적의 좁은 뜻만 다룬다.요금 인상/임상·현행망 성능 증명/몸 분리 성공은 없다.
-작은 검토는 큰 읽기 모임을 다시 예약하지 않고 서로 다른 생활 자리의 짧은 자발적 대화 세 번으로 구현한다.태호는 가게에서 허락한 틈,정미는 허락한 짧은 통화,어머니는 저녁 식사 자리다.각자의 지금 일과 사용 목적이 질문을 바꿔 서인의 답 모으기 계획을 실제로 좁힌다.태호·정미는135의 준비 노동 거절을 유지하고 서인이 새 시간/범위를 묻는다.
-선택지는 실제 가격표가 아닌 가정이다.비싼 선택을 원한다는 답과 실제 돈을 낼 수 있음/보편 접근에 동의함을 구별한다.응답 밖으로 빠지거나 조건을 먼저 묻는 선택도 양식에 생겨야 한다.다수/소수의 말투만 바꿔 한 결론으로 수렴시키지 않는다.
-어머니 출처는47·67의 반말,달걀/자기 돈과 선택,100 잠든 모습이다.현재 건강 악화·요금 인상/빈곤 사실을 새로 추론하지 않는다.살림 행위를 하며 실제 고를 수 있는 범위를 묻는 생활 대화로 쓴다.광고꿈 비밀/사적 앵커 가문은 전하지 않는다.
-세 사람의 새 동의는 서인 질문 초안에 반영하는 사적 메모에만 한정하고 인용/외부 배포는 따로 묻는다.소수 응답은 대표투표/정책효과/대중 합의가 아니다.145의 후속 설계에서 누가 응답을 거절할 수 있는지/누가 확인 노동을 맡는지 실제 질문으로 이어간다.143 목요일 계산은144 끝에도 미래/확인 전이다.
