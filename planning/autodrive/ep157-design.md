# 제157화 설계 · 기다리는 동안

-156 새 읽기 요청 뒤 월요일 소현/나경의 실제 시간 답과 유료 자료실 예약/서인 절반 부담을 얻고 화요일90분 모임을 연다.태호는 새 모임 안내를 읽고 생활비 질문을 새로 신청하고,냉각 증설 계획 공고를 든 신연주는 새 성인 주민이다.세아는 공개 기술 표현/도윤은 비용질문이라는 새 유한 참여를 택한다.정부 공청회·시민 전체 대표/기관 운영 승인 자리가 아니다.
-현역 가족의 사적 문장/문서/집·이름·권고 기간은 가져오지 않고156허락의 대화 영향 정도만 말한다.음성 한 사례와 미독 냉각/물류를 나눠 공개조건에서 담당 운영자·계약/자원 범위를 확인해야 기간/비용을 물을 수 있다고 읽는다.분류가 실측 전환 일정/도시성과가 되지 않는다.
-태호의 현재 계약/꿈 선호와 생활 몫,나경 자신의 안내/재문의 노동,소현의 현재 연결을 더 유지하는 비용,연주의 새 공고/금요일17시 마감을 서로 다른 현재 부담으로 놓는다.증설은 의견을 받는 계획이고 소음·전력 영향/배정·반대 집계 등은 담당에 물을 일이지 현장에서 검증한 피해/정책이 아니다.연주는 자기 의견·문의만 고른다.
-서인은 같은 마감 시각을 다시 읽는 감각 이상을 보이고 세아가 알아채 물/실제 쉬는 틈이 생긴다.공동 큰 비용표 읽기를 미룬다.나경은 정한 시간에 나가고 이후 읽을 범위를 다시 묻도록 한다.연주는 공고 담당에 자기문의/의견,서인은 자기 설계의 자원 조건·계약 생활몫·안내/재문의 담당을 새 접수한다.태호의 허락은 익명 질문 문안만이며 이용내역/금액 공개가 아니다.소현은 공개 자원 계약 자료를 새로 확인할 사람/시간부터 묻고158그 답을 잇는다.
-질문표에 기다리는 동안 누가 부담/언제다시묻는지 열을 실제 추가하고 현재 맡은 일/외부 미답을 구분한다.못 읽은 비용표를 혼자 읽었다고 공동 검토를 완료하지 않는다.전조는148의 후속이며 진단·완치/이전 질병 지식으로 만들지 않는다.새 참여/장소·자료/주민/공고·업무와질의/허락은 (제안).3500~5500자·첫저장 뒤 누계3회/독립 본문 게이트.연출은 공고시각 재독/물·빈 의자/못 읽은 표이며 구현·모바일 미검증·7점 없음·미공개.보호 문서/웹/VN 변경 없음.
