# 제115화 설계 · 먼저 배운 사람

- 선행114 독립 사실·편집 본문 PASS,3693자·누적1/3. 연출미검증·미공개. 115 첫 저장 전 초안 버퍼에서 실제 장면과 분량을 확인했다. 수정0/3.
- 금요일 저녁 도윤의 집. 서인이 교육에 관해 직접 질문할 시간을 청했다. 다음 날 토요일은110금요일에 잡은 세아의 자력 자료 열람이며111월요일 기준 이번 주 토요일로 이어지는 같은 약속이다. 가람은 목록을 남기고 자리를 비웠다.
- 현재 행동: 도윤이 세아가 찾을 것 같은 실패 기록부터 골라 놓는다. 서인은 들어 줄지 묻다가 어떤 자료를 골랐는지와 실제 요청받았는지를 묻는다. 과거 교육과 내일의 자료 준비를 한 가지 죄로 판정하지 않고 각각 질문한다.
- 도윤은 아이들에게 기억을 다시 짚게 한 교육, 좋아할 답이 있던 사실, 중단한 아이가 있었다는 자기 관여를 직접 답한다. 도준의 고백이나 세아의 개인 말·기록을 서인이 대신 전달하지 않는다. 나이·훈련 연표·특정 자녀의 상세는 확정하지 않는다.
- 서인은 도윤이 더 큰 자백을 하길 기다리는 자기 질문도 끝이 없어질 수 있음을 경험한다. 자기 한 달 초안은 여전히 가방 속 보류 상태다. 이 대면으로 고쳤거나 정당화된 것이 아니다.
- 도윤 자신도 그 교육에서 자랐다고 말하고 자기의 오래된 ‘참조 적응 과정/후계 학습 자료’ 겉표지와 빈 질문 첫 장만 직접 보여 준다. 이름·가족 코드·출생일을 조합해 소속을 밝히지 않는다. 정확한 계열·탈취·사상 주입은 미공개.
- 결과: 도윤은 내일 열람 자료를 미리 고르는 대신 상자의 분류표를 보이게 놓고, 서인이 나간 뒤 무엇을 해 두면 좋을지 전화로 직접 묻는다. 서인은 도윤의 책을 가져가지 않고, 그의 본인 이야기를 다음에 더 물을 가능성을 남긴다. 책은 자백 증거가 아니다.
- 카메라: 바닥의 상자·골라 둔 실패 기록→현재 질문에 멈춘 도윤→질문을 끝내는 권한과 의자→도윤의 옛 교재 첫 장→원래 상자와 다음 날 열람 준비. 새 교재 신청·기술 시연 수업을 반복하지 않는다.
- 도윤의 어린 시절 기억·옛 교재·현재 방문/상자 준비는 (제안)으로 notes에 보존. 도윤이 먼저 배운 사람이라는 가능성은 보이되 정확한 reference-line 공개를116~120에 남긴다.
- 연출 구상: 본문 뒤 교재의 빈 응답과 아직 오지 않은 열람자의 자리를 나란히 남김. 추가 주입·유전·행위자를 설명하는 자막 없음. 웹미구현·모바일미검증·7번점수없음.
