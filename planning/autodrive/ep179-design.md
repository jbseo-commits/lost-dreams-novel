# 제179화 설계 · 되찾게 할 것이다
- 목요일 밤 서인→세아 사진, 금요일 오전 기술원 연동 검토실(박현오 접수). 신청 개요만 열람(본문은 검토 위원). `RECOVERY ACCELERATION / MEMORY CONTINUITY`(160 연구 소개 제목과 같은 이름의 외부 연구 협력 계정), `연동 대상 · 회복 지원망 / 전환용 TOKEN 청산망`, `적용 시점 · 공공 위기 또는 청산 재편 국면`, `대상 · 청산망 이용자 전원. 동의 확인 후 해제 가능.`, 처리 순서 `1. 결핍·억압·미뤄진 꿈에 대한 연상 단서 선제 제시 / 2. 단서 출처 표시 / 3. 이용 동의 확인`, `효과 · 미검증. 기존 사례 소규모.` 청산 창구 확인 버튼 앞 빈 회색 상자 예시.
- 170 서인 문안 `REPLAY ETHICS / SOURCE-FIRST`(도윤이 앞부분을 함께 읽고 도움)의 역순 — 세아 노트로 대조. 형식 심사 통과, 남은 것은 청산망 운영 책임자의 연동 승인 서명, 청산 재편 공고 전. 서인은 공개 의견 창구에 세 줄(신청자 이름 없이) 제출.
- 현오: 신청자 확인되면 알려 달라, 지난달 출처 순서 얘기한 자리에 자기도 있었음. 세아: 이번엔 형제 셋에게 바로(“청산망은 오빠도 서야 되는 줄”), 신청자 칸 비움. 도준 “이거 아빠 거임?” 가람 “저녁은 따로 먹을게.”
- 저녁 도윤 집(그릇 둘, 가람 작은 방). 도윤의 구별(원안 보강 179): “회복 센터에 제 발로 온 사람한테는” 출처 우선이 맞다 / 청산 줄은 다 서야 해서 서는 줄 / 순덕 할머니 바닷가(하경에게 들음, 69·70 회수) “자기 바다를 먼저 봤으면” / “나는 아무것도 빼앗지 않아. 빼앗긴 걸 먼저 보여 줄 뿐이야.” / “난 문을 안 잠가. 누구든 다음 날 다시 켤 수 있어.” / 어머니 “안 잃어버리셨어. 달걀 사러 가시잖아.” — “그건 누가 정해요.” / 기존 사례는 “그 사람들한테 묻지 않고는” 말 못 함(아이러니) / 아이들은 잘못이었다 “그땐 애들이었어… 다 큰 사람들이 고를 힘을 잃은 거야.” 서인은 반박을 미룸(186 몫): 지금 꺼내면 도윤이 놓은 순서대로 나올 것 같아서.
- 끝: “공고는 다음 달쯤”, 도준에게는 “도윤 씨가 직접 하세요”, 청산망 책임자는 “네가 찾아”, “아직 아무것도 안 켰어. 켤 수 있게만 해 둔 거야.” 공개 조직도의 연동 승인 책임자 칸 공석(180 고리).
- 잠금: 전국 적용 미실행, 효과 미검증, 상자 내용 미정. 잠든 뇌공급·R·HOLD 미개방. ‘형’ 없음(형식 심사의 ‘형식’만). 30일 언급 회피.
- (제안): 개요 각 칸 문구, 형식 심사·서명 절차·공고 시점, 공개 의견 창구, 현오 대사, 단체방, 도윤 대사들, 파 한 단, 조직도 공석.
