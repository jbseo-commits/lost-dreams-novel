# 제161화 설계 · 회복한 다음의 선택

-160 실제 질의 뒤 월요일 센터/세아 새 답과 방문목적·자료/시간 범위를 얻고 화요일 센터 설명실에 간다.담당 의사 정지윤은 기존 성인 회복지원 프로그램을 설명한다.성인 고민정은 자기 정기면담을 별도로 마치고 오늘 허락한 절차/비개인예시만 방문자와 읽는다.서인/세아가 치료를 시작/설계하는 시험이 아니다.
-민정이 지금 원하는 도움은 수면 안정과 자기하루를 쓰는 일이다.그가 느낀 호전은 개인발화이며 임상효과의 보편실측이 아니다.회복지원 뒤 광고꿈 이용경로를 묻는 선택과 상태/주의사항·진료는 따로 확인한다.현재다른선택을 도움실패/성과응답으로 묶지 않고,회복뒤 목표를 더 찾기보다 자기약속/다음면담을 정하는 실제 행동이 서인의 질문문안을 바꾼다.서인이 상품선호의차이를 처음배우는 반복이 아니다.
-민정은 안내음을 실제 멈추고 글로 다시읽는 도움을 택한다.자기속도/앞문장재독과 준비된단서/실제재생의 상태를 구분한다.ASSOCIATION PRE-WARM는 이프로그램의 다음회복안내 단서준비라는 현재설명만 얻고,R-SESSION/SOURCE TAG AVAILABLE은 출처정보를 붙일 수 있다는 표시다.옛R·135교육본문/기억개입·도윤범죄 증거가 아니다.
-비개인예시의 순서/안내중단·읽기선택은 두사람만볼메모로 새허락하고 개인상태/말은 현장에서듣기 범위이며 이름/생활기록·발언을밖의자료에옮길 허락은 없다.공개프로그램설명/허락된비개인예시문안과 서인자기질문만 따로 남긴다.직원이 다음면담을 맞을시간에 설명을끝내고 추가질문은문의로돌린다.서인은 공개목록의 다음운영기관에 자기모의범위를밝히고 새관찰/자료범위 질문을 실제 보낸다.162 새답/범위는 미래다.
