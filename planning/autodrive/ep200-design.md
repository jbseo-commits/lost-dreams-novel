# 제200화 「네가 정해」 설계
- 세 해 뒤(제안) 봄 화요일. 서인 후유증(타일 다시 세기, 한 달 두세 번), 확인자 쉰몇 명 중 하나(단독 중재석 폐지), 42분·노란 칸·투석 간격 수정 1회 표시(우석). 어머니 광고꿈("바다는 바다더라") 변명·설득 없음.
- 공개 기록: JOIN/LEAVE/REJOIN/DECLINE 수치(제안), `LEAVE · 사유 미기재 · 기록 정상`(철회=배신 아님), 해제 집 평균 19분 더 대기(서인 혈압 약 23분), 앵커 가족 보상 협상 중 세 해째. 하진의 어머니 자발 앵커 주 두 번 세 시간(사유 칸 비움).
- 가람 `D.Y. 기록 · 공개 1차` 맨 위 `SUCCESSOR DELEGATION: REVOKED BY HOLDER` 설명 없이(일 년 망설임), 생일 말 제외, 맞은/틀린 예상 모두 주석. 세아 `UPDATE · SLEEP PACKAGE 7.3 · SOURCE TAG MISSING · DEPLOY BLOCKED`, 아버지 설계 검증 가능 부분·작성자 이름만, 보상표 또 올림. 도준 원안 대사, 연인 광고꿈, 파. 지우 컵.
- 밤: "형, 오늘 이상한 일이 있었어요." 쓰고 지움(200 전용). 동남 정수장 사택 여자·열한 살 아이(197 동일인 단정 없음) "엄마. 오늘 광고꿈 켤까?" → 최종 문장 "네가 정해."
