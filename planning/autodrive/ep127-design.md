# 제127화 설계 · 문제를 빌려준 사람

- 선행126 독립 사실·편집 본문PASS 뒤 집필한다. 월요일 문의 전달/본인 답 미수신으로 끝났으므로, 다음에 본인의 응답과 설명할 자료·시간·장소 동의를 새로 얻는다. 예컨대 화요일 응답을 받고 수요일 교육실 물품 정리 전에 만나는 사건이다.
- 가칭 윤태식은 폐쇄 공공 연구 공간에서 전산 자료를 정리하던 경력이 있는 현재 보관자(제안)다. 나이·기관명·정확한연대는 불필요하면 쓰지 않는다. 자기 교육자료/물품 정리를 마칠 목적과 시간이 있으며 무한히 계보 질문에 봉사하지 않는다.
- 본인이 당시 받은 일반 교육용 자료와, 지역 강좌에 건넨 자기 수정본/보낸 경위를 직접 정한다. 개인 신경기록·공식 비공개 데이터가 아니라 그가 지금 보여 줄 수 있는 일반 사례의 사본이다. 어떤 권한을 가진 자료인지 장면에서 구분한다.
- 사례를 좋아해서 수업에서 조건을 바꾸어 다시 고르게 했다는 생활 목적을 가진다. 혁명 조직에 보태려던 의도로 소급하지 않는다. 지금 그 뒤 다른 운동 자료와 닮았다고 들으면 모르는 부분을 솔직히 남긴다.
- 자료를 직접 받았다는 기억, 현재 남은 사본/수정본·전달 메모, 당시 원본의 현재 상태는 다르다. ‘버렸겠지’라는 말이 나오면 추측으로 남긴다. 실제 확인된 것은 자신이 받은/수정해 건넨 특정 구간이며 모든 문서의 계보가 아니다.
- 물건은 본인이 고른 한정 복사본과 메모를 담은 별도 저장매체/인쇄물이다. 전체 저장장치·개인 파일·다른 저자의 모든 배포 권한을 넘기지 않는다. 서인은 받은 범위·출처표시·다음에 누구에게 보일지를 확인하고 가져간다.
-128은 그 실제 물건과 진술을 대조해 가설을 낮추거나 일부 확인하는 후속 작업이다.127에서 모든 중간 전달자·다른 지역의 유사 자료·독립 발생 여부를 한 번에 풀지 않는다.
- 새 응답·만남·보관자경력/물품·수정본과 전달 메모는(제안). 원본 소각 후보는 채택하지 않는다. 숨은 기술·도윤의 책임/11화배후·자녀개입·199/200 전용 장치·한 달HOLD 경계 유지. 연출 구상만, 실제 구현·모바일 검증·7번 점수 없음.
