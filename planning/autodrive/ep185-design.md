# 제185화 설계 · 청산되지 않는 것
- 목요일(184 수요일 다음 날). 기술원 시험실: 서인·세아·우석(장부실 동료, 151 T0~T3 표를 들고 온 동료 — 표 작성은 151 서인·세아·도윤) + 기술부 서명자(183, 통합 심사 기술 입회인, 명세서 끝까지 읽음). 청산망 T0(생명·재난)/T1(기본 확인) 경로를 회복 지원망 다시 보여 주기 경로와 문을 나눠 분리. 수면제 처방 재검증(명세상 회복 지원) → 서인 판단으로 T1, 상담 기록 따로(181 노인 회수). `ESSENTIAL ROUTE · ISOLATED.` 기술부 서명 옆 `연결 결과 확인함.`
- 과부하 전조(settings/13 1단계 감각 제거의 전조, 191~195용): `필수 재검증 평균 지연. 6. 분.` 숫자와 글자 사이가 잠깐 비어 보임. 아무도 모름. 6분(어제보다 2분 짧음), 비필수 사흘 더, 회복 지원 그대로, T0·T1 유지.
- 점심: 도윤은 입회 안 함(감사실 연락, 가람이 세아에게 전함). 세아 “아빠가 안 오니까 손이 덜 떨렸어요.”
- 센터: 딸 이름 잊는 분(일흔쯤, 딸 마흔쯤) 자발적 회복 프로그램 신청, 동의 칸(183 조서 문구) “네가 해 보라고 해서 하는 거 아니야. 내가 하고 싶어서야.” 딸 “제가 매주 왔던 것도 기억하실까요.” 자발 신청 열한 명, 연락해도 모르겠다는 분들. 181 노인 “왔지.” 약은 필수 줄, 상담은 따로.
- 도윤(장부실): 의료 피해 줄인 것 인정, 경고(스스로 올 수 있는 사람만). 원안 대사, ‘형’→‘도윤 씨’, ‘권리’ 회피(“다시 물을 수 있게 해 줬어”). 감사실 중간 결정 `잔여 경로 · 회복 지원망 내부 사전 안정화 예외로 축소 · 범위 다툼 계속.` 가람 청산 줄 동행(180). 동남 대표 미리 연락(184 회수).
- 집: 어머니 “그럼 내 첫날도 밀렸네.” “상자는? 아직 비었어?” “청산 줄에서는요. 비었어요.” 동남 대표 “월요일 갑니다.”
- 끝: 공개 대시보드 4줄 + `FAIL MODE: OPEN`(보강). 세아 “막은 건 가격표예요. 그 아래 계약은 아직 남았어요.” 실패 시 열림 설명, 회복망 잔여 예외가 같은 문 쓰면… “내일 아침에 볼게요.” 상자 바닥 열린 문, 빈칸 — 원안 해설형 마지막 문장 대신 행동.
- 잠금: 186 강제 복원 미실행, 의료 붕괴 없음, 도윤 무력화 없음, ‘형’ 없음, 4.8배·1.8초 없음.
- (제안): 분리 방식·문 비유, 수면제 처방 분류, 6분·2분·사흘·열한 명, 기술부 입회, 대시보드 공개, 중간 결정 문구, 인물들.
- 수정 1/3 (제안) 추가: 동의 문구 출처 = 184 수요일 의결, 도윤은 열한 명을 연합에서 들음, 동남 ‘1주 연기’는 개략·실제 월요일 재개. 세아 “막은 건 가격표랑 필수 문이에요.”(원안 대사 맥락 보정).
