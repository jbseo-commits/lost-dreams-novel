# 제116화 독립 사실·연속성 검수

**정정 판정: CHANGES — 조정 메모의 실제 효과와 훈련 질문의 선택지 두 곳.** 최초 PASS에서 아래 두 인과·의미 문제를 놓쳤다. 원고는 수정하지 않았다.

- **날짜·세아의 자력 열람(3–21, 99, 217–275행):** 장면은 토요일 오후다. 세아가 가람의 목록을 들고 상자에서 기술 자료를 직접 골랐다고 말하며, 도윤도 상자만 내려 줬다고 분명히 한다(7–17행). 이는 110화 금요일에 다음 주 토요일 열람 담당을 세아로 바꾼 약속(110:133–147)과 115화의 다음 날 방문 약속(115:9–11, 319행)에 맞는다. 세아는 목록에는 있으나 다른 파일이 든 부록을 발견하고 가람에게 먼저 확인하겠다고 한다(219행). 사본은 허가받은 기술 기록만 복사하고 개인 자료는 다음에 가람에게 확인한다고 구분한다(261행). 개인 기록 자동열람이나 전체 상자 공개는 없다.
- **직접 공개와 후보/정식 연결의 구분(21–45행):** 아침 연락은 도윤이 먼저 했고, 그는 자기 사본이라며 봉투에서 직접 서류를 꺼낸다(21–25행). 문서는 “참조계열 03. 후계 후보”, “정식 연결: 미실시”, “훈련 종료: 본인 요청”으로 표시한다(27–31행). 도윤은 후보였다고 답하고 정식 기준자로 들어간 적은 없다고 직접 밝힌다(35–43행). 숫자·코드 해독이나 나이 대조가 없으며, 공개 내용은 도윤이 자기 자료를 직접 보여 준 범위로 한정된다. 03 분류와 세부 훈련은 새 장면 제안으로만 남기고 정본 설정으로 올리지 않는다.
- **평가와 사후 자발 종료(59–97행):** 평가서는 종료 확인서보다 먼저 작성된 훈련 중 평가로 명시된다(65–69행). 도윤은 평가 뒤에 자신이 계속하지 않겠다고 썼다고 설명하고, 평가를 자신의 선택과 같은 뜻으로 만들지 말라고 선을 긋는다(75–87행). “그때는 그렇게 말했어”(89–95행)와 133–149행의 계속 배우고 싶었던 당시 응답은 평가·그 시점의 거부·훈련을 더 원했던 앞선 시점을 구분한다. 탈락 통지나 선발 보장은 만들지 않는다. 118화 예정의 실제 연동도 아직 보여 주지 않는다.
- **자료 소유와 봉투/초안 상태(143–197행):** 도윤은 자기 응답까지만 펼치고, 다른 이름과 세부 사례는 부속 자료로 봉투에 남긴다(143–149행). 서인은 자기 한 달 초안 봉투를 아직 열지 않은 채 탁자에 놓고(153행), 대화 뒤 자기 가방에 되돌려 놓는다. 원고는 초안이 같은 보류 상태라고 명시한다(191–195행). 다른 사람의 기록을 요청하거나 도윤 봉투에서 꺼내지 않는다.
- **정정 1 — 메모와 실제 일정 증가(197–249행):** 원문 메모가 직접 말하는 것은 새 후보를 기다리는 동안 참조 일정의 “조정이 필요”하다는 점뿐이다(197행). 그러나 241행은 도윤이 나가면서 “남은 사람의 일정이 늘었다”고 메모가 입증한 사실처럼 강화한다. 도윤의 “기다리는 사람이 있었다”(203행), “남들이 그 자리에 계속 있어야 했다”(229행)는 발화만으로 실제 일정이 증가했다는 기록 증명이 되지는 않는다. 메모가 필요성만 남긴 것인지, 실제 인원별 일정 변경까지 기록한 것인지 구분해야 한다. 세아가 다른 부록을 발견했을 때 도윤은 상자 위치만 말하고 대신 열지 않으며(217–225행), 도윤 종료 확인서와 조정 메모는 함께 봉투에 돌아간다(249행).
- **정정 2 — 훈련 과제의 ‘다른 데’(287–301행):** 과제는 두 지역 중 “한 곳에 먼저 자원을 보낸다”고 소개되지만(287행), 도윤의 “다른 데 보내면 안 되냐고 물었지”(295행)는 선택을 다른 지역으로 바꾸자는 것인지, 한 곳을 고르는 조건 자체를 벗어나 다른 지역에도 보내자는 뜻인지 구분되지 않는다. 이어지는 제출 시간 종료와 조건 밖이라는 평가 의견만으로 의도된 질문을 하나로 확정할 수 없다. 시간·평가 비용은 보존하되, 문제의 배분 제약과 도윤의 질문 대상이 무엇인지 명료하게 해야 한다.
- **설정·공개 경계:** 서인은 “형”을 쓰지 않고 현재 호칭을 유지한다. 199화 최초 호칭 규칙(설정 04:32)을 건드리지 않는다. 도준의 사적 고백, 세아의 개인 해석, 114화 자료실 로그를 도윤에게 전달하지 않는다. 탈취·사상 주입·야간 연산 비밀도 공개하지 않는다. 서인 초안은 수정·삭제되지 않고 봉투에 보류된다.

다른 검수 범위에서 확인한 날짜·후보/정식 연결·세아 열람 범위·서인 초안 봉투 상태는 유지한다. 전달된 본문 계수는 3,567자로 하한을 충족한다.

## 1차 교정 재검수 — PASS

이번에는 229·241·295행의 변경 구간만 다시 대조했다. 229행의 “나는”으로 도윤 자신의 선택을 말하는 관점이 분명해졌다. 241행은 메모에 “남은 일정의 조정이 필요”하다고 적혔다고만 서술하므로, 실제로 일정이 늘거나 조정이 완료됐다고 확정하지 않는다. 295행의 “왜 한 곳만 골라야 하냐고 물었지”는 한 곳만 선택하게 한 과제 조건 자체를 묻는 발화로 명료해졌다. 기존 두 CHANGES 지적은 이 교정으로 해소됐다. 본문 분량은 3,567자이며, 수정 누적은 1/3이다.
