# 141–145 원천 경계 메모

> 시점 안내: 이 메모는136~140이 아직 작성 중이던 때 옛141~145 개요를 탐색한 자료다.현재136~140은 실제 원고/화별 인계노트/검수JSON으로 확인하며140 최종3616자·1/3·독립 본문PASS다.현재 문의는 비교할 두 방향만 특정했고 데이터/시험 권한이나 실시간망 접근을 얻지 않았다.아래 옛 개요의 숫자/권한·광고꿈 해석은 채택 사실이 아니다.다음 실행은 별도141~145 적용안을 기준으로 한다.

이 메모는 기존 141–145 개요를 위한 출처 탐색이며, 계획 승인이나 미작성 회차의 사실 검수가 아니다. 136–140 적용안은 채택된 계획일 뿐 아직 발생한 원고 사건이 아니다. 개요 첫머리의 “136–140에서 서인이 전체 기록을 확인했다”는 표현은 현재 사실로 소급하지 않는다.

## 정본에서 고정된 출발점

- **20화:** 화면은 검토용 복제였고 실제 실행란은 회색이다. 과거에는 콘텐츠의 계정 오연결 사고가 확대된 뒤 야간망 중단 승인, 11분 후 승인자 4의 철회·복구, 그 뒤에도 남은 공급사 2곳 차단, 시작 37분 후 사고 안정화가 기록됐다. 철회 사유는 감사 열람 범위 밖이다. 11분 복구와 37분 안정화를 하나의 시각·인과로 합치지 않는다.
- **136–140 적용안:** 승인자 4와 새로 연락해 과거 운영기록의 추가 열람 범위와 메모 허용을 장면에서 정하도록 한다. 이는 과거 기록 열람의 범위 확장일 뿐, 실시간 운영망이나 실험망 실행 권한이 아니다. 따라서 141화의 A/B shadow test는 현재 확보된 권한으로 시작할 수 있다고 가정하지 말고, 작중에서 독립적인 자료·시험 권한과 무중단 조건을 마련해야 하는 신규 제안으로 둔다.
- **98화:** 승인자 4는 자기 기기로 일부 운영기록만 현장 열람시켰고, 환자 결과는 열 수 없게 했다. 서인의 추가 열람 요청에는 자료 범위를 따로 정리해 주겠다고 했지만 전체 복사·환자 자료 제공은 약속하지 않았다. 48화에서 서인은 이미 그녀가 하진의 이모이자 가족으로 참석한 사실을 들었다. 141화에서 첫 만남·가족관계 최초 발견으로 만들지 않는다.
- **settings/12:** 승인자 4는 여성·예순쯤, 하진의 이모이자 현역 앵커의 자매·신탁관리인이다. 이름·정확한 기관·11분 사건의 환자와 수치는 미정이다. 전체망 중단을 승인했다가 11분 후 복구한 사실과 당시 인간 생존에 연결된 지연을 확인했다는 큰 방향은 고정이다. 특정 환자·임상 결과·운영자 실명은 별도 원고 제안이다.

## 개요에서 제안으로 남길 요소

shadow system, A/B 입력·결과 비교, 0.7% divergence, 99%/99.94% 일치율, 4.8x 초기 비용, 전력·냉각·검증기 배수, 세아의 비대칭 손실 분류, 시민 선택지, 어머니 대화, voluntary human pool, 분리 아키텍처는 모두 미작성 개요의 제안이다. 고정 정본이나 136–140에서 이미 확인된 결과가 아니다. 4.8x는 개요 말미 통합검수 보강대로 “현재 A망 수준을 맞추는 초기 B망 추정”으로 한정하고, 사회 전체 비용 법칙으로 쓰지 않는다. 기술 인과 감사도 이 구간의 구체 결과를 정본으로 승인하지 않는다.

## 충돌 또는 반드시 보존할 경계

- **광고꿈 연산 비밀:** settings/03은 잠든 이용자의 뇌가 광고꿈 동안 분산 인지 연산 자원으로 쓰인다는 사실을 작가용 비밀로 규정하며, 인물·독자·현재 공개 화면에 옮길 시점은 별도 확정 전까지 열지 않는다. 136–140 적용안도 이 연결을 밝히지 않는다. 따라서 141 개요의 “야간 인간인지 공급”, “사람이 싸서”라는 해석, 광고꿈 지급보다 시스템 가치가 크다는 단정은 이 비밀을 서인·시민에게 공개하는 근거가 아니다. 새 명시적 공개 결정을 받기 전에는 shadow test의 공개 설명과 결과에서 광고꿈 이용자의 뇌 연산 공급을 드러내거나 추론시키지 않는다.
- **실험 권한:** 20화 검토 화면이나 98화 과거 기록 열람은 shadow simulation 운영, 같은 입력 자료 접근, 비용·신뢰도 계산 권한을 주지 않는다. 136–140에서도 그런 권한은 부여되지 않았다. 실제 무중단 실험을 원고화한다면 누구의 시스템에서 어떤 공개/비공개 입력으로 무엇을 승인받았는지를 신규 사건으로 한정해야 한다. 그 전까지 “안전한 실험”은 아이디어일 뿐 실제 실행·무피해를 사실로 쓸 수 없다.
- **11분 사건 결과:** 137–139의 초 단위 흐름, 부서별 선택, 소아 재검토 요청, 보호자·의료진 장면은 모두 새 제안이다. 정본이 확정한 지연 사실과 충돌하지 않도록 쓰되, 환자 생존·진단·치료 결과나 11분 복구가 특정 개인을 구했다는 인과는 만들지 않는다. 과거를 독자에게 보여주는 서술은 승인자 4가 현재 서인에게 공개한 운영자료와 별개다.
- **PRIORITY MEMORY SET:** 135화 실제 원고에서 세아는 본인 이름으로 된 교육자료 목록만 열어 달라고 요청했고, 가람이 범위를 확인해 목록을 보여 줬다. 세아가 서인에게 허락한 것은 표제·등록 필드 2줄 열람뿐이다. 본문은 잠겨 있으며 `AUTHOR: D.Y.` 의미, 작성자/등록자/분류자 구분, 해당 자료를 세아가 실제로 받았는지 여부가 모두 미정이다. 141–145 개요가 이 파일을 다시 알림·기록으로 언급하더라도 열람하거나 뜻을 추정하는 장면으로 넘기지 않는다.
- **호칭·후반 전용 장치:** settings/04는 서인이 도윤을 도윤/도윤 씨라 부르고 존댓말을 유지하며, 첫 “형”은 199화 한 번으로 정한다. 141 개요의 141화 농담 “형이 괜찮다고 하면…”은 그대로 쓰면 확정 규칙과 충돌하므로 원고화 때 고친다. 200화의 메시지 작성 후 삭제 장치도 이 구간에는 없다. 개요의 질문 삭제·재작성은 진행 문서의 비메시지 수정으로만 두고, 메시지 작성·삭제의 정서 장면을 앞당기지 않는다.
- **법·위임:** 140화 `CONTINUITY EXCEPTION`은 136–140 적용안상 사람 확인 없이 대체 경로를 검토하자는 권고일 뿐이다. 141–145 개요에서 이 권고를 이미 제정된 법·기관 권한·서명 합의나 승인자 4의 위임으로 서술하지 않는다.

## 실행 판단

정본이 이미 확정한 20화의 시각·결과, 승인자 4의 관계·역할, 광고꿈 연산 비밀과 199/200 규칙 자체에는 141–145를 막는 불가피한 충돌이 없다. 다만 기존 개요를 문자 그대로 가져오면 141화의 “형” 호칭과 광고꿈 연산 공개가 직접 규칙 위반이며, 실시간 shadow test와 136–140의 기록 열람 권한을 혼동하는 문제가 생긴다. 이들은 승인 대기 사유가 아니라 개요를 현재 적용 범위에 맞춰 보정하고, 필요한 권한을 장면 안에서 새로 설정할 연속성 조건이다.
