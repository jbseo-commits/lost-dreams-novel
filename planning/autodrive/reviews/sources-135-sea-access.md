# 135화 자료 접근 메모: 세아의 열람·동의 경계

- **제116화:** 세아가 가람의 목록을 사용해 기록실 상자에서 자신이 고른 옛 기술 자료를 찾는다. 아버지가 특정 파일을 골라 둔 게 아니라는 점을 직접 밝힌다. 목록과 실제 부록이 다르면 가람에게 먼저 확인하겠다고 한다. 이는 세아가 그날 직접 골라 자료를 찾아 읽은 사실이지, 서인 등 다른 사람의 열람·인용·복제·공개 동의가 아니다.
- **제110화:** 세아는 기록 보존에는 찬성하지만, 현재 사람에게 맡긴 참조 구조를 계속 유지하거나 자기 설계로 바꾸는 데 동의한 것은 아니라고 명시한다. 화면은 그날 가족이 확인한 내용만 저장하며 후속 검토가 남는다. 같은 화에서 가족 기록·기억 반복 학습이라는 오래된 표제가 보이지만, 세부 목록은 열지 않은 채 가람이 접는다. 이 장면은 열람·외부 사용 동의가 아니다. 보존 동의도 특정 교육 자료의 외부 사용권이나 승계 완료로 넓히지 않는다.
- **제115화:** 세아는 다음 토요일 직접 자료를 찾겠다고 하고 열람 일정의 담당자로 기재된다. 도윤이 자기 선택 파일을 미리 꺼내자 서인은 세아가 그 파일을 요청했는지 묻고, 도윤은 물어봤다고 답한다. 이후 도윤은 파일을 원래 상자에 돌려놓고 무엇을 찾을지 세아에게 묻기로 한다. 그녀의 자율 열람 약속은 자료를 다른 독자에게 보여주거나 공유할 포괄 동의가 아니다.
- **제124화:** 가람이 관리하는 목록에서 공개본과 별도 허락이 필요한 자료가 구분된다. 이번에 실제 검토한 것은 유진의 공개 의견서·사업 보고서다. 도윤의 공유 목차 편집권이나 가람의 원본 보존·색인 업무가 세아 개인 기록의 제3자 제공권을 뜻하지 않는다.
- **제105화:** 본문에는 세아가 등장하지 않는다. HOLD/CONSENT CONFLICT 검토는 세아의 교육 자료 접근 동의 근거로 쓸 수 없다.

135화에서 세아의 교육 자료나 개인 기록을 다른 사람에게 보여 주려면, 그 장면에서 자료 종류·열람자·기록/인용 여부·사용 목적을 새로 확인해야 한다. 기존 근거만으로는 가족 내부에서 세아가 직접 읽은 범위 외에 외부 모임 열람, 복사본 제공, 개인 응답 인용을 허용할 수 없다. 공개 목록에 이미 표시된 공개본을 쓰는 경우에도 사적 교육 자료와 분리한다.
