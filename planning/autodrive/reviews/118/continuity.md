# 제118화 독립 사실·연속성 검수

**판정: CHANGES — 배분 판단의 주체와 현재 공개된 동의 범위 두 곳.** 원고는 수정하지 않았다. 전달된 본문 분량은 3,635자이며 수정 누계 0/3이다.

- **성년기 관찰과 권한(3–15행):** 도윤은 성년 이후 후보 자격으로 검토 자료를 보는 참관자이며 집행·변경 권한이 없다고 명시한다. 이는 설계와 맞고, Line04/신경 연결/shadow link를 새 사실로 끌어오지 않는다. 참관 약정·자료 접근은 이 사례의 새 제안이지 일반 권한이 아니다.
- **한정된 자원과 기본 치료(19–51행):** 재난 대비 검증 우선 배정과 의료 재검증 대기가 서로의 시간 자원을 놓고 경쟁한다. 기본 진료와 기존 처방은 계속되며, 환자의 통증·추가 재검증 대기와 재난 경로 확인 지연이 각각 비용으로 남는다. 의료 재검증이 완료되거나 대기 환자에게 실제 악화가 발생했다고 쓰지 않는다. 이 사례의 배분 기준과 자료 구성은 제안으로만 남긴다.
- **당사자 발화와 면담 범위(55–161행):** 환자는 자신의 다음 진료 일정, 통증, 기록 제공 범위, 진술 문구, 연락 방법을 직접 정정·선택한다. 직원이 처방을 변경하거나 면담을 진료·지원 확정으로 처리하지 않는다. 사본은 날짜 기록만 제공되고 집안 일정은 보류된다. 연락처나 병력 원본이 도윤에게 넘어오지 않는다.
- **지원 문의와 실제 결과(113–195, 211행):** 환자가 무엇을 받을 수 있는지 확인해 보고 결정하겠다고 했고, 직원은 당사자 요청으로 문의만 접수한다. 지원금은 정해지지 않았으며, 별도 확인 뒤에도 재검증 대기는 바뀌지 않는다. 도윤에게서 TOKEN이 지출되지 않았고 추가 검사·지원·치료가 완료됐다는 주장도 없다. 이 흐름은 신청·접수·결정·제공·검증 완료를 구분한다.
- **필수 수정 1 — 실제 배분의 주체(41–51, 213, 245행):** 49행의 담당자 발화는 결정이 도윤의 것이 아니라고 분명히 하지만, 그 앞뒤에 “그날 고른 안”, “긴급한 재난 검증을 먼저 해야 한다고 적었던 이유”, “처음 골랐던 이유”가 반복돼 도윤이 실제 배분안을 골랐다는 인상을 준다. 설계상 도윤은 집행 결과를 사후 검토하는 교육 참관자다. 이 문장들을 실제 집행된 안에 대한 도윤의 관찰·분석 기록으로 일관되게 고쳐야 한다.
- **필수 수정 2 — 서인에게 전한 정보의 동의 범위(13–15, 199–217, 225–27행):** 서인 앞에서 보여 주는 것은 익명화된 승인 발췌이며, 207행은 통증과 예약 대기만 허용되고 일을 비운 횟수는 교육 자료에서 빠졌다고 설명한다. 그런데 211행은 별도 지원 문의에 대한 후속 답변과 도윤이 추가한 질문을 서인에게 전달되는 현재 서사의 일부로 남긴다. 지원 문의 상태가 당사자가 승인한 발췌에 포함됐는지 명시되지 않았다. 또한 203행에서 기록한 동행인의 야간 근무·환자의 다음 방문 동행 여부도 승인 범위가 불분명하다. 현재 서인에게 보이는 정보는 실제 승인된 발췌 범위로 한정하고, 추가 정보를 쓰려면 그 구체 항목에 대한 명시적 동의 경로를 보여야 한다. 별도 약정이나 후속 답변을 과거 동의에 소급 포함하지 않는다.

검수 근거: `planning/autodrive/ep118-design.md` 3–10항, `planning/autodrive/ep116-120-adaptation.md` 19·35–36행. 설정 12의 TOKEN·재검증 일반 구조는 작가 확정이나, 특정 재난 배분·참관 약정·지원 문의 절차·당사자 사례는 이번 화 제안으로만 취급한다.

## 1차 교정 재검수 — PASS

교정된 관찰 소유 표현(45·213·245행), 도입부의 현재 자료 범위와 회상 진입(15·19행), 현재 서인에게 보여 주는 승인 발췌의 경계(221–27·245행), 그리고 215행의 당시 판단 근거와 현재 통증의 구분만 다시 확인했다. ‘집행된 안/판단을 분석’하는 기록이라고 일관되게 밝혀 도윤이 실제 자원 배분을 선택·집행한 듯한 인상을 해소했다. 현재 서인에게 보여 주는 기록에는 환자가 허락한 통증·재검증 대기 문구만 남고, 생활 세부와 별도 지원 문의는 포함되지 않는다고 명시됐다. 215행은 당시 자료·우선순위에 대한 평가와 오늘의 통증을 분리한다. 최초 두 CHANGES는 해소됐다. 전달된 본문 분량은 3,717자, 수정 누계는 1/3이다.
