# 171–175 적용안 사실·연속성 검토

**최초 계획 판정: PASS, 조건부 실행.** `ep171-175-adaptation.md`는 170화 r1의 실제 출발과 2026-10-08 D-5 위임 결정을 반영한다. replay-truth를 기준으로 하고 보조 memory-arc의 네 요소를 장면에 맞게 흡수한다. 원안 머리의 이전 선택 대기 문구를 새 승인 대기로 반복하지 않는다. 검토는 미작성 계획에 대한 것이며 원고 사실 PASS가 아니다.

계획의 가족 자료 범위는 현재 근거와 일치한다. 170화에서 세아가 실제 다시 연 것은 135화의 `PRIORITY MEMORY SET`과 `AUTHOR: D.Y.` 두 표기뿐이며, “선택을 연습하는 자료”라는 말은 불확실한 개인 기억이다. 계획은 171화에 새 응답과 당사자별 열람·메모·외부 이용 범위를 받도록 하고, 제목/회상 차이만으로 같은 파일·교육·개입을 확정하지 않는다. 가람의 보존 역할, 도준의 110화 불참, 세아의 자기 기록 선택도 가족 전체의 승계나 전원 동의로 확대하지 않는다.

172–174화의 기록 열람과 기술 감사는 각 사람의 새 허락과 제한한 자료·반출 범위 안에서만 가능하다. 메타데이터의 이름·버전 차이는 질문일 뿐 사용·노출 증거가 아니다. 도윤 명의의 서명이나 승인 주장을 할 때는 서명 진본성, 권한, 실제 실행 기록과 시각을 각각 출처로 확인하고, 직접 인정과도 연결해야 한다. 계획이 제시한 노출·반복·출처 표시 사실은 새 원본이 허락 범위 안에 실제로 확인될 때만 좁게 주장할 수 있다. 135화 제3필드·본문, 타인의 개인 패턴 원본, 실제 노출 시각·강도는 기존 사실로 앞당겨 쓰지 않는다.

가람은 여성·20대 초반이지만 둘째·셋째의 세부 나이와 성씨, 어머니의 신원·부재 사유는 미정이다. 적용안은 이 경계를 명시하고 156화 윤하진의 어머니를 이 가족과 섞지 않는다. 어린 시절의 실제 장면·음성·노출 정도는 새 자료와 당사자별 선택으로 열기 전까지 제안에 머문다. 돌봄과 사랑이 실제였을 가능성을 유지하면서도 부모가 목표와 반복을 대신 정한 책임은 흐리지 않는다.

175화의 책임 인정은 세 자녀가 자기 범위를 선택한 대면으로 구상하고, 전국 강제 replay·광고방송 중단의 실제 실행자·혁명 전체의 편집자 정체는 176–180화에 남긴다. 계획은 대면을 이미 합의된 사실로 쓰지 않는다. 집필 때 도윤의 참석·발언과 각 자녀의 참여·공개는 그때 새로 확인해야 하며, 열람 허락을 대면이나 공개 동의로 간주하지 않는다. 서인의 첫 “형” 호칭은 199화에만 두고, 200화의 메시지 작성 후 삭제 장치도 앞당기지 않는다.

163 r2와 168화의 시간·출처 경계도 적용안에 유지돼 있다. 과거 예외 권고는 서인이 열람한 사후 문서이고, 140화 권고는 과거 실행의 승인 근거가 아니다. 168화의 사고 전 실행일, 승인 근거·임상 범위 미확인은 기존 상태로 둔다. 광고꿈의 뇌 연산 공급과 지급 가치 비밀도 열지 않는다.

**필수 실행 조건:** 각 사람의 새 열람/대면/인용 범위를 별도로 확인하고, 175화 대면은 도윤과 자녀들이 각각 현재 참여를 선택한 뒤에만 성립시킨다. 책임 인정 및 기술 사실은 허락된 원본·출처·시각이 뒷받침하는 범위로 제한한다. 이 조건은 적용안의 허락·증거 경계에 맞춘 구현 조건이며 새 승인 절차를 요구하는 차단 사유는 아니다. 보호 설정·정본 파일을 수정할 필요는 없다.

## 추가 실행조건 최종 확인

**최종 계획 판정: PASS, 조건부 실행 유지.** 추가된 세 조건은 최초 검토의 출처·허락·개인차 경계와 일치한다. 171–173에서 각자의 실제 일정·놓치는 일과 도준의 중단 시점/다음 날 별도 선택을 남긴다. 174에서는 기술 감사의 권한·수신자·반출 데이터·출처·비용을 확인하고 현재 회상, 예정 항목, 실제 실행, 보호자 승인 기록을 구별한다. 175의 대면에는 세 자녀뿐 아니라 도윤도 현재 참여·전달 범위를 따로 선택해야 한다. 일반 가족교육 음원과 타인 유래 연상 경로 개입을 구분하며, 직접 책임은 흐리지 않되 모든 개인 신념의 원인을 단정하거나 176–180의 전모를 앞당기지 않는다.

추가 조건은 기존 계획을 구체화할 뿐, 새 사실·권한·작가 승인 대기를 만들지 않는다. 원고는 미작성이며, 실제 열람·허락·대면의 성립은 각 장면에서 확인해야 한다. 최초 PASS와 본문 사실 PASS가 아니라는 범위 표시는 유지한다.
