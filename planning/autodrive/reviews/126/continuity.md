# 제126화 독립 사실·연속성 검수

## 최초 독립 검수

**최초 판정: 사실·연속성 PASS.** 초안은 본문 공백 제외 3,554자, 수정 누계 0/3이었다.

- **시점과 자료 생성 층위:** 125화 토요일 이후 주말을 지난 월요일, 서인과 가람이 토요일 허용 목록에서 비교자료를 연다. 검색용 사본 둘은 함께 생성됐지만 원문 이미지의 표기는 모두 “거리”다. 원자료 작성 시기, 사본 생성 시기, 도윤이 후대에 목록에 묶은 때를 따로 기록한다. “거러”는 검색용 사본의 오류로만 정정된다. (5–35, 88–104행)
- **유사 사례와 복제 여부:** 옛 참조 교육자료와 후대 지역 강좌 자료에는 비슷한 자원 배분 질문이 있지만, 하나는 먼저 답한 뒤 조건을 다시 묻고 다른 하나는 토론 뒤 다시 고른다. 문구·질문의 유사성만으로 같은 수업, 복사 또는 조직 계보라고 결론내리지 않는다. 공개 강의자료의 “사례 제공” 이름만으로 윤태식이 저자·강사인지, 어떤 문서를 직접 받았는지 확정하지 않는다. (39–84행)
- **연대와 문의 경로:** 자료 작성 표기와 현재 보관 파일 생성 표기가 다르고, 도윤의 후대 분류 시점도 따로 적는다. 자료가 서로 다른 시기에 만들어졌다는 것까지만 확인하며 그 사이 전달자는 공란이다. 공개 강의 안내에 남은 현재 교육 창구로 문의하고, 개인 연락처를 직접 얻거나 당일 면담을 정하지 않는다. (88–108, 120–138행)
- **외부 전달 범위와 회신 상태:** 내부 교육발췌를 외부에 보내는 허락이 없음을 확인하고, 서인은 공개 강의자료와 자기 질문만 보낸다. 도윤의 개인 비교 메모와 내부 발췌는 첨부하지 않는다. 문의는 교육 창구에서 윤태식에게 실제 전달됐지만, 윤태식 본인의 설명 가능 여부 답은 아직 없고 만남 날짜도 비어 있다. (110–116, 140–164, 216–226행)
- **발화·행위 소유:** 시작의 “거리겠죠”는 서인이며, 이어지는 “그렇게 읽히네요”는 가람의 자료 대조 흐름에 붙는다. 문의의 “자료 두 개를 보내 드리면”과 바로 뒤의 범위 수정은 서인이 말한다(140–148행). “그분이 설명할 수 있는지부터 여쭤볼게요”는 창구 담당자의 말이며, 이어지는 서술에서 문의를 받았다고 확인된다(150–154행). 후반 “처음처럼 바로 연결해 놨으면…”은 서인의 발화로 174행의 “그가 말했다”가 확인한다. (7–15, 140–154, 172–182행)
- **다른 지역 공개자료:** 별도 생계 교육자료에도 질문 유사성은 있으나 출처 제공자 표기가 비어 있다. 서인은 이를 윤태식 이름 아래 붙이지 않고 별도 출처 미상으로 둔다. 한 자료의 이름으로 다른 자료의 빈 경로를 채우지 않는다. (186–212행)
- **127화 제안과 기술 경계:** 윤태식에게 실제로 확인된 것은 공개 강의자료의 제공 표기와 간접 문의의 전달까지다. 실제 만남·원자료 수령·저장장치·중간 경로는 다음 구간의 제안이며 이 원고에서 성립하지 않는다. 개인 신경기록, 숨은 인지 연산 기술 또는 내부 교육발췌의 외부 전송은 나오지 않는다. 126화에는 도윤의 현재 직접 대사가 없어 그와 서인의 호칭·말투를 검수할 수 없다. 원고에는 서인이 과거 도윤이 보여 준 훈련과 개인 비교 메모를 떠올리는 내용만 있다. (15, 43, 66, 80–84, 110–154, 215–251행)

검수에서 날짜, 자료 생성·사본·후대 분류 시점, 이름이 확인된 제공자와 작성자 구분, 문의 대상·전달·답변 상태, 외부 사용 허락 범위에 필수 수정은 찾지 못했다. 윤태식의 설명이나 원자료 전달을 다음 화 집필 전 사실로 승격하지 않았다.

## 편집 교정 재검수

**최종 판정: 사실·연속성 PASS.** 본문 공백 제외 3,526자, 수정 누계 1/3이다. 원고는 수정하지 않았다.

180행은 “서인은 이름 아래에 자기 질문을 붙였다”로 바뀌어 윤태식의 답을 이미 받았다는 기대를 만들지 않는다. 이어지는 문장도 그 질문은 아직 윤태식의 답이 아니라고 분명히 한다. 224행의 중복 부정 한 줄 삭제 뒤에도 문의가 어디까지 진행됐는지는 명확하다. 218행은 공개 자료 관련 질문이 윤태식에게 전달됐지만 설명 가능 여부 답은 아직 없다고 적고, 220행은 담당자가 질문을 전달했음을 재확인한다. 인접한 160–164행에는 면담이 약속된 것이 아니라 먼저 물어봐 주기로 했고 날짜는 비워 둔 상태가 남아 있다. 두 교정으로 새 사실이 추가되지 않았으며, 전달 완료와 본인 답 미수신·미확정 만남의 구분이 유지된다.
