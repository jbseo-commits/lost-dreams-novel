# 제164화 설계 · 먼저 떠오른 것

-163 새 문의에 회복센터 정지윤이 금요일 중립 문안 설명 시간/담당을 새로 답한다.세아도 오전 설명만 새로 정한다.심리사 양수경의 기존 안내 독해 점검 목적이며 성인 신다영은 공고를 보고 자발적으로 신청한 문안 검토자다.센터 배정 시간/보상과 중단권을 먼저 읽는다.비개인 예시·절차 발언만 두 방문자 메모/외부 공개는 별도다.
-본인이 적은 단어/담당자 단서/교재 타인 예시의 출처와 안내 시점을 구분한다.출처를 잠깐 접는 조건/재열람·끝나는 방법을 먼저 알고 택한다.그 조건에서 다른 제시 단어가 먼저 이어 나오지만 남의 기억으로 믿은 것/전체 기억주입으로 만들지 않는다.단어·노출/방법 반복이 달라 출처 숨김 하나의 인과나 효과 크기를 측정하지 않았다는 한계를 현재 문안에 붙인다.
-다영은 정답 점수 대신 처음/뒤 선택을 함께 남기고,출처를 펼친 채 다음 문안을 읽기로 고른다.화면 길이/되돌아읽기 비용이 달라진다.개인 선택과 실제 수정 항목/남은 시간이 설명을 바꾼다.치료 중 자기경험 자료의 출처 유지 절차는 오늘 알고 택한 중립 예시의 접기 조건과 다르다.
-기억자료의 출처/연상 단서 준비가 별도 설정임을 담당자가 현재 문안으로 설명한다.기술계보의 세 갈래는114 허용 발췌에서 이미 본 것이며 현재 센터 문안과 분류 접점만 새로 확인한다.옛 방송 장애의 실제 배포/행위자·도윤/135본문 증거는 아니다.
-오늘을160에 정한 첫 재검토일로 삼고 미란에게 실제 기존 상담 경로/운영자·재원 미답 상태를 알린다.새 기관 설명과 모의 점검이 운영자 답을 대신하지 않는다.센터 자료 담당에게 비개인 연결 예시/순서 비교 목적의 새 요청을 보내고,개인 발언/원자료는 보내지 않는다.165의 자료허락/기술팀 자기목적·시간·검토 범위는 미래다.
-새 담당·성인/공고·보상/자료·허락·시간·문안/질의·확인일은 (제안).3500~5500자·첫저장뒤누계3회/독립 사실·편집.연출 미구현·모바일 미검증·7점 없음·미공개.비밀/HOLD/R/135본문·4.8·1.8한정/199200 유지.설정/요약/config/웹/VN 무변경.
