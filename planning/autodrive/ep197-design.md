# 제197화 「돌아오는 사람」 설계
- 시점: 목요일(쿨링 닷새째). 서인은 읽기만, 판단하지 않음.
- 세 선택 동시(평가 없음): `LEAVE · 동남 · 아이 운동회`(운동회 철망 너머 패치 자국 여자, 동일인 여부 확인하지 않음) / `REJOIN · 북부 · 보상표 확인 · 하루 네 시간 제한 · 검진 통과`(이틀 지연 때 빠졌던 분) / 광고꿈 유지 61%(제안).
- 저녁 7시 도준 수영장 2층 강습실 철회 설명: 사다리 비유, 네 칸(대체 경로·위험도 공개·전환 확인·연결 종료), "다시 들어와도 돼요". 보드 구석 아버지 문장 `사람은 편한 꿈을 고른다. — 아버지(도윤), 12년 전 강연 녹취`(제안) 출처 붙여 지우지 않음.
- 서인안 검토 모임 문규(신규, 제안): 61% = 실패. 지우(3화 광고꿈 재가입·29화 회수): "저도 그 61이에요." "우리가 자유롭게 고르라고 했잖아요. 왜 우리가 원한 걸 골라야만 성공이에요?" 도준 `DECLINE` 칸 추가(세아 제안).
- 가람: 왼쪽 쪽 '편한 쪽 다시 고른 사람' 번호(스물셋째=지우), 오른쪽 쪽 본인 말, 이름 제외 — 계승형 기록과 사생활.
- 밤: 세아 `SOURCE · CONSENT VERIFIER · CODE PUBLIC · AUDIT OPEN`, 남부 권역 확대 보류(재정, 석 달)(제안). "묻는 거 아니에요. 알리는 거예요." 서인 지우에게만 "잘 자." 계산 기다리지 않고 불 끔.
- 잠금 점검: 형·30일·1.8초·4.8배·도윤 등장 없음.
