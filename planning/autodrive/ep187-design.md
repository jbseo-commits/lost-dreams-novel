# 제187화 설계 · 내가 원했던 것
- 토요일(186 금요일 다음). 감사실 독립 조사 진술 접수, 서부 센터 상담실, 원하는 사람만·녹음은 허락 시, 서인 청구인 입회(듣기만). 원칙: 무엇이 켜졌는지 먼저 말하지 않음(본인이 먼저 말하게, 다시 떠오르지 않게). 아침 도윤은 6시에 떠남(물 한 번 더, 수건 개어 둠).
- A 장상철(186 작업복 남자, 구태석 12-1·13-2와 혼동 피해 개명, 공구 공장 야간조 십육 년, 광고꿈은 입사 때부터): 새벽 4시 기타 줄 누르던 손가락, 스무 살 밴드, 기타 팔았음 → 중고 기타, 어젯밤 처음 광고꿈 끄고 줄 갈기(TOKEN 덜 들어옴 = 줄 값), 야간조 미정. “동의 안 한 건 맞아요. 근데 지금 이 마음도 내 거예요.” 원상복구 반대. “청구 낸 사람이면, 이거 뺏을 거예요?” 서인 “저는 안 뺏자고 할 거예요.” 번호표 오선 사진 기록.
- B 오영란(186 3층, 쉰쯤, 어머니 십 년 돌봄·인지 공급, 녹음 거절): 마당 있는 옛집(웃음) → 어머니 쓰러진 날(늦게 들어온 날) 반복, 숨 막힘. 어머니는 동생이, 공급 이틀째 멈춤(약값). 치료 + 기록 삭제(조사 종료 후 본인 요청으로). 도윤의 정체 질문 → 서인(담당자 동의) “그분이 이 일을 정한 사람이에요.” “그것도 기억할 거예요. 근데 그게 이거를 지워 주진 않잖아요.” “내 마음이라고 해도, 누가 허락 없이 건드렸잖아요.” “그 사람, 벌 받아요?” “그거 말고요.” 생수는 아침에 목말라 땄음(누가 둔 줄 모르고).
- C 은찬(186 이어폰 청년, 지우와 혼동 피해 개명, 스물셋): 무증상, 엄마 권유. 게시판 양쪽 “서른 명이 깨어났다” / “서른 명이 침해당했다”. 엄마 전화 무시. “난 아무것도 안 느꼈는데 왜 자꾸 내 이름으로 말해요?” 숫자에서 빼 달라 → 연결 기록은 사실, 본인 진술(무증상) 첨부.
- 대리 진술 남자(186 접수대): 아내 대신 원상복구 요구 → 본인 진술 원칙, 아내 전화 “남편이 그러라면…” “남편분 말고, 선생님 생각이요.” “다음 주에 제가 직접 갈게요. 혼자요.”
- 정리: 피해 유형 칸(인지 침해·정서 손상·기타·해당 없음) 대신 분류는 나중, 파일 이름을 각자 첫 문장으로 — `지금 이 마음도 내 거예요.` / `누가 허락 없이 건드렸잖아요.` / `왜 자꾸 내 이름으로 말해요.` 보고서 묶기 어려움. 다음 주 아내 파일도 같은 방식. 세아 “아빠한테 보여 줘도 돼요?” “그분들한테 먼저 물어봐야죠.” 노트에 세 문장(다시 쓰지 않음). 컵 세 개(빈 것·반·손 안 댄 것).
- 잠금: 피해자 한 종류로 묶지 않음, 사후 선택은 자동으로 가짜 아님, 사후 지지가 무동의 정당화 아님, ‘형’ 없음, 30일·1.8초 등 없음, 도윤 체포·무력화 없음.
- (제안): 진술 절차·원칙, 인물 이름·이력·세부(장상철·오영란·은찬), 게시판 문구, 분류 칸, 파일 이름 방식, 대리 진술 부부.
- 수정 1/3 (제안) 추가: 도윤 지지 모임 게시판(189 집회 전 단계), 상철 어제 아침 퇴근 후 기타 구입, 파일 이름은 각자 한 말(첫 문장 아님).
