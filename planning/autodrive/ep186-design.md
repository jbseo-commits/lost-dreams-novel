# 제186화 설계 · 열리지 말아야 할 문
- 금요일(185 목요일 밤 다음). 새벽 5시 세아 전화(밤샘): 서부 권역 회복 센터 1시 반부터. 로그(보강) `LEGACY CONTINUITY PATH / FAIL MODE: OPEN` / `PRE-CONSENT STABILIZATION (CONTINUITY EXCEPTION)` / `ASSOCIATION PRIMER ACTIVE` / `SOURCE TAG DELAYED` / `CONSENT ROUTER: PENDING — 4m 12s`. 세아 “예전에 우리가 잰 건 캐시가 늦는 시간이었어요. 이건 늦는 게 아니에요. 기다리게 만들어 놓은 거예요.”(163 숫자 미인용) “모릅니다.” 범위: 연결 지역 좁음, 영향 범위 확인 중. 야간 운영자 1시 20분 ‘응급 재활 복구’ 승인(양식이 그것). 실행 권한 서명 = 외부 연구 협력 계정. 185 감사실 중간 결정 ‘범위 다툼 계속’ = 틈. 세아 “사람은… 서인 씨가 물어봐 줘요.”
- 7시: 감사실 담당자(어머니 서부 아님) → 실행 권한 정지 청구(이미 돈 것은 못 멈춤), 접수 번호를 184 동남 메모 아래 붙임. 도윤 전화 “사고 아니야. 내가 정했어.” “서부 센터. 가람이한테는 문자 보냈어.” 11시 정지 발효, 이후 새 실행 없음(도윤 무력화 아님, 절차).
- 오후: 범위표(서부 대기자 쉰 명쯤 중 연결 서른 남짓, 가족 경로 빈칸). 기술부 “운영자가 속은 게 아니라, 양식이 그걸 허락한 거예요.” 정지윤: 자기 센터 무영향, 185 신청 어머님 아침에 딸 이름 한 번에 부름(프로그램 무관). 가람 “청산 줄은 같이 설 거예요… 오늘은 아빠 얼굴 못 보겠어요.”
- 밤 9시 서부 센터 대기실: 반응 다양(무증상 아내·불면 남편, 이어폰 청년 무증상, ‘원래대로 돌려놓으라’ 남자 — 189 원상복구 씨앗, 의자 바로 놓는 노인). 작업복 남자(마흔쯤, 기름때 — 187 A 씨앗, 번호표 뒤 오선 같은 줄과 점) “난 처음으로 내가 뭘 원했는지 생각났어요.”
- 3층 병실 B(쉰쯤, 어머니 돌보며 인지 공급한 보호자, 새벽에 어릴 적 집 얘기하며 웃다가 숨 가빠짐·불면, 진정제 거부): 도윤 아침부터, 가족 아님(82 ‘가족은 아닙니다’ 결), 물수건, 셔츠 자락으로 이마(공개 45 L149). “누구세요.” “아는 사람이에요.”
- 복도 대치(보강, ‘형’→‘도윤 씨’, 30일 미언급, 99 제한→유예→최소 회복기간): 49 “꺼내는 사람… 반은 정한 거” 회수. 도윤 “그래서 아무도 안 꺼냈어. 떠오르게만 했지. 문도 안 잠갔고.” 쉰 명/열한 명. “넌 기간을 정해서 잠그려고 했잖아.” “네. 저는 잠그려고 했어요.” 창밖 꺼진 창마다 광고꿈 수신기 대기 초록 불(제안). “넌 저 사람들한테 뭘 줬는데. 기다리라고?” 서인 무응답(191~195 인과). “그날 도윤 씨가 제 이마 닦아 준 거, 진심이었죠.” “지금도 진심이야.” 자판기 생수 → 마시지 않고 B 머리맡. 마지막 이미지: 뚜껑 닫힌 생수병.
- 잠금: 도윤 체포·무력화·사망 없음, ‘형’ 없음, 30일·1.8초·4.8배·R·잠든 뇌공급 없음, 전국 세뇌 아님, 의료망 붕괴 없음.
- (제안): 로그 시각·4m 12s, 운영자 승인, 정지 청구 절차·발효 시각, 범위 수치, 인물들, 초록 불 수신기.
