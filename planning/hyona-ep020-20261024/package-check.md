# 제20화 로컬 패키지 기록 확인

**판정: 패키지 기록은 핵심 원고·변경·브라우저 근거와 맞는다. 외부 연속성 보고서 정정본의 재복사는 완료 대기 상태다.** 이번 확인은 기록, 해시, 변경 대조, 코드 맵과 패키지 범위에 한정했고 원고를 재검수하거나 편집하지 않았다.

원고는 5,492자이며 SHA-256 `aa01e206ae3345b735393980e0a1aeb21394b93062bc07bf89008ec3c26f4641`로 검사 JSON 및 브라우저 기록과 일치한다. 변경 대조는 22쌍이고, 원본에서 변경 JSON을 순서대로 적용하면 현재 원고와 바이트 단위로 일치한다. 외부 편집 보고서 사본은 패키지본과 일치한다. 외부 연속성 보고서는 이 확인 도중 두 연결 요약의 시간·공개 순서를 바로잡고 웹 맵을 보완했으며, 패키지 사본은 그 직전 판본이다. 메인이 최신 사본을 다시 복사하기로 했다.

패키지에는 README, 변경 대조, 편집·연속성 보고서, 삽화 평가, 검사 JSON, 브라우저 JSON, 증거 화면 7장이 있다. 브라우저 JSON의 원고 해시는 일치하며 6개 본문 figure, 이미지 3장 디코딩, page error 0, 가로 넘침 없음으로 기록돼 있다. 회색 버튼 미리보기는 별도 화면으로 저장되어 72시간 기존 보호와 신규 심사 대기를 구분한다. `pilot.html`의 오래된 정적 팝업 문구와 실제 런타임을 혼동하지 않도록 기록은 `reader-scenes.js`의 교체와 직접 미리보기 방식을 구분하고, 자연 스크롤 발동은 미검증으로 남긴다.

코드 맵은 제20화 삽화 3개, `reader-info-graphics.js`의 납품 비교·범위 분리·대기 목록 3개, 화말의 `graybutton` 호출을 구분한다. `reader-inline-direction.js`에는 제20화 전용 문장 팝업이 없다. 사용된 증거는 PNG 7장이다. 제19-2화 파일은 없고, 작업 트리의 본문 변경은 제20화 하나다. 변경 기록에는 예상된 작업 로그와 20화 패키지 추가가 있으며 보호 설정·공식 요약·다른 회차 본문은 변경되지 않았다. `git diff --check`는 통과했다.

패키지 정본은 이미 남겨 둔 공급사 정체·기능 미확정, 그림 한계, 그래픽 반복, 화말 자연 스크롤·자동 종료 미검증을 그대로 보존한다. 이미지 평가는 루트가 직접 본 원화와 브라우저 기록에 근거하며, 이 검수자는 새 이미지 판정을 하지 않았다.
