# 효나씨 관점 공개본 수정과 main 반영

사용자의 “메인 병합해줘” 승인에 따라 검수한 공개 수정본을 main에 반영한다. 대상은 공개 원고18편, 효나씨 기준·역할, 관련 설정·공식 요약과 읽기 화면이다. 미공개 작업본과 PR #84 초안의 별도 원고·연출·전체 패치·캡처는 이 병합에 포함하지 않는다.

공개18편 모두 정식7항 기준을 충족했다. 같은 두 편집 검수자가 담당 범위를 유지해 수정 구간과 영향을 확인했다. 각 항8점 이상·평균9점 이상, 필수 인과·연속성·형식과 공백 제외3500~5500자를 확인했다. 이는 영향 원고의 비평 판단이며, 전체105화의 새로운 정식 인증을 뜻하지 않는다. [점수표](score-table.md), [원문 해시와 결과](results.json).

3·4-2·9-1화의 실제 실패·일정 충돌·선택을 펼쳤다.10화는 평가에서 자료가 부족한 문제와 조건부 시술 동의를,19~21화는 잠을 쉬는 집의 일을 다른 공급처로 넘길 때의 생활·치료 비용을 구체화했다.27·32·44·66화 등에서는 설명·회상·시간·대가의 연속성을 맞췄다. 구체적인 이유와 이전 수정 이력은 CHANGELOG 및 해당 원고 Git 이력에 남겼다.

효나씨는 생문과이고, 쭉쭉 읽고 싶고, 머릿속에 장면이 안 그려지면 읽기를 멈추는 독자다. 이번 공개 변경 중3·4-2·9-1·10·19·20화는 같은 효나씨가 다시 읽고 PASS를 확인했다. 말하는 사람, 현재 할 일, 판단 근거와 즉시 생기는 손익을 먼저 읽히게 하고 정상 미스터리는 유지했다. 기준 파일은 `loop/hyona-reader.md`, 역할 파일은 `.codex/agents/hyona-reader.toml`이다.

400×900 실제 모바일 화면에서 연출을 확인했다.20화의 발동 문장을 현재 본문에 맞추고21화의 잘못된 시각 표시를 없앴다. 연출을 끄면 다음 화 버튼이 숨은 채 남던 문제도 고쳤다. 공개 대표 기능 사례는19→20의 실제 NEXT 클릭과21화 연출의 본문 복귀 및21→21-1 이동이며 둘 다 통과했다. 전체 회차의 모든 조합을 전수 검사한 것으로 확대하지 않는다. [기능 결과](mobile-functional.json), [공개 화면 목록](evidence.json), [검증 범위](verification.json).

기준 main은 `d2419487d757886eae8a23781d3d1a80504a2553`, 검수한 공개 수정본은 `3896ddfd0c73d3ab291964e5fc6d0f9789bd0d73`이다. 공개 목록은 본편70화와 범퍼22편을 유지한다. 검수 원문·웹 파일은 그대로 두고 공개 근거와 병합 기록만 더했다. 병합 직전 최신 main 및 독립 검토를 확인하고, main 반영은 force 없이 수행한다. 저장소의 기존 Pages workflow는 main 반영 시 자동 실행된다.
