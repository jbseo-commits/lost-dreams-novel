## 인물과 이야기의 변화

서인이 같은 경고를 잊고 혼자 나가 다시 훈계받는 반복을 줄였다. 현장에 나타난 남자 이야기를 강연우에게 먼저 알리고, 정류장까지 이동할 때 통화를 요청한다. 습격으로 단말이 떨어져 통화가 끊기고 강연우가 다시 연락한 흔적을 남겼다. 완벽한 안전 판단을 하는 인물로 바꾸지는 않았다. 동행을 사양한 선택과 현장의 위협은 남는다.

배차 담당은 서인만 탓하는 대신 자신도 출차 확인을 믿고 보냈던 일을 돌아보고 다시 동행을 제안한다. 계약의 ‘또는’을 읽어 예비차를 내보내는 권한, 자기 이름으로 비용을 떠안는 선택과 소명 요구는 그대로다. 냉장차가 음식도 살리고 서인도 구하는 회수, 공동주방 책임자의 돌봄실 질문과 아침값, 아이가 건네는 숟가락을 보존했다.
