# 4화 관찰 단서 시네마틱 갤러리

- 대상: `manuscript/ep004.md`의 아르카디아 협상. 본편 텍스트와 저장 좌표 불변.
- 순서: **시계**(손목시계를 반복해서 만짐) → **메시지**(읽고 즉시 화면을 뒤집음) → **시선**(회의 종료에도 출입구 대신 창밖).
- 승인 목업 구현: 얼굴 비노출, 휴대폰 한 대, 모바일에서 한 행 3장의 터치 카드, 클릭 시 관찰 확대, '관찰 기록 펼치기' 버튼 유지.
- 실제 이미지 3종을 `vn/assets/ep04-clues/watch.webp`, `message.webp`, `gaze.webp`에 추가함. Git 객체 SHA:
  - watch: `2c5c77dcdda2261a9aeb1846a6430be7deb59129`
  - message: `2d4abdfeddab08726f3e784163ec90b0b041278f`
  - gaze: `e736cf8a56f87bce67ddd21686fc06a070353554`
- **배포용 이미지**: 기존 제작 CG를 192×144 WebP로 최적화한 경량 버전. 실제 카드에는 적합하지만 확대 시 원본보다 선명도가 낮음. 원본 1448×1086 WebP 3종은 대화 내 `ep04-clue-assets-github-ready.zip`으로 별도 보존됨. 고해상도 교체는 후속 작업.
- 검증 대상: 390/400px UI, 터치 → 확대 → 닫기 → 본문 이동, 화면 숨김 터치 차단, 이미지 요청 200, 공개 데모 빌드, GitHub Pages 배포.
