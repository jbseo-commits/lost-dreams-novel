# 제14화 독자 감사 — 두 번째로 보지 않은 사람

- 기준 main SHA: `90898eaef66329e9886994a34540739ff87ce1ca` (origin/main)
- 읽은 범위(정독): `manuscript/ep014.md` 전수(1~801행).
- 요약/검색 확인(정독 아님): `manuscript/ep013.md` 625~633행(13화 끝), `manuscript/ep010.md` 273~297행(17명 코호트). 제15화 이후 내용은 판정에 사용하지 않는다.

## 독자 시점 재구성

- 목적: 27분 안에 기밀 유출원(등급 4 전략 자료, 열람자 11명)을 찾아 협상을 살린다.
- 막힘: 전송 기록 없음·내부자 가능성 68.4%. 박선호의 숨김(손목 가림·문으로 간 시선·꺼진 화면)이 유출과 너무 잘 맞는다.
- 선택: 두 번째로 보지 않고 박선호를 지목한다 → 격리 후에도 노출량 증가(+7.2%→+11.8%)로 오판을 자인하고, 인간 가설을 빼고 재분석해 분류 규칙 충돌(외부 감사 미러 자동 복제)을 찾는다. 이후 B안 대신 아무것도 고르지 못한다.
- 결과: 계약은 유지됐으나 비용 +2.1%·물량 40% 축소. 서인은 쓰러지고 "최소 일주일" 진단을 받는다. "사람을 빨리 읽는 것과, 사람을 제대로 아는 것은, 같은 능력이 아니었다."

## 가장 먼저 이해가 끊긴 지점

254행 "네 번째 사람의 지나치게 느린 대답"에서 잠깐 멈춘다. 지면에는 세 사람(화가·겁·박선호)의 면담만 있고 네 번째의 느린 대답 장면이 없기 때문이다(audit-ep014-03). 10초 안에 목록의 취지(버리지 못한 가설들)로 넘어간다.

## 문제 기록

### audit-ep014-01 — 오판의 인과 증명 (문제 없음)

- 원문 인용 (`manuscript/ep014.md:137-165, 203-225, 285-353`):
  > 들키면 안 된다. / 지금 확인하면 끝난다. / 여기서 나가고 싶다. / 숨기는 게 있었다.
  > "이 사람이에요." / … / 서인은 박선호를 한 번 더 볼 수 있었다. / 그러지 않았다. / "네."
  > **외부 노출량 +7.2%.** / … / **외부 노출량 +11.8%.** / 박선호는 이미 모든 연결이 끊긴 상태였다. / 그런데 자료는 계속 나가고 있었다.
  > "열람자 전부 빼고 다시 계산해요." / … / 전날 밤 수정된 분류 규칙. / 내부 문서의 비식별 태그를 붙이는 조건 하나가 뒤집혀 있었다.
- 판정: 오판의 단서(숨김의 징후)→확신(두 번째로 보지 않음)→반증(격리 후에도 증가)→전환(인간 가설 제외)→원인(분류 규칙·미러 복제)의 사슬이 모두 지면에 있다. "자기가 읽은 것은 틀리지 않았다. 박선호는 숨기고 있었다. 그게 무엇인지 틀렸다."(423~427행)가 이 화의 명제를 한 줄로 봉합한다. 박선호의 다른 비밀(배우자 의료 기록·연산 무단 사용, 395~405행)도 유출과 무관한 별건으로 정리된다.
- 해결 방향: 수정 불필요.
- 분류: 문제 없음 / 상태: 해결 확인

### audit-ep014-03 — 지면에 없는 네 번째 면담 (문제 없음, 관찰)

- 원문 인용 (`manuscript/ep014.md:73-75, 239-268`):

  > 첫 번째 사람의 짜증. / 두 번째 사람의 떨리는 손. / 박선호의 닫힌 채널. / 네 번째 사람의 지나치게 느린 대답.
- 판정: 용의자 4명 중 지면에 면담이 있는 것은 3명뿐이고, 네 번째의 "느린 대답"은 독자가 목격하지 못한 장면의 한 줄 요약이다. 그러나 이 목록의 기능은 범인 찾기가 아니라 서인이 버리지 못하는 가설들의 나열(257~268행 "범인. 공범. 실수. 유도…")이며, 유출 원인이 인간이 아니라는 결론(343~353행)에 네 번째의 정체가 쓰이지 않는다. 선택·결과에 영향을 주지 않는 요약 생략이므로 본편 수정 대상으로 올리지 않는다.
- 해결 방향: 수정 불필요.
- 분류: 문제 없음 / 상태: 해결 확인

## 범퍼 검토 후보

없음. 13화→14화 사이(첫 업무 다음 날들의 위기)는 "첫 주 치고 이벤트가 많네요"(17행) 한 줄로 시간 경과가 처리되고, 공백 시간 제도의 후일담은 13-1화가 이미 맡고 있다. 박선호 사과 장면은 15화 본편에 있어 범퍼로 끌 문제가 아니다.
