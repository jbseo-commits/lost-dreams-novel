# 독자 검수 절차
기준 SHA: 7699855f8c31519ceaa9da0120b19430579f7548
읽기 순서: source-manifest.json files 배열의 order 1~125. 본편 1~105와 범퍼 20개. 파일명과 label 매핑은 배열에 고정되어 있음. 파일 path만 확인하고 미래 원문/설정/기존 평가/요약/기획/다른 독자 기록을 열지 말 것.
각 독자는 처음부터 순서대로 한 파일의 원문 전체를 읽는다. 다음 원문은 현재 판단과 이유를 기록한 뒤에만 표시한다. A=바로 다음을 누름, B=여기서 쉬고 나중에 읽음, C=자발적으로 여기서 하차. 범퍼도 독립 판정한다. B는 하차가 아니다. 첫 C는 불변이며 첫 C를 포함한 파일의 나머지와 이후는 업무 독서다. 이후 A는 흥미 회복 반응일 수 있으나 자발 독서 생존으로 되돌리지 않는다.
원문을 읽고 먼저 vote를 저장. 그 다음 별도 호출의 reason에 이유/인용/행을 저장. C는 문장 중간 위치도 지정 가능. 마지막까지 기다리지 않는다. 원문 전체 표시 자체가 실제 중간 중단의 증명은 아니므로 보고서에서 표시와 판단 위치를 구별할 것.
긴 분석보다 즉각 반응을 기록. 미래 반전으로 과거의 판단을 바꾸지 않는다. 이해 실패인지 이해했지만 지루함인지 구분. 조용함 자체를 결함으로 취급하지 않는다. 편집자/설정 검수자로 전환하지 말고 수정안/점수/PASS를 만들지 않는다.
문맥이 짧아지면 자신의 기록에 현재 인물/사건 기억을 간단히 남겨 이어 읽는다. 읽지 않은 원문은 미독으로 정확히 보고. 읽기 순서를 요약으로 대체하지 않는다.
각자의 reader-workspaces/readerN 안에만 기록. 다른 독자의 기록을 찾거나 읽지 않는다. 메인이 6명 완료 후 별도 최종 보고서로 종합한다.
