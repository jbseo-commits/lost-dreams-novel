# GitHub 공개용 사본 안내

이 폴더는 2026-10-15의 105화 독자 검수 전체 산출물과 2026-10-16의 5~7화 수정 계획을 게시한 사본이다. 사용자의 “일단 전체 내용 깃허브 올려줘” 지시에 따라 준비했다.

## 포함 범위

종합 보고서, 독자 6명의 보고서, 125개 파일의 화별 판단·잔류 표와 CSV, 본편 105화 잔류 CSV, 독자의 원본 판정·이유·상태·이벤트, 인용 정정과 집계 정정, 기준 SHA의 원문 snapshot125개, 읽기 순서와 blob 검증, 실행·검증 보조 도구, 수정 계획을 포함한다.

원고는 수정하지 않았다. source의 복제본도 검수 SHA의 원문 blob과 같다. 기존 manuscript/settings/웹/기존 기록 경로에 대한 변경은 없다. 수정 계획은 제안이며 미집필이다.

## 공개용 변환

- Markdown의 로컬 파일 링크를 이 폴더 안 상대 링크로 변환했다. 행 번호는 GitHub의 #L 형식으로 옮겼다.
- 개인 컴퓨터의 절대경로는 저장소 경로 또는 공개 제외 표기로 바꿨다.
- 로컬 실행 로그의 불투명 암호문 본문, 세션 UUID, 원본 로컬 로그 위치는 공개 제외 표기로 치환했다. 모델·역할·호출 시각·fork 옵션과 판단 검증 결과는 보존했다.
- 독자별 판단·이유·원문 인용·첫 C·업무 독서 표시·정정 기록은 원본과 대조했다. 원문 snapshot은 바이트 그대로 보존했다.
- 출력 파일 해시 목록은 공개용 변환 후 다시 생성했다.

공개 제외된 실행 지시 본문이나 세션 식별자는 이 사본만으로 독립 재검증할 수 없다. readable-brief는 메인이 작성한 읽기용 계약 사본이고, 암호화된 실행 지시의 자동 복구본이 아니다. 원본 모델 메타데이터와 별도 절차 검토의 대조 결과는 해당 evidence 설명을 따른다.

보고서의 “원격 반영 미실행” 등은 검수·계획을 완료한 당시 상태다. 이번 게시가 최초 반영이며 원고 수정·main 병합·웹 배포는 포함하지 않는다.
