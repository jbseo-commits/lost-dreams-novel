# 「꿈을 잃은 세계」 독자 이탈 검수 — 105화까지

**빠른 전개·일반 웹소설 독자는 7화, SF 독자는 25-1 범퍼, 인물 몰입 독자는 42화, 긴장 중심 독자는 46화에서 최초 C를 고정했다. 관계 중심 독자는 C 없이 105화까지 자발 독서를 유지했다.** 다섯 최초 C는 모두 뜻을 이해한 뒤 반복·대기 때문에 다음을 누를 마음이 꺼진 반응이었다.

여섯 명 모두 요청 범위의 **125개 파일(본편 105개 + 범퍼 20개)을 끝까지 읽었고 미독은 0개**다. 하차한 다섯 명의 이후 독서는 업무 독서다. 뒤에서 재미를 되찾은 A를 자발 잔류로 되돌리지 않았다.

이 수는 여섯 AI 역할의 이번 실행 기록이다. 실제 독자 이탈률·상업성·판매 전망으로 환산하지 않는다. 평균 점수와 통과 판정은 만들지 않았다.

## 4. 여러 독자가 독립적으로 지적한 이탈 원인

### 이해한 재선택 문제를 다시 묻는 귀환

빠른 전개·일반 독자의 최초 C는 7화, 긴장 독자의 최초 C는 46화다. SF 독자도 6화부터 같은 선택 문답에 B를 기록했고, 46화에는 여섯 명 모두 즉시 다음을 누르지 않았다.

6화의 “그럼 해야 하는 거 아니에요?”([manuscript/ep006.md:675](../source/manuscript/ep006.md#L675))와 7화의 “더 할 수도 있었잖아.”는 상대의 사정을 이해한 뒤에도 서인이 같은 답을 다시 요구하는 것으로 읽혔다. 46화의 “조건을 다 없앴는데도 돌아가요.”는 긴장 독자에게 열파 피해 뒤 초반 문답으로 돌아온 마지막 계기가 됐다. 다른 다섯 명도 46화에서 B 또는 업무 C를 기록했다.

문제가 된 것은 광고를 다시 고르는 인물이 있다는 사실이 아니라, 이미 이해한 선택을 다시 납득시키는 동안 서인의 새 행동을 기다리게 된 경험이다. 46화의 반응은 독자1~4 B, 독자5 최초 C, 독자6 업무 C다.

### 발견·정답 뒤에 심사·영향 확인·재계산이 계속 남음

SF 독자는 18화의 0.8초 중단 이후 실제 작동을 기다리다가 19~20화의 실행 조건에 피로했다. 관계 독자는 16~20화와 20-1에서 연속 B였고, 긴장 독자는 19화와 32~35화의 추가 절차에 B를 남겼다.

“등급 6 심사 조건: 공동 운영위원회 실무 참여 1회.”([manuscript/ep019.md:637](../source/manuscript/ep019.md#L637)), “영향 분석 예상 72시간.”([manuscript/ep035.md:563](../source/manuscript/ep035.md#L563))처럼 허점을 발견한 뒤 또 조건이 붙는 끝이 누적됐다. 인물 독자는 42화의 진행률 0퍼센트 재시작에서 최초 C를 고정했다.

42화는 취향이 갈렸다. 빠른 전개 독자와 긴장 독자는 규모를 세 배 놓친 위험에 A였다. 같은 압박이 누군가에게는 다음 사건이고, 다른 독자에게는 관계로 돌아가지 못한 대기였다.

### 이미 보인 변화의 의미·처리 범위를 여러 번 재확인함

74화, held89화, 92화에서는 여섯 명 모두 즉시 다음을 누르지 않았다. 74·89화는 B 다섯 명과 독자6의 업무 C 한 명, 92화는 B 여섯 명이다. 이 구간들에서 추가 최초 C가 발생한 것은 아니다.

74화는 민석이 얻은 한 시간 반을 지우·키 큰 여자·도윤이 차례로 다시 설명하는 피로였다. “여덟 시 반에서 열 시로 한 시간 반은 늦춰졌네요.”([manuscript/ep074.md:205](../source/manuscript/ep074.md#L205))와 “한 시간 반이면 어묵 두 번 먹고 드라마 한 편 볼 시간이야. 그거 적은 거 아니다.”([manuscript/ep074.md:235](../source/manuscript/ep074.md#L235)) 사이에서 독자들은 방금 본 결과를 다시 확인한다고 반응했다.

89화의 “그러면 오늘은 그냥 쉴게요.”([loop/held/ep089.md:215](../source/loop/held/ep089.md#L215))에는 마음이 갔지만, “오늘 밤만입니다.”([loop/held/ep089.md:251](../source/loop/held/ep089.md#L251))라는 범위를 통화·지급·장부·도착 뒤까지 확인하는 동안 피로했다. 92화의 “그럼 내가 잘된 걸 보려면 어디로 가요?”([manuscript/ep092.md:209](../source/manuscript/ep092.md#L209))는 도윤의 권위를 흔들었지만, 자료를 빼지 말고 원문을 함께 보자는 절차가 오래 이어졌다는 반응이 공통이었다.

## 7. 우선 손봐야 할 구간 — 최대 3곳

이 우선순위는 최초 C 전 누적 피로와 실제 최초 C를 먼저 고려한 메인의 판단이다. 독자에게 수정안을 만들게 하지는 않았다.

1. **5~7화, 특히 6~7화 후반의 재선택 문답.** 빠른 전개·일반 두 명이 7화에서 최초 C, SF·긴장도 6~7화 B였다. 4~4-1의 구체 승리와 다음 초대에서 붙은 독자가 서인의 다음 행동을 기다리는 동안 사례와 가정을 다시 듣는다. 관계·인물 독자의 관심은 남으므로, 인물의 결점 자체보다 같은 답을 다시 요구하는 구간이 얼마나 전진하는지 먼저 확인할 이유가 크다.
2. **23~25화와 25-1 범퍼의 선택·대기 재확인.** SF 최초 C가 범퍼 끝 412에서 발생했고, 빠른·일반 업무 B와 긴장 B도 ‘앞 화에서 본 하루와 대기의 반복’이었다. 인물·관계는 이웃의 대화에 A여서, 생활 장면의 존재보다 이미 본 결과로 돌아오는 전체 길이가 핵심 점검 대상이다.
3. **41~46화의 계산 대기와 열파 직후 재호 문답.** 42화는 인물 최초 C, 44~45화는 전원 A, 곧바로 46화는 긴장 최초 C이며 전원 B/C다. 실제 손실이 새 행동을 만들었다가 다시 같은 질문으로 돌아간다는 독립 반응이 가장 선명하게 이어진다. 42화의 위험에는 A도 있으므로 계산 장면 전체보다 관계 복귀의 지연과 46화의 되돌아감을 구분해 볼 필요가 있다.

74·89·92화의 공통 피로도 분명하지만, 이미 하차한 다섯 명의 업무 반응을 새로운 최초 하차로 바꾸지 않았다. held89화는 아래 임시 연속성 구간의 별도 진단에 남긴다.

## 9. 검증·보존과 방법의 한계

- 독자별 125개 완료·미독0, 총 2,250개 read/vote/reason 이벤트의 순서와 첫 C 이후 mode를 대조했다. 여섯 보고서와 125행 matrix·105행 본편 잔류표가 원기록과 일치한다.
- 인용 표기 9건은 별도 corrections 파일로 정정했다. 원래 판정·즉각 이유·이벤트를 지우거나 바꾸지 않았다. [인용 정정 모음](quote-corrections.json)
- 독립성은 새 대화 맥락·역할 분리·다른 평가 비공유 지시로 유지했다. 공용 파일시스템에 대한 보안상 접근 차단은 하지 않았다.
- 파일 전체 원문을 한 번에 표시하므로 중간 하차의 행은 자기보고다. 인간 독자의 실제 클릭·휴식 시간·물리적 중단 행동을 측정한 것은 아니다.
- 긴 원고의 문맥 정리 뒤 자기 로그를 보며 이어 읽었다. 후반 회고의 기억 부담에는 이 실행 방식의 영향도 분리해 입증할 수 없다.
- 실제 호출 옵션·세션·모델은 기록으로 확인했다. 로컬 로그의 초기 호출 본문·리마인더는 암호문이라 평문 원본을 자동 복구하지 못했다. [읽기용 작업 계약 사본](../evidence/readable-brief.md)은 메인의 재구성임을 명시했다.
- 기존 저장소의 원고·설정·웹·기록은 수정하지 않았다. 최종 보고서 사본의 원문 링크를 source 경로로 바로잡고, 독자1의 첫 C 전·후 A/B 부분합 오기만 원래 판단표로 재계산해 정정했다. 개별 판단·이유는 바꾸지 않았으며, 독자의 원본 보고서·로그는 reader-workspaces에 남겼다.

이 검수는 어떤 취향이 언제 다음을 누르지 않겠다고 반응했는지와, 그 뒤 어떤 장면에서 다시 관심이 생겼는지를 보존한 기록이다. 후반 A나 주제의 의미로 과거 C를 취소하지 않는다.
