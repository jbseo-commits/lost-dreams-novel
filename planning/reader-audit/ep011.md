### audit-ep011-02 — 인원수 정합: 열일곱 + 서인 = 열여덟 번째 (문제 없음)

- 원문 인용 (`manuscript/ep010.md:273-297`, `manuscript/ep011.md:214-222, 270-276`, `manuscript/ep014.md:338-342`):
  > "몇 명." / "열일곱." / "성공은?" / … / "셋." / "죽은 사람." / "두 명." / "나머지는." / "중단."
  > "열일곱 명 중에 둘은 모르는 것도 안다고 대답했어." / "그 둘은 지금 없어."
  > "열일곱 번 풀었어. 네가 열여덟 번째." / "다들 풀어 달라고 했어요?" / "너 빼고."
  > "중간에 멈춘 열두 명이 지금 어떻게 사는지 봤으니까."
- 판정: 17(성공 3 + 사망 2 + 중단 12) = 서인 이전 코호트, 서인은 18번째 시술자. "너 빼고"는 서인이 풀어 달라고 하지 않은 유일한 사람이라는 뜻이며 코호트 수와 충돌하지 않는다(사망 2명은 검사 오답 2명과同一로 11화에서 재확인된다). 독자가 세어보면 맞는다.
- 해결 방향: 수정 불필요.
- 분류: 문제 없음 / 상태: 해결 확인

- 분류: 정상 미스터리 / 상태: 미해결(회수 대기)
