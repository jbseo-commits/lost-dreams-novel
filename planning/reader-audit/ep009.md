## 독자 시점 재구성

- 목적: 쓰러진 몸을 회복하고 회사로 복귀한 뒤 특별 인지 평가를 받을지 정한다.
- 막힘: 빛·소리 통증, 사람의 다음 동작이 "너무 많이" 보임(137~141행), 복도에서 엿들은 "다음 단계" 대화.
- 선택: 공원에서 재호 목격→회사 복귀→도윤의 설명을 듣고 평가 수락("검사는 받을게요", 547행), 금속 조각 수령.
- 결과: AI 비의존 추론 적합도 측정 상한 초과(10화에서 통지), 평가 전날 밤의 장치와 "끝날 때까지 옆에 있을게"(745~747행).

## 가장 먼저 이해가 끊긴 지점

## 문제 기록

### audit-ep009-01 — 복도의 낯선 여자와 "다음 단계" (정상 미스터리)

- 원문 인용 (`manuscript/ep009.md:155-179, 199-215`):
  > "다음 단계는 보류해." / 낯선 여자가 말했다. / "시간 없어." / "얘 죽을 수도 있어." / "알아." / 도윤의 목소리였다. / … / 도윤이 말했다. / "그래서 내가 멈출 거야."
  > "언제부터 준비했어요?" / "좀 됐어." / … / "너 같은 사람을."
- 판정: 발신자 신원·"다음 단계"의 내용이 의도적으로 보류되나, 존재 신호(계획의 다음 단계가 있고 서인의 몸이 변수라는 사실)는 명확히 주어진다. 서인이 엿듣고 추궁하는 장면 안에서 독자의 질문("나를 위한 계획인가")이 인물과 동기화된다. 오류로 볼 근거가 없다. `loop/story-so-far.md` 제11화 요약에 회수 단서가 있으나 이번 판정의 근거로 사용하지 않으며, 다음 배치(11화 원문 정독)에서 착지 여부를 확인한다.
- 해결 방향: 수정 불필요.
- 분류: 정상 미스터리 / 상태: 해결 확인(감사 분류 확정. 서사적 회수는 다음 배치 확인 대상.)

### audit-ep009-02 — 능력 묘사의 연속성: 과부하에서 후유증으로 (문제 없음)

- 원문 인용 (`manuscript/ep009.md:117-141`):

- 해결 방향: 수정 불필요.
- 분류: 문제 없음 / 상태: 해결 확인
