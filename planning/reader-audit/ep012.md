- 읽은 범위(정독): `manuscript/ep012.md` 전수(1~605행).
- 요약/검색 확인(정독 아님): `manuscript/ep011.md` 499~533행(재인증·면담 예고), `manuscript/ep010.md` 273~297행(17명 코호트, audit-ep011-02와同一 근거). 제13화 이후 내용은 판정에 사용하지 않는다.

## 독자 시점 재구성

- 목적: 고위 전략직 전환 면담(11화 끝 "9시간 8분" 뒤)을 통과한다.
- 막힘: 검색대의 신경 서명 불일치(일치율 71.4%), 강연우의 실전 면접(틀리는 걸 보기), 숫자 없는 두 번째 문제.
- 선택: 모노 분석을 끄고 사람을 본다(셋째 책임자), 숫자만 있는 문제에는 "모르겠습니다"라고 말한다, 추론 출처 "미확인" 계약에 서명한다.
- 결과: 30일 잠정 배치·연산 무제한·등급 4. "다른 사람의 내일을 결정할 권한"을 얻는다.

## 가장 먼저 이해가 끊긴 지점

207~213행의 단위 없는 숫자("4만. / 11만. / 38만.")에서 10초가량 멈췄다가, 239행("서인은 숫자를 보지 않았다.")에서 의도적 노이즈로 해소된다(audit-ep012-02).

## 문제 기록

### audit-ep012-01 — 시간·서명 정합과 "미확인"의 엔진화 (문제 없음)

- 원문 인용 (`manuscript/ep011.md:480, 503-504, 533`, `manuscript/ep012.md:3-32, 481-505`):
  > 밤 11시 52분. … **알림: 고위 전략직 전환 면담까지 9시간 8분.**
  > 오전 8시 47분. / … / **등록 사용자와의 일치율 71.4%.** / … / **구두 재인증 이력 확인.**
  > **추론 출처: 미확인 / 외부 호출: 없음**
- 판정: 23시 52분 + 9시간 8분 = 익일 9시, 면담 당일 8시 47분 검색대 통과로 시각이 맞는다. 서명 불일치는 11화의 구두 재인증 이력으로 해소되고, "상층 모델 바꾸는 분들은 서명 흔들리는 경우 많아요"라는 직원 대사가 시술 흔적의 위장 환경을 본편 안에서 설명한다. "미확인"은 2회 배치가 정상 미스터리로 넘긴 추론 출처 문제(audit-ep008-03)를 덮지 않고 계약서 문구로 제도화해 다음 화들의 엔진으로 쓴다.
- 해결 방향: 수정 불필요.
- 분류: 문제 없음 / 상태: 해결 확인

### audit-ep012-02 — 단위 없는 세 숫자 4만·11만·38만 (문제 없음, 관찰)

- 원문 인용 (`manuscript/ep012.md:199-239`):
  > **경쟁사 선행 계약 체결.** / **예상 손실: 2.8%.** / **대응 경로 생성 중.** / 숫자가 벽을 덮었다. / 4만. / 11만. / 38만.
  > 상대가 A를 선택할 확률. / A를 예상해 B로 갈 확률. / … / 계산은 빨랐다. / 그리고 끝이 없었다. / 서인은 숫자를 보지 않았다.
- 판정: 세 숫자가 경로 수인지 금액인지 본편이 밝히지 않아 첫 독서에서 잠깐 멈춘다. 그러나 직후 확률 나열→"끝이 없었다"→"서인은 숫자를 보지 않았다"로 숫자의 무의미함이 명시되고, 면접의 판정 대상이 계산이 아니라 사람 보기(셋째 책임자)임이 275~331행에서 증명된다. 선택·결과에 영향을 주지 않는 일시적 멈춤이므로 본편 수정 대상으로 올리지 않는다.
- 해결 방향: 수정 불필요.
- 분류: 문제 없음 / 상태: 해결 확인

### audit-ep012-03 — "모르겠습니다"의 대가와 계약 (문제 없음)

- 원문 인용 (`manuscript/ep012.md:365-425, 507-565`):
  > "내일 가장 큰 사고를 칠 사업부를 골라 보세요." / … / "모르겠습니다." / "볼 게 없으니까요."
  > 멈출 이유가 없어서 멈추는 것. / 그게 지금은 생각보다 어려웠다. / … / 승인했다.
- 판정: 첫 번째 문제(볼 게 있음→본다)와 두 번째 문제(볼 게 없음→모른다고 말한다)의 대구가 "모르는 걸 모른다고 말하는 사람"이라는 채용 이유(505행)로 수렴한다. 승인 버튼 앞에서 일부러 손을 떼는 동작(519행)은 11화 이전의 재확인 버릇 상실과 대비되는 자각적 멈춤이며, 서인 본인이 차이를 의식한다. 목적·선택·결과가 원고만으로 연결된다.
- 해결 방향: 수정 불필요.
- 분류: 문제 없음 / 상태: 해결 확인
