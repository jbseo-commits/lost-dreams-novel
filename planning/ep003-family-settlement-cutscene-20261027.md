# 3화 지우 가족 정산 화면: 시선형 컷신 제작 카드

## 원문·설정 경계
- 정본 `manuscript/ep003.md`, "지우의 집".
- 시작: "지우가 가족 계정의 정산 화면을 내밀었다. 광고 수익 재개일과 퇴사 취소가 같은 날짜 아래 있었다."
- 발견: "서인은 화면을 받지 않았다."
- 행동: "지우가 팔을 내렸다."
- 후속: "왜. 그거 도와주는 건 싫어?" → "서인은 열린 지원 목록을 닫았다. 정산 화면을 받아 읽었다. 잘못된 곳은 없었다."
- 정확히 이어지는 다섯 문장의 앵커가 모두 맞을 때만 컷신을 재생한다. 원고·설정·선택지·저장 좌표는 수정하지 않는다.
- 화면에 실제 일자 숫자는 없다. `같은 날짜`라는 공통 적용일만 표시하고, 광고꿈 뒤의 인지 연산 비밀을 추론·확정하지 않는다.

## 아트·제작 결정
- 현 단계는 **실제 동작하는 DOM/CSS 시네마틱 컷신**이다. 신규 채색 원화가 아니라 저장소의 정본 `seoinWorry`와 `jiwooGuarded`를 사용한다. 휴대폰 단말은 CSS/문자 레이어이므로 일자·표시는 모바일에서도 읽을 수 있다.
- 화면 전환은 기존 VN 진행/이전/자동/읽은 곳 넘김/저장 복원을 그대로 사용한다. 컷신 자체가 입력을 가로채지 않으며 `prefers-reduced-motion`과 작품 설정의 움직임 감소를 지원한다.
- 공방/편의점의 기존 3화 컷신은 유지한다. 새 컷신은 원문 줄이 바뀌면 표시를 중지한다.
- 실제 신규 도색 컷을 추가하려면 지우와 서인 원화 정본을 참조한 연속 CG를 별도 제작하고, 시선·휴대폰 손잡이·의상 연속성 검수를 통과시켜야 한다. 이번 구현을 신규 채색 CG 제작 완료로 기록하지 않는다.
