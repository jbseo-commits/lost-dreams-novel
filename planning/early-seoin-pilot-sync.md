# 초반 서인 웹 동기화

2026-10-03 · `claude/writing-direction-doc-22sqhk`

`tools/sync_early_seoin_pilot.py`는 승인된 초반 보강 원고를 현재 `pilot.html`에 제한적으로 동기화한다.

- 독서 순서: 3→3-1→4, 5→5-1→6, 9→9-1→10→11.
- 새 장면 재현 세트피스: `mealchoice`, `uselesshour`, `returnlife`.
- 10화 동의 세트피스: 기존 단순 승인 연출 대신 현재 원고의 첫 번째/두 번째 읽기, 손을 뗌, 다시 승인, 완료 화면 재확인을 재현하는 `secondconsent`.
- 기존 1~40화, 기존 범퍼, 공통 엔진은 건드리지 않는다.

실행:

```bash
python tools/sync_early_seoin_pilot.py
```

스크립트는 예상 앵커가 바뀌었으면 assert로 중단한다. 성공 뒤에는 400×900에서 새 독서 순서, 팝업 기준 문장, 8배속/닫힘, 콘솔 오류와 기존 세트피스 회귀를 확인한다.

현재 GitHub 연결은 대용량 `pilot.html`을 부분 패치하는 쓰기 동작 없이 전체 파일 치환만 제공하므로, 이 브랜치에서는 안전한 결정적 패치 스크립트까지 커밋하고 실제 `pilot.html` 실행은 부분 패치가 가능한 실행 환경에서 수행한다.

## 2차 검수 후 원고 변경 (Claude, 2026-10-03) — 패치 실행 전에 반영할 것

독립 검수에서 5-1이 6화 서두("도윤에게 두 번째로 불려 갔을 때… 3.4토큰 갚으러 왔어요")와 충돌해, 5-1을 6화 이후로 옮겨 **`manuscript/ep006-2.md` (제6-2화)** 로 이름을 바꿨다. 패치 스크립트(`scripts/apply-early-bumpers-to-pilot.mjs`, `tools/sync_early_seoin_pilot.py`)는 아직 바꾸지 않았으니 실행 전에 맞춘다.

- 독서 순서: 3→3-1→4, **6→6-1→6-2→7**, 9→9-1→10→11. `BUMP`에서 `5:['5-1']`을 빼고 `6:['6-1','6-2']`로 한다. 키·팝업·`'5-1'`을 `'6-2'`로.
- 6-2 새 끝줄: "서인의 정산 칸은 그때도 비어 있었다." (hook과 `on`, KEY를 원고 문구 그대로 다시 쓴다. 지난 "혁명 이야기를 하지 않았다"는 삭제됨)
- 3-1 끝줄은 원고 그대로 "두 번째가 더 쌌다는 생각은 집에 도착할 때까지 세 번 났다." — 패치 hook을 이 문장으로 맞춘다. 팝업의 "장날", "그냥 먹고 싶어서"는 원고에 없으니 뺀다.
- 9-1 끝줄은 "그래도 한 번 더 읽었다." — 패치 hook을 맞춘다. 팝업의 "검사 받을 거야?"는 "내일 평가 받을 거야?"로, "남한테는 그렇게 잘 물어보면서" 문구는 삭제됨.
