# EP141–145 설계 — 사람을 빼는 실험

> 중심 질문:
>
> **인간을 시스템에서 해방시키고 싶다면, 먼저 인간이 없어도 되는 시스템을 만들어야 하는가?**

## 위치와 기능

3부 \`101–150: 도윤과 세습된 혁명을 이해한다\`의 아홉 번째 5화.

136–140에서 서인은 승인자4의 11분 셧다운 전체 기록을 확인했다.

그가 얻은 결론은:
- 셧다운 자체가 악은 아니다.
- 인간 reference를 제거하려는 목표도 틀렸다고 확정할 수 없다.
- 그러나 실험의 증명을 위해 타인에게 위험을 강제로 부담시키는 순간 권한 문제가 생긴다.
- “12분째의 비용을 누가 내는가”를 먼저 물어야 한다.

141–145는 이 교훈을 받은 서인이 **무모하게 다시 끄는 것이 아니라**, 실제 사람에게 위험을 떠넘기지 않도록 최대한 안전하게 설계한 제한 검증을 실행하는 구간이다.

그리고 바로 그 안전한 실험에서 중요한 사실이 드러난다.

> 문제는 ‘사람을 빼면 시스템이 무너진다’가 아니다.
>
> **현재 시스템이 인간의 희생을 전제로 너무 싸게 설계되어 있다는 것**이다.

이 발견이 146–150의 파괴→분리 전환을 만든다.

# 실험 설계 — HUMAN-OPTIONAL SHADOW TEST

서인은 승인자4의 실패를 반복하지 않는다.

실제 서비스를 끄지 않는다.

현재 시스템은 그대로 운영하면서,
동일한 입력을 복제한 **shadow system**을 병렬로 돌린다.

A:
현재 운영망
- human reference 포함
- anchor 포함
- 기존 cognitive network 포함

B:
인간 필수요소 제거 가상망
- 인간 reference 없음
- anchor 판단 없음
- 야간 인간인지 공급 없음
- AI/GPU/power fallback만 사용

실제 시민에게 적용되는 것은 A.

B는 결과만 계산.

즉 B가 틀려도 실제 피해 없음.

서인:
“이번엔 아무도 12분째를 내지 않아요.”

승인자4:
“좋습니다.”

그러나 이 실험은 ‘현재 기술로 인간 없이 가능한가’를 아주 잔인하게 보여 준다.

사람이 제공하는 실제 시스템 가치보다 낮음.

- 가족 보상
- 안정된 지위

를 받지만,
그들이 대체하는 GPU/전력/검증 비용과 비교하면 매우 저렴.

즉 체제는 단순히 인간이 필요해서 인간을 쓴 게 아니다.

> **인간을 쓰는 것이 가장 싸기 때문에 인간을 필수로 남겨 두었다.**

# 철학적 핵심

이 세계의 체제는 멍청하거나 악해서 유지되지 않는다.

오히려 너무 합리적이다.

인간 뇌:
- 이미 존재
- 저전력
- 병렬
- 비정형 판단 강점
- 보상 비용 낮음

GPU/전력/냉각:
- 비쌈
- 자원 필요
- 인프라 필요

따라서 체제 입장에서는 인간을 쓰는 것이 합리적.

혁명의 핵심은 그 합리성을 부정하는 게 아니다.

> **“더 비싸더라도 사람을 필수부품으로 쓰지 않겠다.”**

라는 사회적 선택.

그래서 최종 혁명은 효율의 혁명이 아니라
**비효율을 감수할 권리의 혁명**이 된다.

# 기존 요소 회수

## TOKEN
TOKEN 가격이 단순 화폐가 아니라 AI 서비스 요구권이라는 설정과 직접 결합.

인간 제거 → 서비스 생산비 증가 → TOKEN 실질 구매력 변화.

## 앵커
앵커 특권은 착취 대가이면서 동시에
사회가 비싼 비인간 reference 비용을 절약하는 방식.

## 광고꿈
인지 공급자가 받는 TOKEN보다
그들이 만들어 내는 시스템 가치가 큼.

## 세아
106–110에서 제시한 HUMAN-OPTIONAL REFERENCE PROTOCOL의 초기형이
실제 데이터로 가능성을 얻음.

## 승인자4
“끄지 마”가 아니라
“사람 없이 돌아가게 만들어라”의 증인으로 이동.

## 도윤
서인의 새 방향을 막지 않는다.
오히려 가능성을 인정.
그러나 이후 강제 restoration을 택하면서
둘의 차이가 선명해질 준비.
