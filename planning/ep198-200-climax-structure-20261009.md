# 198~200화 클라이맥스 구성 및 미확정 기술 인과 기록

> 기록일: 2026-10-09
> 상태: 작가가 승인한 **서사 방향 기록**. 아래 기술 메커니즘·사망 원인·위임 대상은 미확정이며, 원고나 정설로 승격하지 않는다.
> 작업 범위: 기획 기록만 추가. 기존 설정·원고·main은 수정하지 않는다.

## 확정된 서사 방향

- **198~199화는 2화 연속 클라이맥스**로 구성한다.
- **198화**: 비상 연속성 경로의 재활성화, 강제 복원 위기, 서인과 도윤의 이념 충돌, 도윤이 서인을 구하기로 결심하는 순간에 종료한다.
- **199화**: 도윤의 수동 차단으로 서인 구출 → 잔여 후계 강제 승인권 확인 → 별도의 의식적 결정으로 승인권 폐기 → 도윤의 죽음과 서인의 상실. 기술 설명보다 행동과 관계에 집중한다.
- **200화**: 몇 년 뒤의 독립적인 에필로그. 두 컵라면, 도윤에게 쓰다 지운 메시지, 어머니의 선택, 자녀들의 서로 다른 삶을 거쳐 마지막 문장 **“네가 정해.”**를 유지한다.
- 도윤은 자신의 강제 복원 사상이 틀렸다고 고백하지 않는다. 마지막 행동은 속죄 완료나 과거 책임의 소멸이 아니다.
- 서인은 **199화 마지막에 처음 “형”**이라고 부른다. 따라서 기존 199화 기획 초반의 “형이 그걸 정하면…”은 원고화 시 “도윤 씨가 그걸 정한다고…” 등으로 교정한다.
- 도윤의 첫째는 **가람**. 재호의 딸 **김하린**과 혼동하지 않는다. 둘째·셋째의 세부 이름은 확정 여부를 별도 점검한다.

## 198~199화 가안: 마지막 10분

| 시점(가안) | 사건 | 검증해야 할 조건 |
| --- | --- | --- |

| T-8~6분 | 서인이 강제 실행을 저지하려다 필수망·안전 인터록과 충돌 | 전체 정지가 환자·필수 서비스에 미치는 위험을 구체화 |
| T-6~3분 | 도윤이 수동 차단을 실행하여 서인을 구출 | 왜 현장 수동 확인이 필요한지, 왜 도윤이 실행하는지 입증 |
| T-3~1분 | 도윤이 살아 있는 잔여 위임권을 확인하고 독립적으로 REVOKE | 구출의 자동 부산물이 아님을 명시; 실제 위임 대상·ARMED 경위 미확정 |
| 마지막 | 서인이 처음 “형”이라고 부름. 도윤의 죽음과 침묵 | 기술 설명보다 인물 관계와 상실을 우선 |

시간 배분은 분량 설계용이며 실제 장치 반응 시간·생존 가능 시간을 확정하지 않는다.

## 기술 인과: 기존 설정과 보강 필요 지점

1. **이미 있는 복선**: 139~140의 운영자 확인/예외 권고 → 165의 새 모듈 FAIL CLOSED·레거시 의료 연속성 FAIL OPEN → 183~185의 계약상 잔존 우회 경로 → 198의 복합 조건에 의한 재활성화 → 199의 수동 차단.
2. **아직 미정**: 도윤의 사망을 유발하는 직접적인 물리·의학적 메커니즘. 단순한 버튼 조작으로 사망하거나 서인의 인지 과부하 규칙을 도윤에게 무단 전용하지 않는다.
3. **검증 후보(제안)**: 수동 차단 중 도윤이 치명상을 입고, 서인 구출 후 잔여 승인권을 별도로 폐기한다. 현장 개입의 필연성, 원격 대체 불가능성, 치명상 후 조작 가능 시간, 구조 불가능성을 모두 검증하기 전까지 정설로 쓰지 않는다.
4. **위임권 미정**: `SUCCESSOR DELEGATION: ARMED`의 설정 경위와 실제 대상은 미확정. `SUCCESSOR DELEGATION: REVOKE` → `REVOKED BY HOLDER`는 제안된 표현이며 실행 권한·효력을 검증해야 한다.
5. **회차 분량 원칙**: 198화에서 기술적 위기와 결심을 대부분 설명하고, 199화에는 구출·폐기·첫 “형”·상실의 세 장면을 집중 배치한다.

## 후속 검수 체크리스트

- [ ] 198화 마지막 장면의 선택과 199화 첫 장면의 동작이 정확히 이어지는가
- [ ] 도윤만이 수동 차단해야 하는 이유가 충분한가
- [ ] 사망의 직접 원인과 응급 구조 실패가 기존 기술 규칙에 부합하는가
- [ ] 승인권 폐기가 구출과 분리된 선택인가
- [ ] 199화 이전의 “형” 호칭이 없는가
- [ ] 200화의 컵라면·미전송 메시지·마지막 문장 “네가 정해.”가 보존되는가
