# 18~23화 장면 가시성 실제 적용 큐

대상 브랜치: `chatgpt/20261005-scene-visibility-audit`

목표: 사건·대사·설정은 바꾸지 않고 독자가 사람/공간/행동을 놓치지 않도록 카메라만 설치한다.

## ep018
- 시작부: `서인은 마지막 줄을 세 번 읽었다.` 직후에 작업 공간을 1~2문장으로 고정한다. 서인과 강연우가 같은 화면 묶음을 보고 있다는 사실이 먼저 보여야 한다. 이후 `다른 화면`, `세 번째 화면`은 새 장소가 아니라 같은 자리에서 화면을 전환하는 행동으로 읽혀야 한다.
- R-2 검증: 세 문제를 푸는 동안 최소 한 번 손목 띠, 화면, 강연우의 위치를 같은 프레임에 둔다. 숫자/문서만 연속되는 느낌을 끊되 문제 내용과 판단은 수정하지 않는다.
- `문이 열렸다`: 물리적 문으로 오독될 수 있으므로 `04-771 열람 창이 열렸다`처럼 대상을 명확하게 한다.
- 04-771 공급망: 현재 공급망 지도와 `4 / 6 / 두 칸 차이`는 보존한다.

## ep020
- 공동 운영위원회 시작: `공동 운영위원회 화면에는 사람보다 지도가 먼저 떴다.` 주변에 서인·윤세라·위원들의 실제 배치를 짧게 설치한다. 지도/승인자4 원격 자리/서인이 어디를 보는지 한 프레임에서 이해되어야 한다.
- 전체망 중단: `광고 수익 / 의료 보조 / 교육 크레딧 / 주거 감면 / 가족 단위 TOKEN 정산`은 삭제하지 않는다. 숫자가 쏟아지는 동안 서인이 화면의 어느 항목을 따라가는지 행동 하나를 둔다.
- 72시간: `72시간`과 `비상 생존 정산 모드`는 핵심이므로 설명을 늘리지 않는다. 서인의 손/화면/회의실 정적 중 하나만 붙여 선택의 무게를 물리화한다.

## ep023
- 설명회 시작: `설명회에는 얼굴 대신 질문이 먼저 떠올랐다.`는 보존한다. 직전 또는 직후에 서인·백윤하·강연우가 어디에 있고 질문이 어느 화면에 뜨는지 1~2문장으로 설치한다.
- `모릅니다`: 채팅이 멈추는 순간 서인의 마이크/화면과 강연우의 `이마를 짚었다`를 같은 프레임으로 묶는다. 대사는 바꾸지 않는다.
- 참여율 58→64→71: 숫자는 유지한다. 백윤하와 강연우가 같은 변화 화면을 보고 있음을 짧게 보여 준다.
- 신고 이후: `저 사람까지 밀어서 만든 숫자면요.` 장면은 이미 원인-반응이 강하므로 과설명하지 않는다.

## 완료 조건
1. 새 설정·사건·감정 이유를 만들지 않는다.
2. 기존 핵심 대사는 삭제하지 않는다.
3. 장면마다 3~5문장 안에 위치/인물 관계를 복원한다.
4. 숫자·정책 구간에서도 사람의 몸과 공간이 완전히 사라지지 않는다.
5. 짧은 문단과 속도는 유지한다.
6. 18→23 연속으로 읽었을 때 18화부터 갑자기 `화면 속 텍스트만 읽는 느낌`으로 바뀌지 않아야 한다.
