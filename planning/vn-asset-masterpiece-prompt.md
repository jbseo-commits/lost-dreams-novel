# VN 에셋 마스터피스 제작 지시서

이 문서는 비주얼 노벨 「꿈을 잃은 세계」 에셋을 만들 때 AI에게 그대로 붙여 넣는 프롬프트입니다. 1부 지시서, 2부 명세서, 3부 개별 에셋 요청 양식으로 구성됩니다. 근거 자료는 2026-10-19 실제 플레이 평가, `vn/assets/*/provenance.json`, `vn/story-data.js`의 장면 키 집계입니다.

목표는 "예쁜 그림"이 아니라 "이 장면의 사건·감정·계층 차이가 그림만 보고도 읽히는" 마스터피스급 에셋이다.

[작업 전 반드시 읽을 것]
1. AGENTS.md (특히 인물 성별 규칙, 웹 규칙)
2. settings/12-characters.md — 해당 인물 절 전체
3. settings/02-world.md — 계층·TOKEN·뉴럴피드 생활상

   - CG: vn/assets/ep1/cg-sea.webp
   - 타이틀 톤: 티저 S19 타이틀 프레임

[정전 고정값 — 절대 바꾸지 않는다]
- 서인: 남성. 검은 머리, 20대 후반. 여성 지칭·여성적 체형 금지.

[스타일 고정값]
- 차분한 회화풍 세미리얼 게임 아트. 채도 낮은 중간톤 + 장면별 단일 강조색.
- 하층(서인의 집·병원 동선·출근 열차): 형광등·텅스텐의 누런 빛, 낡은 질감, 좁은 공간 압박.
- 상층(회의실·재단·평가실): 차가운 유리, 넓은 여백, 반사광. 사람보다 공간이 큼.
- 꿈·광고꿈: 과포화 청록·백색광, 지나치게 완벽해서 불편한 느낌.
- 뉴럴피드·시스템 UI는 그림에 굽지 않는다 (게임이 HTML로 얹음). 화면 상단 오른쪽 1/3, 하단 1/3(대사창 영역)에는 핵심 정보를 두지 않는다.

[마스터피스 품질 게이트 — 하나라도 실패하면 재제작]
G1 서사 판독: 대사 없이 그림만 보고 "누가, 어디서, 어떤 압박 아래" 있는지 한 문장으로 말할 수 있다.
G2 원고 일치: 장소·시간대·인원수·소품이 원고와 일치. (예: 10화 "평가실에는 의자가 하나뿐" → 의자 1개. 소파 금지)
G3 인물 일관성: 기준 스프라이트와 얼굴형·머리·체형·의상 계열이 같다. 손가락 5개, 손에 든 물건의 쥐는 방식이 자연스럽다.
G4 감정 연기: 표정 차분 대비 — 같은 인물의 표정 세트끼리 눈썹·입꼬리·시선·어깨가 실제로 다르다. 얼굴만 바꾸고 몸이 같은 세트 금지.
G5 계층 대비: 같은 회차의 하층/상층 배경을 나란히 두면 빛·밀도·여백 차이가 즉시 보인다.
G6 UI 공존: 1280×720과 390×844 크롭 모두에서 대사창(하단 32%)이 얼굴·핵심 소품을 가리지 않는다.
G7 축소 판독: 25% 축소 썸네일에서도 실루엣과 장소가 구별된다.
G8 결함 없음: AI 흔적(녹은 글자, 뒤틀린 손, 이중 동공, 깨진 원근, 의미 없는 간판 글씨) 0개.
G9 세트 정합: 같은 장소의 아침/밤/식사 버전은 가구 배치·창 위치가 같다.

[제작 절차]
1. 장면 카드 작성 (3부 양식) → 원고 근거 줄 번호 명시.
2. 썸네일 구도 3안 (저해상도) → G1·G2·G6로 1안 선택. 선택 이유 기록.
3. 본제작. 인물은 기준 스프라이트를 레퍼런스로 넣고 편집 모드 우선.
4. 자가 검수: G1~G9 표를 PASS/FAIL로 채운다. FAIL은 원인과 재제작 내용 기록.
5. 같은 에셋 재제작은 최대 3회. 3회 FAIL이면 멈추고 작가에게 보고.
6. 원본 PNG 보존 → 런타임은 WebP 변환만 (크롭·리사이즈 금지, 명세 크기로 처음부터 제작).
7. provenance.json 기록 (2부 형식).
8. 게임에 연결 후 PC 1280×720, 1920×1080, 휴대폰 390×844에서 실제 장면 캡처로 G6 재확인.

[보고 형식]
- 만든 파일 경로와 크기
- G1~G9 결과표
- 원고 근거 (파일:줄)
- 실패·재제작 이력
- 확인 못 한 것과 이유
- (제안) 항목은 분리 표기
"검증 못 한 것을 PASS로 쓰지 않는다."

## 2부. 명세서

### 2-1. 파일 규격

| 종류 | 크기(px) | 모드 | 형식 | 경로 규칙 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 배경 | 1672×941 | RGB | WebP q88 (원본 PNG 보존) | `vn/assets/epNN/bg-장소-시간.webp` | 인물 없음. 하단 32%는 바닥·벽 등 정보 적은 영역 |
| 인물 스프라이트 | 1024×1536 | RGBA 투명 | WebP q90 | `vn/assets/epNN/인물-표정.webp` | 무릎 위~머리 위 여백 6%. 발끝 잘림 허용, 머리 잘림 금지 |
| 사건 CG | 1672×941 | RGB | WebP q90 | `vn/assets/epNN/cg-사건.webp` | 회차당 1~3장. 그 화의 선택·손해가 터지는 순간만 |
| 갤러리 썸네일 | 원본에서 게임이 축소 | — | — | 별도 제작 금지 | |

파일 이름은 영문 소문자와 `-`만 쓴다. 한 파일당 300KB(배경·CG)·250KB(스프라이트) 이하를 목표로 한다. 오프라인 단일 HTML이 이미 약 47.6MB이기 때문이다.

### 2-2. 인물 표정 세트 (인물당 최소)

| 표정 키 | 연기 지시 |
| --- | --- |
| `neutral` | 기본 상태. 어깨 힘 빠짐, 시선 정면에서 살짝 비낌 |
| `worry` | 눈썹 안쪽 올라감, 손이 몸 쪽으로 모임 |
| `firm` | 턱 내려감, 어깨 정렬, 시선 고정 |
| `wounded` | 시선 떨어짐, 한쪽 어깨 처짐, 입 다묾 |
| `tease` / `warm` | 인물 성격에 맞는 쪽 하나. 입꼬리보다 눈가로 표현 |

같은 인물이라도 표정마다 **몸 자세를 다시 그린다**. 얼굴만 바꾼 세트는 G4 FAIL로 처리한다.

### 2-3. 제작 우선순위 (실제 데이터 기준)

`story-data.js` 장면 키 집계(문장 수)를 기준으로 정했다.

| 순위 | 대상 | 근거 | 효과 |
| --- | --- | --- | --- |
| 1 | `neutral` 장면을 실제 장소로 분해 | 11,997문장이 빈 무대 | 31~105화 체감 최대 |
| 2 | `meeting` 상층 회의실 세트(낮/밤) | 2,711문장 | |
| 3 | `office` 서인 회사(아침/야근) | 1,934문장 | |
| 4 | `kitchen` · `room` 서인의 집 연속 세트 | 1,161 + 913문장 | 1화 집과 G9 정합 |
| 5 | `clinic` 클리닉 지하·장부실 | 1,099문장 | 80~90화대 핵심 |
| 6 | 10화 "의자 하나의 평가실" 전용 배경 | 현재 펜트하우스로 오배치 | G2 위반 수정 |
| 7 | 반복 인물 10명 표정 세트 | 12-characters.md 1~10절 | 화자 판독 |

1순위는 먼저 `neutral` 문장들을 원고의 장소로 분류하는 표가 필요하다. 그림을 그리기 전에 explorer가 회차별 장소 목록을 뽑고, 같은 장소는 배경 하나로 묶는다.

## 3부. 개별 에셋 요청 양식 (매번 채워서 1부 뒤에 붙임)

```
[에셋 요청]
종류: 배경 / 스프라이트 / CG
파일명: vn/assets/epNN/________.webp
쓰이는 곳: 제N화 ___ 장면 (manuscript/epNNN.md:__~__)
원고 근거 문장 (그대로 인용):
  "..."
장소·시간대·날씨:
등장 인물과 표정 키:
이 장면의 압박/선택 (한 줄):
보는 사람이 느껴야 할 것 (한 줄):
반드시 있어야 할 소품 (원고 근거 있는 것만):
절대 없어야 할 것:
계층 톤: 하층 / 상층 / 꿈 / 경계
같은 세트로 맞출 기존 에셋:
구도 메모 (카메라 높이, 인물 위치 좌/우, 여백 방향):
```

### 작성 예 — 10화 평가실

```
[에셋 요청]
종류: 배경
파일명: vn/assets/ep10/bg-evaluation-room.webp
쓰이는 곳: 제10화 첫 장면 (manuscript/ep010.md:3~25)
원고 근거 문장: "평가실에는 의자가 하나뿐이었다." / "조명이 꺼졌다."
장소·시간대: 상층 기관 평가실, 실내 인공광
등장 인물: 없음 (배경)
압박/선택: 평가받는 사람에게 앉을 자리 하나만 허락된 방
느껴야 할 것: 넓은데 숨 막힘. 사람이 측정 대상이 되는 공간
필수 소품: 의자 1개 (원고 근거). 그 외 소품은 원고 확인 후에만
금지: 소파, 장식 식물, 도시 전경 창 (기존 오배치 원인), 글자 있는 간판
계층 톤: 상층 — 차가운 백색광, 반사 바닥, 넓은 여백
세트: 조명 꺼짐 버전 bg-evaluation-room-dark.webp 를 같은 구도로 추가
구도: 눈높이보다 약간 높은 카메라, 의자는 화면 중앙보다 약간 위(대사창 회피)
```
