# 효나씨 정독 편집 · 진행 기록

- 상태: 사용량 확인 대기. 현재 완료 화 없음, 다음19화. 원고 수정·삽화 평가 미착수.
- 최신 요청:19화부터 현재 정본 독서 순서로 한 화씩 정독·수정한다. 캐릭터 매력과 이야기 재미를 우선하고, 실제 연결된 삽화의 장면 적합성·몰입·어색함을 직접 평가한다.
- 사용량 조건: 계정의 남은 사용량50% 이하에서 중단. 조회 도구가 없어 어떤 한도인지/현재 잔여율을 확인하지 못했다. 사용자에게 현재 수치를 요청했다. 토큰 수·경과시간을 잔여율로 환산하거나 자동 감시한다고 주장하지 않는다. 확인 가능한 기준 없이 긴 연속 편집을 시작하지 않는다.
- 기준: loop/hyona-reader.md. 한 화 전체 정독, 앞선 원문에 근거한 인물별 말투, 원문→수정문→이유, 같은 검수자의 최종 수정본 전체 연결 독서. 기존 수정 이력/누계를 보존한다.
- 실제 적용 전 최신 정본의 독서 목록과 합쳐지거나 퇴역한 사이 화수 구조를 확인한다. 파일 존재만으로19-2 등 독립 회차를 다시 만들지 않는다.
- 삽화는 실제 연결 파일과 전후 장면을 대조하고 직접 본 범위를 기록한다. 교체·새 이미지 생성은 이번 요청 범위가 아니다.
- 새 회차 집필·머지·공개배포·설정 확정은 하지 않는다. 보관 원고는172화까지이며 새173화는 미작성이다.
