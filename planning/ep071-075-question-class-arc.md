
# EP071–075 설계 — 질문할 수 있는 사람

> 중심 질문: **다시 물을 권리를 모두에게 줘도, 모두가 같은 답을 얻을 수 있는가?**

## 핵심
66–70의 동부 27 실험에서 공공 재검증권은 성공했다. 71–75에서는 이를 확대한다.
TOKEN 개혁은 실패하지 않는다. 돈 때문에 중요한 질문을 다시 묻지 못하는 사람은 크게 줄어든다.
그러나 돈의 벽 뒤에서 시간, 문해력, 제도 경험, 질문 구성 능력, 첫 답을 의심할 심리적 여유, 실패를 버틸 안전망의 격차가 드러난다.

새 계급은 TOKEN 부자가 아니라 **질문을 잘 만들고 의심할 여유가 있는 사람**이다.

## 공공 재검증 개혁
의료·주거 안전·교육 배치·재난/보험·필수 생계 행정에서 일정 횟수 재검증을 TOKEN 잔액과 분리한다.
1차 재검증은 간단 신청, 고위험 판정은 교차검증, 결과가 달라져도 불이익 없음.
31화의 상층 특권을 아래로 내려보낸다.

---

# 71화 — 한 번 더
정책 첫날. 노인이 1차 의료 판정을 보고 묻는다.

“이거 한 번 더 물어봐도 돈 안 들어?”
“네.”
“진짜?”
“네.”

노인은 한참 있다가 재검증 버튼을 누른다.

실제 성공:
- 저소득층 재검증 이용 급증
- 오판 수정
- 교육 배치 재조정
- 주거 안전등급 수정
- TOKEN 장벽 사례 대폭 감소

지우 가족 같은 기존 생활권 인물을 연결한다. 예전 같으면 6.8 TOKEN 앞에서 망설였을 추가 의료 검증을 무료로 누른다.

지우: “이제 이건 안 아껴도 되는 거네.”
서인: “응.”

이 순간은 진짜 승리다. 71화는 성공으로 끝낸다.

---

# 72화 — 두 번 물은 사람
같은 무료 재검증권을 가진 두 사람이 다른 결과를 얻는다.

박미라(가칭)는 야간근무자. 아들의 학교 배치가 이상하다고 느끼지만 이유를 정확히 설명하지 못한다.
1차: 현재 배치 적정.
무료 재검증: 현재 배치 적정.

같은 학교의 다른 부모는 부자는 아니지만 사무직이고 문서/AI 도구에 익숙하다.
그는 통학시간 제외, 최근 적응도 가중치 축소, 평가 오류 가능성, 대체학교 교차비교를 각각 묻는다.
결과: 재배치 권고.

둘 다 무료였다. 차이는 돈이 아니라 질문이었다.

서인: “같은 권리를 줬는데요.”
TOKEN 개혁파: **“같은 버튼을 준 거죠.”**

미라가 묻는다.
**“나는 뭘 더 물었어야 했어요?”**
서인은 바로 답하지 못한다.

---

# 73화 — 시간이 있는 사람
두 번째 격차는 시간이다.

재검증 자체는 무료지만 자료 제출, 상담, 대기, 결과 비교에는 시간이 든다.
상층은 기다리는 동안 생활이 무너지지 않는다. 하층은 다르다.

미라가 아들의 배치를 다시 검토하려면 평일 낮 상담이 필요하다.
상담비는 무료지만 일을 빠지면 일당과 야간수당이 줄어든다.

미라: “무료라면서요.”
직원: “상담은 무료입니다.”
미라: **“그럼 오늘 일당은 누가 줘요?”**

반대로 은퇴한 김 영감은 절차를 끝까지 파고든다.
“돈 없는 대신 시간은 많아.”

서인은 대리 질문 지원, 야간/비동기 창구, 음성 신청, 자동 자료 첨부를 제안한다.
중요: 이 개선도 실제 효과가 있다.

---

# 74화 — 질문을 대신해 드립니다
서인이 합리적인 해결책을 만든다.

PUBLIC QUESTION ASSIST:
사용자가 상황을 말하면 공공 AI가 추가 검증 질문 후보를 만든다.
최근 데이터 편향, 대체 기준, 독립 교차검증, 예외 사례 등을 자동 제안한다.

효과는 크다. 미라 같은 이용자도 훨씬 좋은 재검증 결과를 얻는다. 격차가 다시 줄어든다. 또 성공이다.

하지만 수많은 사람이 비슷한 ‘잘 정리된 표준 질문’을 하기 시작한다.
AI는 가능한 질문을 잘 정리하지만 AI가 생각하지 못한 질문을 대신 만들어 주지는 못한다.

서인은 한 사건에서 추천 목록을 전부 보고도 이상함을 느껴 목록 밖 질문을 한다. 결과가 뒤집힌다.

담당자: “왜 그걸 물어보셨어요?”
서인: “그냥 이상해서요.”

초능력이 아니라 기존의 불일치 감지/가지치기 능력으로 표현한다.

불편한 깨달음:
**질문 격차를 AI로 줄이면 더 평등하게 질문할 수 있지만, 질문의 다양성 일부가 다시 AI의 사고공간으로 수렴한다.**

평등과 인간적 불규칙성이 처음 충돌한다.

---

# 75화 — 무엇을 물어야 하는지
TOKEN 개혁 1차 결산.

- TOKEN 기반 재검증 격차: 크게 감소
- 저소득층 재검증 이용: 크게 증가
- 수정된 공공 판단: 증가
- 질문 지원 이용: 증가
- 결과 격차: 감소했으나 잔존

개혁은 성공했다.

잔존 격차의 원인은 시간, 문해력, 제도 경험, 질문 구성 능력, 첫 답을 의심할 심리적 여유, 실패해도 버틸 생활 안정이다.

TOKEN 개혁파: “그래도 전보다 훨씬 낫습니다.”
서인: “맞아요.”
“그러면 더 하면 됩니다.”
서인도 동의한다. 그러나 묻는다.
**“끝이 있어요?”**

## 어머니 장면
서인의 어머니가 공공 재검증 화면을 본다.

서인: “왜 안 눌러?”
어머니: “뭘 물어봐야 하는데?”

서인이 여러 질문을 대신 생각해 준다.
어머니가 화면보다 서인을 본다.

**“너 없으면?”**

서인이 멈춘다.

## 도윤
서인: “돈 문제를 줄였더니 질문 문제가 나왔어요.”
도윤: “응.”
“질문 문제를 줄이면 또 뭐가 나와요?”
도윤: “모르지.”

서인이 의외라는 듯 본다.

도윤: **“그걸 알았으면 진작 끝났겠지.”**

도윤을 전지적 현자로 만들지 않는다.

## 마지막
서인은 과거 상층 검증의 1.2M / 3.8M / 6.4M / 9.4M 구조를 다시 본다.

이제 숫자 아래가 보인다.
상층은 돈만 많았던 것이 아니다.
전문가가 질문을 만들고, 기다릴 시간이 있고, 틀린 답을 의심하도록 교육받고, 여러 답을 비교하는 법을 배우고, 실패하면 다시 시작할 안전망이 있었다.

마지막 문장:

> **돈을 나누는 것보다 어려운 것은, 의심할 여유를 나누는 일이었다.**

---

# 71–75 감정 곡선
71: 가난한 사람도 다시 물을 수 있다.
72: 같은 버튼을 눌러도 질문이 다르면 답이 다르다.
73: 무료 질문에도 시간이 든다.
74: AI가 질문 격차를 줄이지만 질문 자체가 표준화된다.
75: 돈의 계급 뒤에 ‘의심할 여유의 계급’이 있었다.

## 계급의 심화
기존: TOKEN이 많은 사람 = 더 많이 틀릴 수 있는 사람.
개혁 후: **여유가 많은 사람 = 언제 다시 물어야 하는지 아는 사람.**

상층은 답을 산 것이 아니라 **의심을 계속할 수 있는 환경을 샀다.**

---

# 76–80으로 넘길 질문
조건을 꽤 많이 고쳤다.
생계 보전, 재검증 평등화, 질문 지원, 회복 기간, AI 선택권까지 제공했다.
그런데도 일부 주민은 광고꿈을 다시 켰다.

다음 질문:
**사람들은 왜 자유로운 조건에서도 광고꿈을 선택하는가?**

광고꿈을 중독상품으로 단순화하지 않는다. 실제로 좋은 꿈이어야 한다.
잃은 사람과 다시 만남, 실패하지 않는 하루, 젊었던 몸, 가지 못한 여행, 가족과 평온한 저녁 등.

76–80의 중심:
**행복을 선택하는 것과 꿈꾸기를 포기하는 것은 같은가?**

# 품질 게이트
- TOKEN 개혁은 실제 성공해야 한다.
- 무료 재검증을 숨겨진 유료화로 뒤집지 않는다.
- 새 계급을 ‘똑똑한 사람 vs 멍청한 사람’으로 만들지 않는다.
- 질문 능력 차이는 교육·시간·경험·심리적 안전과 연결한다.
- 박미라를 무지한 하층민 캐리커처로 만들지 않는다.
- 공공 질문도우미 AI도 실제 효과가 있어야 한다.
- AI 질문 표준화 문제를 즉시 재앙으로 만들지 않는다.
- 서인의 통찰은 마법이 아니라 불일치 감지로 표현한다.
- 도윤이 모든 다음 문제를 이미 알고 있지 않게 한다.
- 75화에서 TOKEN 개혁을 부정하지 않는다.
- 결론은 ‘평등은 불가능하다’가 아니라 ‘평등하게 다시 물으려면 돈보다 더 많은 조건을 나눠야 한다’이다.
