- 최소 수정: 177화에서 방송 중단을 ‘연상 실험의 창’이자 원천 replay/출처인증 모듈의 불법 복제·탈취 기회로 명시. 기술의 정확한 원천은 확정 설정에서 미정이므로 **구체 모듈은 작가 승인 전 확정 금지**. 사건 전후 소유권·접근권 변화와 보관된 서명으로 입증할 것.

### P0-2. 서인의 상층 잠입용 **극한 인격 조정에 도윤이 관여**한 사실이 178화에서 충분히 회수되지 않음
- 근거: \`settings/07-antagonist.md\` 작가 확정: 도윤이 극한 뇌내 스캔·인격 조정을 통해 AI 없는 통찰 요원을 만들려 함. \`settings/08-protagonist-cognition.md\`: 시술은 원래 재능을 만든 것이 아니라 재확인 브레이크를 약화.

### P0-3. 도윤의 역사 편집 정체 공개 시점 중복
- 근거: \`planning/200-episode-world-reveal-master-arc.md\`는 **126–130화에서 도윤이 과거를 하나의 혁명으로 만든 사람**임을 밝히고, **176–180화에서 최종 적대자의 정체를 확정**.

## 2. 우선순위 P1 — 강한 장면을 약화하는 구조적 문제

### P1-1. 200화 시간 점프와 공존 체제의 증거 부족
- 마스터 아크는 “몇 년 뒤 기존 체제와 분리 체제 공존”.
- 현재 200화는 “시간이 흐른다”에 그침.
- 제안: **몇 년 뒤**를 명시하고, 광고꿈 계속 사용하는 가정 / 자발적 앵커 참여 / 연결을 끊고 사는 사람의 서로 다른 생활 장면을 병치. 어떤 선택도 계몽/실패로 단정하지 말 것.

### P1-2. 181–185화 TOKEN 전쟁의 스케일과 서인 능력의 대가가 약함
- 마스터는 국가·기업·혁명군·기준계열의 충돌과 서인 가지치기의 최고조를 요구.
- 상세 설계는 청산위원회 심의·가격·계약 분리에 집중되어 정치적/전략적 전쟁의 실감이 약함.
- 제안: 재검증 선점 경쟁의 구체적인 **상대 전략과 반전**, 서인의 가지치기 한 번이 필수 서비스와 특정 시민에게 동시에 낳는 대가, 국가/기업의 서로 다른 계산을 한 사건으로 묶는다. 191–195 과부하의 전조를 185에 물리적으로 심는다.

### P1-3. 중반 51–100화와 후반 151–190화에 반복 구조 위험
- 앵커 이탈 실험→부작용→보완, 개혁 실험→격차→보완, 모듈 결합→감사→보완, TOKEN 변경→감사→보완이 누적될 수 있음.
- 제안: 각 10화에서 최소 하나는 **인물 관계의 돌이킬 수 없는 손실**, 하나는 **생활 속 결과**, 하나는 **주요 권력 관계 변화**를 강제. 보고서/위원회/감사 장면 연속 2개 이상이면 장면 교체 검토.

### P1-4. 도윤의 세 자녀가 후반에 역할 기능으로만 축소될 위험
- 171–175화는 감정선이 강하지만 196–200화에서 하린=기록, 도준=교육, 세아=기술이라는 기능으로 요약됨.
- 제안: 200화에서 각자 **아버지의 유산을 받아들이거나 거부하는 사적이고 비효율적인 행동** 한 가지를 추가. 클론/연속성 기록의 미확정 암시도 설정집 \`settings/10-heirs-and-epilogue.md\`에 맞춰 선택적으로 한 장면 배치하되 실존 확정 금지.

### P1-5. 195화 “모르겠습니다”의 선행 회수 확인 필요
- 마스터는 11–15화에서 이 말이 패배처럼 느껴지는 서인을 요구.
- 제안: 초반 서인이 “모르겠습니다”를 **끝내 말하지 못해 실제 손해를 낳는 장면**을 보존/배치해 195화와 대칭시킨다. 단순 명대사 반복은 금지.

### P1-6. 198–199화 장치 위기가 다소 편의적으로 보일 위험
- 최종 우회 인증, 안전 인터록 이상, 과열이 198–199에 연속 등장하지만 161–185의 모듈 구조와 정확히 연결된 고장이 아니다.
