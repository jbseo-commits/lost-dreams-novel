# PR #84 · 검수본 공개 통합

사용자의 “PR #84 이것도 해야하지 않아?” 요청에 따라 PR #84의 검수 완료 범퍼16-1·19-1·19-2와 재등장·독서 흐름 지침을 최신 main에 통합한다. 앞서 main에 반영한 공개18편과12-1화의 개선은 유지한다. 미공개71화 이후 원고는 포함하지 않는다.

세 편 본문은 검수 커밋 `37a8133842bbd5a8fe2154b7bdb91ad6c4f1f604`와 바이트 동일하다.16-1은7항9.5/9.5/9/9.5/9.5/9/8.5(평균9.2143),19-1·19-2는 각 항9(평균9.00), 필수·분량 PASS다. 같은 검수자가 변경된 공개 연결과 실제 화면을 다시 확인했다. 새 전체 재독이나 점수 재설정은 아니다. [원문·점수](results.json).

검토 전용 연출 파일의 그림·문장·발동 기준은 그대로 두고 일반 공개 모듈 `reader-bumper-scenes.js`로 연결했다. 검토 모드의 ORDER 전체 교체와 PR 문서 제목 설정은 제거했고, 회차 배경 표시는 각 장면 이름을 쓴다. 본편 상한70을 유지하며 범퍼는25편, 읽기 목록은95개다. 순서는16→16-1→17,19→19-1→19-2→20이다. 자동 생성 manifest는 직접 수정·추적하지 않았다.

일반 공개 화면을400×900으로 열어 초기 팝업 없음, 끝까지 스크롤한 뒤 실제 발동, 본문 복귀, 목록 열기·닫기, 연출 끄기, 다음 화 이동을 확인했다. 선행16→16-1·19→19-1도 실제 버튼으로 확인했다. 핵심 독서 기능5사례는 통과했으며 JS 오류·로컬 자산 실패·가로 넘침·숨은 레이어 터치 차단은 없었다. [기능 결과](mobile-functional.json), [실제 화면6장](evidence.json).

초기 검사에서 기존 Google Fonts 외부 스타일 요청이 실패해 광범위 요청 게이트는 세 편 모두 실패했다. 해당 실패를 [원본 결과](mobile-raw.json)에 보존했다. 추가 외부 글꼴 진단은 글꼴 URL에 원고에서 유래한 문자가 담겨 외부로 전송될 수 있다는 자동 승인 검토의 이유로 거절됐다. 외부 호스트를 모두 사전 차단한 로컬 확인으로 대체했고, 범퍼 SVG의 실제 글꼴은 system-ui, sans-serif였다. [로컬 확인](font-diagnostic-local-only.json). 외부 글꼴 다운로드 성공으로 보고하지 않는다.

기존 Node CI10개, JS/inline 문법, 목록 생성·삽입 순서를 확인했다. Git의 CHANGELOG/pilot 충돌은 기존 main 수정과 PR 범퍼를 함께 살려 해결했다. AGENTS·집필 방향·가시성의 PR 지침을 보존하고, 공식 요약·현재 노선·루프 로그에 공개된 세 사건을 반영했다. settings/05의 세 항목은 개별 거래 사례로만 확인하며 일반 권한·법칙이나 다른 미확정 제안을 확정하지 않았다. 초기 미공개·연출 미구현 기록은 당시의 기록으로 남겼다. [검증 범위](verification.json).

기준 main은 `ec37ac0037ef403e8f85189946a7ddc8c993f322`, PR 최초 head는 `0805ec399b5c1e5c8ec57e6f2994ba9d3c7b97fd`다. PR 브랜치 `codex/intermediate-authority-chain`을 먼저 갱신하고 같은 공개 통합 커밋을 main에 반영한다. 두 기준의 커밋 이력을 보존하며 force push 없이 처리한다.


## 후속 확인 · 작가 “마스터피스로 병합” 지시

- 확인 당시 main `1846010641065042e0ce253832a2b99e77855562`는 이미 공개 통합 `7768d963813e5bad223261a10e0e9ca803a34b29`를 포함했다. 세 원고는 위 검수 결과의 원문 해시와 일치했으며, 해당 통합과 최신 main의 Pages 배포도 성공했다. PR #84만 이미 병합된 부모 브랜치를 대상으로 OPEN 상태였다.
- 기존 결과표의 19-2 분량 3,510자는 제목 포함 측정이다. 제목을 제외하면 3,499자로 하한에 1자 미달해 당시 형식 PASS의 분량 근거가 부정확했다. 이를 숨기거나 기존 결과표를 덮어쓰지 않고 이 절에 정정한다.
- 보정은 “서인은 그 손으로 서류를 받았다” → “서인은 그 손으로 서류를 건네받았다” 한 어구다. 앞에 “남자가 서류를 내밀었다”가 이미 있어 전달 동작을 명확히 하며 새 사건·권한·설정을 만들지 않는다. 보정 뒤 제목 제외·공백 제거 본문은 3,501자, SHA-256은 `dd28d38e0e884fecebadbbb5ac22829e8323ef2d1194b9b850658c118ff28b5a`다.
- 최초 체인의 같은 별도 편집자가 변경 어구와 인접 문단을 확인해 전달 경로·가시성·문법·행동 연속성 및 형식 보정 PASS를 회신했다. 새 전체 재독·7항 점수 갱신·원고 수정 한도 초기화는 수행하지 않았다. 기존 후속 7항 검수는 해당 source_commit의 역사 기록으로 보존한다.
- 16-1·19-1 본문은 각각 3,593·3,574자로 변함없다. 현재 main의 21~22 개고와 공개 연출은 보존하며 새 연출 코드를 추가하지 않는다. manifest 직접 수정·공식 줄거리 변경 없이 `git diff --check`와 기존 목록 생성기로 확인한다. PR #84의 base를 main으로 바꾸고 이 형식 보정을 병합한다.
