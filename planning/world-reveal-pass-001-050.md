# WORLD REVEAL PASS · 1~50화

> 목표: 설정을 더 설명하지 않는다. 설정 때문에 사건이 벌어지게 만든다.
> 상태: 진단/재설계 단계. 이 문서 승인 전 원고 직접 수정 금지.

## 0. 핵심 진단

1~20화는 작품의 핵심 질문과 SF 장치가 비교적 선명하다. 광고꿈의 매력, 회복 뒤 재가입, 서인의 인간 통찰, 상층의 재귀 AI 병목, 과부하, 인지망의 실제 사회적 효용까지 사건으로 드러난다.

그러나 21~50화는 세계를 넓히는 대신 운영 규칙의 미세 조정이 전면으로 나온다. 승인 등급, 시범 운영, 재심사, 신청 순번, 주소군, 조회 기록, 이름표, 물·컵·고지서 등 개별 연속성은 촘촘해졌지만, 독자가 설정집에서 느끼는 거대한 세계의 확장감은 오히려 약해진다.

특히 31~50화는 `규칙 발견 → 허점 발견 → 서인이 최소 수정 → 새 부작용 → 다시 수정`의 문법이 반복된다. 이것은 서인의 윤리적 성격을 보여 주지만 20화 이상 이어지면서 TOKEN·혁명·상층·인지망·앵커·도윤이라는 대형 축을 뒤로 밀어낸다.

따라서 목표는 전면 재집필이 아니라 **세계관의 크기를 사건의 크기로 되돌리는 것**이다.

## 1. 50화까지 독자가 반드시 가져야 할 다섯 감정

1. `광고꿈이 나쁜 건 알겠는데 나라도 켤 것 같다.`
2. `부자는 돈이 많은 사람이 아니라 계속 틀리고 다시 고를 수 있는 사람이구나.`
3. `혁명군 안에서도 누구 말이 맞는지 모르겠다.`
4. `상층도 단순한 착취자가 아니고 누군가는 실제 비용을 치르고 있다.`
5. `서인은 멋있지만 점점 도윤과 같은 질문으로 가고 있다.`

50화에서 이 다섯 감정이 동시에 존재하지 않으면 WORLD REVEAL PASS 실패로 판정한다.

## 2. 구간별 판정

### 1~10화 — 유지 + 복선 강화
- 판정: **A급 핵심 보존**.
- 이미 광고꿈의 실제 매력, 재가입의 자발성, 서인의 가지치기 통찰, 상층 AI 병목, 도윤의 매력이 사건으로 작동한다.
- 설명 추가 금지.
- 보강은 후반 설정을 위한 짧은 복선만 허용: TOKEN 재검증 격차, 도윤이 과거 실패를 너무 잘 아는 순간, 상층의 '다시 계산' 습관.

### 11~20화 — 유지 + TOKEN 의미 선명화
- 판정: **대부분 유지**.
- 서인의 시술/과부하/회복과 중앙 전략망 진입은 핵심 성장축으로 사용.
- 16화의 대규모 TOKEN 전쟁을 작품의 첫 번째 '재선택권' 세트피스로 승격한다.
- 20화 권한 획득은 행정 승급이 아니라 '버튼 하나로 사람들의 밤과 의료 검증을 동시에 바꾸는 자리'라는 공포를 전면화한다.

### 21~30화 — 압축 + 혁명 연합체 발현
- 판정: **구조 보강 필요**.
- 현재 시범·공공망·가족 보호·야간 공급 등의 사건은 좋은 재료지만 비슷한 정책 실험으로 읽힐 위험이 있다.
- 이 구간에서 현재 혁명 조직이 단일 집단이 아니라는 사실을 사건으로 처음 보여 준다.
- 생계파 / 회복파 / TOKEN 개혁파 / 인지해방파가 같은 사건에 서로 다른 답을 내게 한다.
- 도윤은 회의를 지배하지 않는다. 각 주장에 과거 실패 사례를 하나씩 알고 있는 사람으로 보인다.
- 독자는 아직 '실패의 독점'의 정체를 알면 안 되지만 `왜 저 사람은 이것까지 이미 알고 있지?`를 느껴야 한다.

### 31~40화 — 가장 큰 압축 대상 + 상층 희생/앵커 진입
- 판정: **WORLD REVEAL PASS 최우선 수술 구간**.
- HUMAN ONLY, 이름 사용, 신청 대행, K-7, 순번/주소군 등은 각각 흥미로운 소재지만 연속 배치되어 작품의 스케일을 좁힌다.
- 최소 2~3개 사건군으로 압축 가능성 검토.
- 확보한 분량/호흡을 이용해 '기준층'과 승인자 4를 단순 미스터리 용어가 아니라 인간적 비용으로 연결한다.
- 36~40화 사이에 **앵커를 직접 보거나, 앵커 가족의 실제 생활 비용을 목격하는 A급 사건**이 필요하다.
- 목표 감정: `상층을 무너뜨리면 끝인 줄 알았는데, 이 사람을 빼면 누가 대신 들어가지?`

### 41~45화 — 앵커/상층의 도덕적 반전
- 판정: **설정 발현 강화**.
- 승인자 4는 규칙 설명자가 아니라 실제로 한 번 전체망을 꺼 본 사람이라는 흔적을 남긴다.
- 11분 사건의 전모는 공개하지 않아도 된다. 단, 의료 재검증/재난 신뢰도/물류 안전모드가 동시에 흔들렸다는 체험적 흔적이 필요하다.
- 상층 특권과 희생을 한 인물 안에서 동시에 보여 준다.
- 앵커 후계자가 법적으로 거부할 수 있다는 사실과, 거부하면 부모가 더 오래 연결되어야 한다는 구조를 사건화한다.

### 46~50화 — 생활 미스터리 단독 진행 금지 + 도윤/혁명축 재점화
- 판정: **재배치/범퍼 검토**.
- 704호·이름표·컵·물·고지서의 생활 서사는 정서적 장점이 있으므로 삭제하지 않는다.
- 다만 50화 도착점이 이름표 미스터리만 남아서는 세계관 상승곡선이 꺾인다.
- 생활 사건 뒤에 더 큰 질문이 붙어야 한다: 누가 누구의 비용을 대신 내는가 / 누가 남기 위해 다른 사람이 연결되는가 / 자유를 거부하는 사람에게 혁명은 무엇인가.
- 50화 말미 또는 49~50 사이 범퍼 후보로 **서인이 처음으로 '한 번은 강제로 끊어야 하는 것 아닌가'에 가까워지는 사건**을 배치한다.
- 도윤은 그 말을 부추기지 않고 오히려 제지한다. 첫 독자는 도윤이 더 온건하다고 느껴야 한다.

## 3. 설정 발현 세트피스 후보

### S1. 다시 생각할 권리
하층의 6.8 TOKEN 재검증 망설임과 상층의 1.2M → 3.8M → 6.4M → 9.4M 재계산을 같은 사건군 안에서 대비한다. 숫자를 설명하지 않고 '같은 종류의 두 번째 판단'에 드는 가격으로 보여 준다.

### S2. 혁명군의 첫 공개 분열
광고꿈/인지공급을 1개 구역에서 끊을 기회가 생긴다. 회복파는 즉시 중단, 생계파는 TOKEN 수입 공백을 반대, TOKEN 개혁파는 계약 수정, 인지해방파는 인간 뇌 생산수단 자체를 거부한다. 어느 쪽도 악역으로 만들지 않는다.

### S3. 앵커의 거부권
서인은 앵커를 피해자로 보고 연결 해제를 제안한다. 앵커는 법적으로 나갈 수 있다고 답한다. 그러나 자신이 나가면 후계자인 자녀가 들어오거나 부모 세대가 더 오래 남아야 한다. '강제 없음'이 오히려 더 잔혹한 구조로 보이게 한다.

### S4. 승인자 4의 11분
전체 전모는 후반용으로 남긴다. 1~50에서는 승인자 4가 과거 11분간 전체망 중단을 승인했다가 되돌렸다는 사실과, 그때 여러 사회 기능의 신뢰도가 동시에 무너졌다는 흔적까지만 발현한다.

### S5. 서인의 첫 오판
TOKEN 전쟁에서 서인은 대부분의 가지를 정확히 버리지만 한 인물의 사적 이유를 몰라 마지막 가지 하나를 잘못 버린다. 이 실패가 '서인은 AI보다 우월하다'를 깨고, 과부하와 재검증 브레이크 문제를 동시에 살린다.

### S6. 도윤의 실패 데이터베이스
혁명 내부 논쟁마다 도윤이 `그 방법은 예전에 있었다`는 식으로 너무 정확한 실패를 알고 있다. 정체는 설명하지 않는다. 50화 이전 독자는 도윤을 '이상할 정도로 오래된 사람'처럼 느끼기 시작한다.

## 4. 화별 판정 태그

실제 원고 수정 전에 1~50 모든 화에 아래 중 하나 이상을 부여한다.

- `KEEP`: 현재 A급 장면/기능 보존.
- `COMPRESS`: 반복되는 규칙·조회·절차를 줄임.
- `REVEAL`: 기존 사건에 세계관 의미를 사건으로 추가.
- `BUMPER`: 본편을 크게 훼손하지 않고 사이에 새 사건이 필요.
- `MOVE`: 좋은 장면이지만 상승곡선상 위치 변경 검토.

원칙: **좋은 생활 디테일을 설정 설명으로 교체하지 않는다.** 생활 디테일에 더 큰 구조가 충돌하도록 만든다.

## 5. 1차 작업 우선순위

1. 31~40화 정밀 판정 — 가장 큰 스케일 축소 구간.
2. 41~50화 정밀 판정 — 승인자 4/앵커/도윤 재점화 위치 확보.
3. 21~30화 혁명 연합체를 끼울 수 있는 기존 사건 찾기.
4. 1~20화는 최소 수정 원칙으로 복선만 점검.
5. 전체 지도 승인 뒤에만 원고 수정.

## 6. 금지

- 설정집 문장을 등장인물 대사로 그대로 설명하지 않는다.
- 도윤의 앵커 가문 출신/최종 계획/자녀 세뇌를 50화 전에 확정 공개하지 않는다.
- 앵커를 단순 성인/희생양으로 만들지 않는다.
- 광고꿈 이용자를 무지한 피해자로 만들지 않는다.
- 혁명군을 하나의 이념으로 통일하지 않는다.
- 서인의 통찰을 초능력/정답 생성기로 만들지 않는다.
- main 직접 수정 금지.

## 7. 성공 기준

50화까지 읽은 독자가 설정 용어를 모두 설명할 필요는 없다. 대신 다음 질문을 스스로 하게 해야 한다.

- 왜 사람들은 자유를 줘도 돌아가는가?
- 왜 돈이 아니라 '다시 생각할 기회'가 계급을 만드는가?
- 인간 뇌를 빼면 실제로 누가 피해를 보는가?
- 희생을 스스로 선택한 사람을 해방시켜도 되는가?
- 도윤은 왜 모든 실패를 이미 알고 있는가?
- 서인이 사람들보다 더 잘 안다고 믿기 시작하면 도윤과 무엇이 다른가?

이 질문들이 살아 있으면 설정은 설명된 것이 아니라 **발현된 것**으로 판정한다.
