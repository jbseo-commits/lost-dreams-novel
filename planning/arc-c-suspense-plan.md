# 아크 C 「열두 시의 불」 서스펜스·스펙터클 계획 (42~53화, 제안)

2026-10-03 · 평가(1~41화 전문 정독)에서 나온 구조적 약점(21~26화, 35~40화의 '제안→숨은 피해→반박→인정' 반복, 정책 퍼즐화, 서인이 구경만 하는 화, 도윤·혁명군 부재, 방치된 조회 차단 6건)을 끊고, 독자가 다음 화를 넘기게 만드는 시간 압박과 도시 규모 장면을 넣기 위한 계획이다. 모든 사건과 수치는 **제안**이며 작가가 정하기 전에는 확정이 아니다. 도윤 정체 공개(146~165화)와 승인자 4의 정체, 07·09·10번의 확정 방향은 건드리지 않는다.

## 1. 약점별 처방

| 평가에서 나온 약점 | 이 아크의 처방 |
| --- | --- |
| 정책 퍼즐이 사건을 대신함 (대기 순번·승인 상한 변형) | 새 수치 규칙을 사건 원인으로 쓰지 않는다. 수치는 **시계**(카운트다운)로만 쓰고, 사건은 사람의 행동과 추적으로 만든다. |
| 서인이 제안하고 약자가 피해를 보는 틀 반복 | 서인이 아니라 **외부 행위자가 먼저 움직인다**(세르젠·오르비스·누군가의 감시). 서인은 막거나 늦거나 틀린다. |
| 서인이 구경만 함(41화) | 서인이 직접 행동하고 **잃는다**(어르신 신뢰, 도윤에게 진 빚, 어머니의 안전한 일상 중 하나). |
| 대사로 주제를 말함 | 장면마다 '이번 화의 행동 하나'를 정하고 설명 대사 없이 끝낸다. 관료 인물마다 호칭·어휘를 달리한다. |
| 도윤·혁명군 부재 | 43화에 돌아온다. 사상은 설명하지 않고 **일을 같이 하는 사람**으로 쓴다. |
| 방치된 단서(조회 차단 6건, 17화 에일론 회신, 21화 20분 약속) | 44·46·50화에서 회수한다. |

## 2. 시계: D-14

40화에서 해제 요청이 적용되고, 정책 소관 14일(추첨 재심사)이 같은 날 시작됐다. **14일 뒤 금요일 밤 0시**에 두 가지가 겹친다. (1) 해제로 승인 대상이 된 동부 27번 가구들이 한꺼번에 야간 공급을 시작한다. (2) 14일짜리 정책이 처음 적용된다. 42화부터 매 화 끝에 남은 날수를 한 줄로 적는다(숫자 퍼즐이 아니라 시계로만 사용). 클라이맥스는 52~53화의 금요일 밤이다.

## 4. 스펙터클 장치 후보 (제안)

1. **도시 지도 소등:** 동부 27번 불빛이 구역별로 꺼지는 장면. 웹 연출의 후보 세트피스다.
2. **야전 의료실:** 폐쇄 클리닉 지하를 개조한 공간. 수면 클리닉의 원래 기능과 대비한다.
3. **노인 120명 이동:** 노인정→시장 2층→병원으로 이어지는 야간 이동. 달력 뒷장 판이 이동 중에도 이어진다.
4. **K-7 야간 클럽 협상:** 형광 불빛과 번호표 기계가 있는 공간에서의 대립.
5. **서인의 직접 걷기:** 모노 없이 환자 이송 경로를 눈과 발로 막는 장면. 극한 통찰의 대가(코피)와 연결한다.

## 5. 지킬 것

- 도윤은 사상과 과거를 설명하지 않는다. 의미심장한 침묵으로 끝나는 장면을 더하지 않는다. 정체 단서는 소품으로만 쓰고 서인이 열어 보지 않는다.
- 승인자 4의 정체·소속은 미공개로 둔다. 49화는 숫자 하나만 보낸다.
- 새 수치 규칙(순번·상한·퍼센트)을 사건의 원인으로 만들지 않는다. 숫자는 시계로만 쓴다.
- 서인이 틀리는 장면과 늦는 장면을 최소 두 곳 넣는다(44화, 53화).
- 각 화 마지막 줄은 잠언이 아니라 행동이나 물건으로 닫는다.
- 노인과 소액 참가자를 무지하게 그리지 않는다. 판을 지키는 것도 판을 바꾸는 것도 그들의 선택으로 쓴다.

## 6. 먼저 고칠 연속성 (이 아크 전에)

- 41화: 윤 여사가 일곱 시 판을 '일요일 아침'에 정한 것으로 고쳤다(40화 끝에 서인이 있던 자리와 모순 해소).
- 지우 공방 요일: 7·11화 '토요일'을 '저녁'으로 맞춘다.
- 달걀 가격, 대기 일수, 34화 환급 수치, 21화 '20분 안에 재연락' 약속, 24화 보도자료 시각을 정리한다.
- 40화의 승인자 4 면담이 05에는 42화 이후로 적혀 있으니 05를 40화 기준으로 정정한다.
