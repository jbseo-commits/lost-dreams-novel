# 비주얼노벨 어머니 에셋 연령 일관성 2차 교정

2026-10-27 · 작업 브랜치: `art/mother-age-consistency-20261027`

## 문제와 고정 기준
4화 모바일 화면에서 서인은 섬세한 반실사 애니메이션 화풍인데, 어머니는 회색 머리에도 지나치게 젊은 얼굴로 읽혔다. 2026-10-21의 `*-mature.webp` 교정본 7종 역시 유사한 문제가 있다. **서인은 수정하지 않고**, 어머니의 시각적 연령을 50대 후반 인상으로 통일한다. 이는 설정상 정확한 나이를 확정하지 않는다.

## 반영 범위
- 어머니 표정: `motherCare`, `motherWarm`, `motherSearching` (3종)
- 사건 CG: `kitchenAd`, `table`, `coreMotherSleep`, `coreMotherDinner` (4종)
- 적용 경로: `vn/parent-art.js`의 7개 키, `vn/ep1-assets.js`, `vn/title-screen.css`, 데모 로딩 캐시 경로
- 원고, 대사, 저장 좌표, 캐릭터 ID, 지우 아버지와 서인 에셋에는 변경 없음

## 제작 방식과 한계
새 `*-age-v2.svg`는 기존 고해상도 WebP를 **그대로 포함한 정적 SVG 교정 레이어**다. 눈가, 팔자주름, 광대 아래, 목의 음영/선 묘사와 일부 손등 피부결을 보강한다. 원본 WebP는 삭제하지 않았다.

이는 **완전히 다시 그린 픽셀 원화가 아니라 비파괴 보정 후보**다. 따라서 코·광대·턱의 형태, 머리카락, 표정 구조를 완전하게 교체한 결과라고 주장하지 않는다. 사용자 최종 품질 기준은 모바일 실제 화면에서 판정해야 한다.

## 검증 범위
- GitHub에서 7개 SVG 실파일을 다시 읽고 XML 헤더, 내장 원본 이미지, 치수, 교정 레이어 존재를 확인했다.
- 기존 `vn/teaser-art.test.mjs`는 SVG 교정본에 포함된 원본 WebP의 크기/알파와 해시를 검증하도록 업데이트했다.
- **실제 Node 테스트 실행 및 390·400px 실브라우저 스크린샷 비교는 수행하지 않았다.** 테스트 통과나 최종 미술 품질을 인증하지 않는다.
- 기존 `vn/play-offline.html` 생성 번들은 이번 PR에서 재빌드하지 않았다. 온라인 데모 변경과 별개로 오프라인 재생본의 동기화가 필요하다.
