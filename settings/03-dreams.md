# 꿈의 계급화

하층민은 토큰을 벌기 위해 잠든 동안 뇌에 광고를 틀고, 그 대가로 "내가 꾸는 꿈"을 잃었다.

| | 상층 | 하층 |
| --- | --- | --- |
| 몸의 휴식 | 같음 | 같음 |
| 잠자는 동안 | 꿈 없이 자거나, 원하는 꿈을 골라서 꿈 | 뇌 내장 광고를 보고 토큰을 받음 |
| 내 꿈 | 있음 | 사라짐 |

- **수면의 질은 다르지 않다.** 몸은 멀쩡하고, 잃은 것은 내면과 정체성이다.
- **하층에게는 잠도 노동이다.** 낮에는 일하고 밤에는 꿈을 판다.
- **겉보기에 피해가 없는 불평등이다.** "몸은 멀쩡하잖아"라는 논리 때문에 문제 제기 자체가 어렵다. 이 세계의 가장 무서운 지점이다.
