# 미정 사항

## 이번 논의에서 확정한 사항

- [x] **꿈이 사라진 영향**: 장기간 광고 꿈에 노출되면 자발적인 상상력과 욕망이 약화되고 기업이 설계한 욕망으로 대체된다.
- [x] **꿈의 회복 가능성**: 광고 꿈을 중단하면 누구나 충분한 시간에 걸쳐 완전히 회복할 수 있다.
- [x] **회복 조건**: 시간에 따른 자연 회복, 자발적인 경험과 선택의 촉진 효과, 경제적 여유에 따른 회복 기회의 격차.
- [x] **혁명의 중심 갈등**: 군중은 회복할 수 있어도 회복을 선택하지 않는다. 주인공은 강제적 혁명밖에 없다고 믿게 된다.

- [x] **혁명군 메인 빌런**: 과거 광고 송출을 중단하고 뇌내 재생 기술을 탈취해 자신의 아이들의 꿈을 조정·세뇌했으며, 혁명을 세대에 걸쳐 강요한다. 혁명 이후 새로운 억압자가 된다.

- [x] **극한 잠입 훈련**: 주인공은 상류층 잠입을 위해 고통스러운 뇌내 스캔과 인격 조정을 견디며, AI 없이 인간의 통찰로 혁명을 수행할 극소수의 요원 중 하나다.

- [x] **최종 빌런의 서사적 위장**: 정체 공개 전까지 주인공의 가장 친한 조력자이며, 기술 탈취·자녀 세뇌·인격 조정의 진상은 암시만 한다.

- [x] **주인공의 AI 없는 통찰과 회복**: 급변하는 토큰 전쟁에서 AI의 예측 병목을 빠른 인간적 통찰로 돌파한다. 상류층은 비밀 최첨단 AI로 오해하며, 일주일 이상 회복하는 공백은 오히려 신격화를 강화한다.
- [x] **빌런의 후계자 관계 방향**: 작가는 C 방향을 선택했다. 빌런은 주인공을 자신의 혁명을 완성할 후계자로 여기며 진심으로 아끼지만 자신이 설계한 이상을 계승시키려 한다. 구체적 관계 장면은 제안 단계다.

- [x] **정체 공개 시점**: 혁명 성공 직전 마지막 실행 권한 확보 단계에서 가장 친한 조력자의 진상을 공개한다(A). 정확한 증거와 장면은 제안.
- [x] **최종 혁명의 딜레마**: 기술적 분리 문제·군중의 생존 토큰·빌런의 후계자 제안을 동시에 결합한다(D). 해방 프로토콜의 기술 구현은 제안.
- [x] **최종 혁명의 대가**: 능력 상실 위험·조력자 상실·불완전한 해방을 결합한다(D). 영구적 능력 상실은 미정.
- [x] **빌런의 운명**: 주인공을 살리기 위해 죽지만 자신의 사상이 틀렸다고 인정하지 않는다(A). 죽음의 기술적 원리는 제안.
- [x] **사후 후계자와 결말 방향**: 빌런의 친자녀들이 남아 사상을 계승하거나 거부하며, 주인공은 애증을 안고 살아간다. 친자녀 중심에 클론 존재 가능성만 암시한다(B). 클론의 실재는 미정.

- [x] **작품의 핵심 주제 재정립**: 단순한 꿈 회복이 아니라, 꿈꿀 자유가 있어도 꿈꾸기를 포기하는 사람들의 세계를 중심에 둔다.
- [x] **꿈 포기의 사회적 방향(D)**: 꿈을 포기하는 선택을 합리성(A)·행복(B)·책임(C)이 함께 작동하는 구조로 발전시킨다. 구체적 제도와 인물 장면은 제안 단계다.
- [x] **꿈 회복과 꿈꾸기 선택의 구분**: 자발적 욕망을 회복하는 것과 그 욕망을 실제 삶에서 추구하는 것은 별개의 문제다.
- [x] **주인공의 출신 계층(A)**: 서인은 평생 하층에서 살았지만 극빈층 출신은 아니다. 안정적인 노동과 광고꿈 수입으로 교육과 회사 생활이 가능했던 평범한 하층 가정이며, 어머니는 체제를 단순히 증오하거나 자신의 삶을 실패로 여기지 않는다. 아버지의 상태와 통찰 능력의 근원은 별도 미정.
- [x] **서인의 시스템 의심 형성 방식**: 한 번의 개인적 비극이 아니라, 광고꿈을 자발적으로 선택한 어머니·AI를 통해 자기 욕망을 발견하는 어머니·꿈을 포기하고도 행복한 또래·계층별 의료 AI가 만드는 불확실성의 차이가 누적되어 서인의 오래된 의문을 형성한다. 1화 이전에는 저항 행동으로 이어지지 않는다.

## 계속 결정할 사항

- [x] **주인공의 출신 계층**: A 방향 확정. 극빈이 아닌 평범한 하층 출신이며, '불행해서 혁명하는 가난한 천재' 서사를 피한다.
- [x] **시스템을 처음 의심하게 된 과거 사건**: 단일 비극 대신 네 종류의 작은 균열이 성장 과정에 누적되는 구조로 확정. 구체 연령·대사·제도명은 원고화 전 조정.
- [ ] **통찰력의 근원**: 토큰이 부족해 스스로 생각해온 삶, 광고 꿈이 들어가지 않는 체질, 또는 타고난 천재
- [ ] **중간층의 존재 여부**: 상층과 하층 두 계층만 둘지, 중간층도 둘지
- [ ] **잠입의 위험 요소**: 상류층이 토큰 없는 사람을 알아보는 방법 (응답 속도, 지식의 폭, 꿈 이야기 문화, 칩 신호 검사)
- [ ] **주인공의 위장 기술**: 상대가 듣고 싶은 답 읽기, 질문으로 되받기, AI가 못 하는 예측 불가능한 선택
- [ ] **무너뜨리는 방법**: 광고 꿈의 진실 폭로, 토큰 시스템의 약점, 상류층 내부의 불신
- [ ] **반란군의 구체적 역할**: 바깥의 조력자, 주인공과의 갈등, 마지막에 합류
- [ ] **하층민의 구체적 인식 차이**: 알고 슬퍼함, 당연하게 여김, 세대마다 다름
- [ ] **이 세계가 시작된 시점**: 10~20년 전(기억하는 세대가 있음) 또는 50년 이상 전(꿈이 전설이 됨)
- [ ] **"꿈"이라는 단어의 쓰임**: 장래희망이라는 뜻까지 사라짐, 상류층의 말, 금기어
- [x] **결말의 큰 방향**: 완전한 혁명이 아닌 불완전한 해방과 주인공의 애증을 남긴다. 구체적 경제 제도와 주인공의 자기 꿈은 미정.
- [ ] **기업의 의도**: 욕망 대체를 처음부터 의도했는지, 발견 후 악용했는지, AI 최적화의 부산물인지
- [ ] **혁명 결심의 결정적 사건**: 군중의 회복 거부를 주인공이 어떤 사건으로 확인하는지
- [ ] **D 통합 사회의 구체적 제도**: AI 인생 경로 권고, 광고 꿈의 행복 상품화, 개인의 도전이 가족에게 발생시키는 비용을 어느 수준까지 제도화할지 (제안)
- [ ] **꿈을 포기한 대표 인물들**: 생존자·만족자·체념자의 구체적 신상과 주인공과의 관계 (제안)
- [ ] **회복한 만족자의 재선택 사건**: 충분히 회복한 사람이 광고 꿈과 기존 삶을 다시 선택하는 결정적 장면과 주인공의 반응 (제안)
- [ ] **주인공의 최종 변화**: 타인의 선택을 진정으로 존중하게 되는지, 혹은 대신 결정할 권리가 없음을 인정하는 수준인지
- [ ] **혁명 이후의 군중**: 강제 중단과 경제적 충격, 주인공에 대한 반발을 어떻게 다룰지
- [ ] **회복 초기의 심리적 공백과 기업의 대응**: 제안 단계

- [ ] **뇌 사용 극한의 정의와 부작용**: '100 이상'의 의미, 측정 방식, 인격 조정의 후유증과 탈락자들의 운명
- [ ] **주인공의 회복 규칙**: 일주일 이상의 회복기 증상, 반복 사용의 위험, AI 검증을 피하는 방법
- [ ] **후계 관계의 결정적 사건**: 첫 만남, 후계자 선언, 최종 결별과 복선의 구체적 형태
- [ ] **빌런의 과거와 자녀 세부**: 과거 송출 중단 사건의 시점·규모, 친자녀 수와 위치·인물 성격, 혁명 성공 직전 정체 공개의 구체적 증거

## 새로 남은 결정 사항

- [ ] **해방 프로토콜**: 광고 중단·임시 토큰·꿈 재생 기능을 연결하고 분리하는 기술적 원리 (제안)
- [ ] **빌런의 희생**: 주인공을 살리면서 죽는 구체적인 신경 연결·안정화 장치 (제안)
- [ ] **주인공의 최종 인지 상태**: 마지막 통찰 후 장기 회복과 영구적 능력 손상 여부
- [ ] **친자녀의 독립적 선택**: 주요 친자녀 수, 첫째가 주입 이후에도 사상을 재선택하는 사건, 둘째의 독립적 삶 (제안)
- [ ] **클론의 실재 여부**: 클론 존재는 암시만 한다는 방향 확정. 실제 존재·기억 계승·프로젝트 기록의 진실은 미정
- [ ] **최종 에필로그 원고**: 첫째·둘째와의 대화, 미확인 세 번째 기록, 마지막 행동의 정확한 표현 (제안)
