## 08 주인공 인지 — 동기화 판정

기존 핵심인 `AI는 분석하고, 인간은 통찰한다`, 서인의 가지치기형 통찰, 11화 시술의 재확인 브레이크 약화는 유지한다.

추가 확정:
- 극한 사용의 핵심 부담은 단순히 생각을 많이 하는 것이 아니라 **올라오는 후보를 빠르게 억제하고 재검증을 생략하는 상태를 장시간 유지하는 비용**이다.
- 과부하는 `감각 제거 → 과잉 확신 → 후보 붕괴 → 셧다운`의 4단계로 진행한다.
- `쿨링`은 속어다. 실제 회복은 억제/흥분 균형과 재검증 경로의 재안정화이며 심한 사용 뒤 1주 이상 걸린다.
- 가장 위험한 장기 대가는 죽음이나 단순 기억상실보다 **자기 판단이 틀릴 수 있다는 감각의 상실**이다.
- 기존 08의 `극한 사용 시 모든 단서가 의미 있어 보인다`는 표현은 과부하의 한 국면으로 유지하되, 최종 붕괴는 후보를 제대로 생성/비교하지 못하고 첫 답에 고착되는 단계까지 포함한다.
- 서인의 최종 성장은 더 빠른 정답이 아니라 `모르겠다`를 받아들이고 가능성을 닫지 않는 능력이다.

## 09 전체 서사 — 동기화 판정

기존 6부 구조는 참고 골격으로 유지하되 아래를 최신 확정으로 승격한다.

- 혁명군은 도윤이 처음부터 만든 단일 비밀결사가 아니라 여러 시대의 독립 혁명 계보가 합쳐진 연합체다.
- 도윤은 공식 절대지도자보다 여러 계보의 실패를 가장 많이 연결하는 조정자이며 그의 권력은 **실패의 독점**에서 나온다.
- 서인은 생활파에서 출발해 TOKEN 개혁·회복·인지해방·앵커 문제로 내려간다.
- 서인의 강제혁명 논리는 `조건을 해결해도 복귀 → 진실을 알아도 체제 선택 → 희생자인 앵커도 연결 유지 선택`의 세 실패로 누적된다.
- 국가/기업/기준계열 신탁은 서로 다른 기능을 가진다. 국가만 또는 기업만 제거해서는 체제가 끝나지 않는다.
- 최종 혁명의 답은 전체망 파괴가 아니라 **인간 의존 기능을 분리하고, 인간이 반드시 필요한 판단을 상시 뇌 공급이 아닌 선택적 질문 구조로 바꾸는 것**이다.
- 12개 기준계열은 즉시 제거하지 않고 고정된 개인 기준에서 분산 인간 판단 집단으로 점진 전환한다.
- 새 구조는 기존 체제보다 비싸고 느리며 TOKEN 공급·성장률·서비스 속도에 실제 비용을 만든다.
- 도윤은 사람들의 재선택이 결국 옛 체제를 되살릴 수 있다는 이유로 강제 욕망 복원을 선택한다.
- 서인은 자기 분리안조차 전 인류에게 강제하지 않는다. 기존망과 분리망의 공존을 허용한다.
- 도윤은 사상을 철회하지 않은 채 서인을 살리고 죽으며, 마지막에 포기하는 것은 사상이 아니라 **결론을 독점할 권리**다.

## 10 후계자·에필로그 — 동기화 판정

최신 확정:
- 도윤 친자녀는 **3명**이다: 계승형 / 거부형 / 개혁형.
- 어느 자녀도 작품의 정답으로 판정하지 않는다.
- 클론은 끝까지 실존 여부를 확정하지 않는다.
- 혁명 뒤 세계는 전면 교체가 아니라 대략 30~40% 감각의 불완전한 전환이다. 정확한 공식 수치는 원고에서 밝히지 않아도 된다.
- 기존망/분리망, 광고꿈 사용/비사용, TOKEN 의존/저의존 경제가 공존한다.
- 마지막 윤리는 `꿈을 되찾게 한다`가 아니라 **꿈을 꿀 수도, 꾸지 않을 수도, 다시 선택을 바꿀 수도 있는 조건을 남긴다**이다.

## 05 open questions — 닫힌 항목

아래는 더 이상 미정으로 취급하지 않는다.

- TOKEN 발행·정산의 큰 구조: 기업이 미래 연산 공급능력을 증명하고 국가가 사회적 청구권 인정 범위를 승인하며 공동 청산망이 발행·정산한다.
- TOKEN 전쟁의 원리: 미래 희소 자원 선점 경쟁 + 상대 AI의 대응을 다시 예측하는 재귀 병목.
- TOKEN 대규모 소비의 의미: 답 하나 구매가 아니라 반복 재검증/재선택 비용.
- 인간 인지망 통제 분할: 접속·시민권은 국가, 작업 설계·산업 활용은 기업, 장기 인간 기준은 기준계열 신탁.
- 혁명군의 큰 조직형: 독립 혁명 계보의 연합체.
- 도윤의 조직 내 위치: 여러 실패 계보를 통합한 조정자. 전체 최종계획은 도윤만 알고 핵심 인물 3~5명은 부분만 안다.
- 서인과 도윤의 첫 관계: 우연에 가까운 발견 뒤 도윤이 이상치를 관찰하며 접근. 사건을 만들기보다 실제 선택을 관찰한다.
- 도윤이 서인을 후계자로 확신하는 계기: 서인이 도윤의 예측 밖의 선택을 만들어 성공했을 때.
- 서인의 과부하 단계와 핵심 장기 위험.
- 최종 혁명의 기술적 방향: 인간 의존 기능 분해 + 선택적 인간 질문 + 기준계열의 분산 전환.
- 도윤 친자녀 수와 세 방향: 3명, 계승/거부/개혁.
- 에필로그의 큰 상태: 불완전한 다중 체제 공존.
