# 작품 개요

토큰이 곧 지능이자 계급인 세상에서, 토큰 없는 한 사람이 자기 머리 하나로 상류층에 잠입해 디스토피아를 무너뜨리는 이야기다.

| 항목 | 내용 |
| --- | --- |
| 가제 | 꿈을 잃은 세계 |
| 한 줄 콘셉트 | 꿈마저 광고로 팔아야 하는 세상에서, 토큰 없는 삶을 꿈꾸는 한 사람의 잠입과 반란 |
| 장르 | 근미래 SF 디스토피아, 잠입물 |
| 핵심 테마 | 꿈의 상실과 회복, AI에 의존한 지능과 인간 고유의 통찰, 해방과 선택의 충돌 |
| 상징 | 꿈. 잠의 꿈과 삶의 꿈이 함께 사라진 세계에서 다시 꿈을 꾸는 것 |

## 작품의 중심 갈등

꿈을 잃은 군중은 꿈을 되찾을 수 있어도 되찾기를 선택하지 않는다. 주인공은 그들의 자발적인 선택을 기다리는 것으로는 체제를 바꿀 수 없다고 생각하며, 결국 강제적인 혁명밖에 없다고 믿는다. **자유를 되찾아 주기 위해 타인의 자유를 거스를 수 있는가**가 이야기의 중심 모순이다.

군중이 꿈을 되찾지 않는 이유를 단순한 무지나 악의로 처리하지 않는다. 생계와 익숙한 행복, 스스로 선택했다고 믿는 욕망이 복합적으로 작용한다.
