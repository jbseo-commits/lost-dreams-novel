# 34화 합의 면담·환급 창구 장면 제작 (2026-10-21)

원고 근거: `manuscript/ep034.md` 53~280행 외부 회의실, 285~322행 환급 창구. 
- 오전 11시 아르카디아 회의실: 오하준 앞에 물이 **놓여 있지 않음**. 무표기 책상과 비어 있는 회의실을 시범 SVG로 제작.
- 오후 2시 10분: 환급 접수 창구는 작은 사무실 옆방. 번호표를 든 열댓 명, 상담원, 대기 행렬이 사건의 중심. 12 TOKEN 안내와 환급 거절은 원고 출현 후에만 HTML 레이어로 표시.
- 323행 복도 이동 시 환급 창구 배경은 종료. 34화 1~49행 사무실 위치 미확정 구간에는 잘못된 외부 회의실을 적용하지 않음.
- `vn/notes/ep034-internal-preview.html`: 34화 원고를 실제 문장 순서대로 이전/다음 및 면담/환급 시점 이동. 정식판이 공개된다는 의미가 아님.

현재 공개 `vn/index.html`과 `vn/app.js`는 **1~11화 데모 버전**이므로 직접 수정하지 않음. `tools/build-vn-public.mjs`의 공개 산출물은 기존 잠금 범위를 보존하고, 이 페이지는 내부 원본 저장소 `vn/notes/`에만 보관한다. 실제 정식판의 34화 연결은 릴리스 승인 전까지 대기.

SVG 2개와 모듈·검수 페이지는 제작되었지만 **회화풍 원화 품질 G1~G9는 완성되지 않음**. 생성 이미지 한 차례는 엉뚱한 행사장/평가실 콜라주로 오생성되어 G2 실패, 저장소 반영하지 않음.

코드 회귀 테스트와 공개 빌드의 데이터 경계는 PR의 GitHub Actions에서 검증한다. `main` 직접 수정·병합·배포 금지.

## 2026-10-22 회화풍 본제작 재검수 및 내부 합성
- 회의실과 환급 창구의 회화풍 배경을 새로 생성하려 했으나, **두 개의 독립된 16:9 장면 대신 행사장·회의실·창구·로비 4분할 이미지**로 나왔다. 그림 속 확정되지 않은 기업 로고·간판·건물 구성 때문에 **G2/G8 FAIL**, 저장소의 정식 에셋으로 채택하지 않았다.
- 기존 `vn/assets/seoin.webp`, `yoonha.webp`의 원형을 유지하여 내부 검수 페이지에 인물 레이어로 합성했다. 오하준과 젊은 신청자는 전용 원화가 없어 얼굴을 새로 만들거나 다른 캐릭터로 대체하지 않았다.
- 모바일 화면에서는 캐릭터 1명만 보이도록 하고, 환급 창구에서는 백윤하 레이어를 감춘다. 정보 UI에는 `pointer-events:none`을 적용하고 이전/다음 버튼은 별도 영역에 둔다.
- 내부 검수용 파일: `vn/notes/ep034-internal-preview.html`. 최신 main의 무료 공개 빌드로 배포하지 않도록 `vn/release.test.mjs`와 `vn/notes/ep034-internal-preview.test.mjs`에 격리/파일 검사 추가.
- GitHub Actions에는 `vn-ep34-internal-review` 아티팩트 생성 단계를 추가했지만 **현재 HEAD의 CI 완료는 아직 확인되지 않았다**. 브라우저 자동 화면 검사 역시 해당 환경에서 `ERR_BLOCKED_BY_ADMINISTRATOR`로 실행되지 않아 **G6 PENDING**.
- **결론:** 내부 장면 조합·원고 출처 연출·회귀 검사 파일은 구현. 고품질 최종 1672×941 PNG/WebP 아트 승인과 G1~G9 전부 PASS는 아직 불가.
