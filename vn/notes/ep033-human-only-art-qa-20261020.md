## 연출 계획과 실제 구현
1. 외부 진입 직후부터 군중 줄을 보여 주되 **HUMAN ONLY OPEN**, **서인 방식으로 풀어 보세요**라는 홍보 문구는 각 문장이 읽혔을 때만 비문자 그래픽 위 HTML로 표시한다.
2. 대기실 참가자 0512, 0519의 숫자는 각 문장이 등장하기 전까지 숨긴다.
3. 중년 노동자의 검은 입력 보조 칩은 최초 묘사 이전에 보여 주지 않는다.
4. `정확히 3초.` 이후에만 정지 신호를 보여 주어 앞선 장면의 부정 패턴을 미리 유출하지 않는다.
5. 후반 다은의 일치도 72%, 인간다움 가산 +0은 실제 채점 대목에서만 노출한다. 다은 캐릭터 CG가 제작되지 않은 상태이므로 임의 얼굴이나 성인 원화를 대신 쓰지 않는다.
6. 모바일 레이어는 터치 불가(`pointer-events:none`), `aria-hidden`으로 원문 읽기를 방해하지 않는다.

## 원화 품질 판정
- 기존 이미지 생성 시도는 33화 인재홀 대신 10화 평가실 구도를 반복해 **G2 실패**, PNG 미채택.
- 이번 33화 두 장은 직접 구성한 1672×941 **벡터 시범 배경**이다. 장면의 위치와 군중 대비를 검증하는 구성도이지 상업용 완성 회화풍 PNG/WebP **원화가 아니다**.
- G1 PARTIAL(장면 의미는 보이나 표정·감정 CG 부재), G2 PARTIAL(원고 명시 장소·시간·방송 화면 준수, 건물 구조 확정 여부 불명), G3/G4 PENDING(다은·정미경 캐릭터 원화 미제작), G5 PARTIAL(상층 회의실과 밀도 대비), G6/G7/G8/G9 PENDING(실기기 캡처·축소·렌더 검수 전).
